# HD-2D — 风格提示词（v1）

> 低分辨率像素角色，站在有纵深、有光照的立体像素场景里：光柱从门外斜照进来，尘埃在光里飘，前景和远处虚掉，只有主角是清楚的。适合奇幻、游戏预告和“进入一个新世界”的瞬间。
> 样片：《晨光神殿》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **HD-2D** 风格拍一个“光照进来”的仪式感时刻。用户给你一个场景和一个角色，你把它做成：黑暗中的立体像素空间 → 一个动作带来光（开门、点火、拉开帘子）→ 光柱、尘埃、泛光铺满画面 → 角色沿着光走近镜头 → 一个定格姿势 + 片名。

---

## 1. 这个风格是什么

两套分辨率叠在一起：**材质是像素**（320×180 放大 4 倍、关闭平滑，砖缝和地毯花纹都是一格一格的），**光是高清的**（平滑的光照贴图、带模糊的光柱、泛光、尘埃光斑、景深）。角色是一张小小的像素精灵，按透视缩放，但永远是整数像素、边缘锐利。观众的感受是“像素游戏被放进了真实的光里”。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **光的出现** | 从暗到亮是最强的叙事，开门、日出、点燃火把都行。 |
| **纵深行走** | 角色从远处走向镜头，精灵越走越大，景深越来越浅，自带史诗感。 |
| **尘埃** | 只有落在光柱里的尘埃才亮，光柱本身因此“有体积”。 |
| **定格姿势** | 结尾一个像素化的标志动作（举剑、举灯），配一颗十字星闪光。 |

**结构（15 秒版，80 BPM，一拍 0.75 秒）**：0–3 秒暗厅，火把闪烁，镜头缓慢推进 → 第 4 拍（3.0 秒）敲门声，门缝透光 → 3.15–5.25 秒两扇门向内转开 → 第 7 拍（5.25 秒）门全开，钟声 + 合唱，光柱和尘埃铺满 → 第 8–15 拍骑士沿红地毯走向镜头 → 第 16 拍（12.0 秒）举剑，剑尖闪光 → 第 17 拍（12.75 秒）片名“晨光神殿” → 14.45–15 秒淡出。

## 3. 视觉语言

- **像素场景**：一个逐像素光线投射器，在 320×180 上算出材质颜色。焦距 210、主点 (160, 72)、眼高 1.6；大厅宽 ±3.2、高 5、后墙在 z=12；门洞宽 2，拱顶 `2.2 + √(1−x²)`（最高 3.2）；六根方柱在 x=±2.35、z=4/7/10，半宽 0.36。
- **材质**：石板地面每格 1 个单位、缝宽 0.07，底色 (104,106,124) + 格子噪声；中间红地毯 |x|<0.72，(128,34,48)，金边 (196,150,60)；墙砖 1×0.5 错缝，(88,88,108)；柱子带凹槽和浅色箍；门板每单位 5 条竖木板 (104,64,40) + 两道铁箍和铆钉；门外是晨光庭院 (240,226,196)。每种材质再叠一层 1/8 单位的格子噪声，保证“像素感”。
- **光照贴图**（同样 320×180，但放大时开平滑，再 `multiply` 到场景上）：环境光 rgb(40,46,98)，门开后升到 (66,70,110)；六支火把各一个暖色径向光（半径 300/距离，14 Hz 闪烁）；门洞沿阳光方向投到地上的光斑（模糊 2px）；骑士身后朝镜头方向的长影子 rgba(40,40,80,.65)。
- **光柱**：阳光方向 (0, −0.35, −1)。把门洞切成 11 条竖带，每条从门洞顶沿阳光方向投到地面，亮带和暗带交替（强度 1 或 0.22），渐变透明度 0.8 → 0.38 → 0，在低分辨率上模糊 1.6px 后 `screen` 叠加；骑士画完后再用 0.28 透明度叠一遍，保持“光在人前面”的体积感。
- **泛光**：`lighter` 叠加——门洞一团暖光（半径 260 + 160×开门程度）、每支火把一团橙光、剑尖一颗白光 + 十字星。
- **景深**：左侧一根离镜头很近的暗柱（模糊 10px）、右侧一串锁链；尘埃离对焦面越远越大越虚；最后把整帧复制一份，上下各两条带子重画（0–70 / 660–720 模糊 5px，70–130 / 600–660 模糊 2.5px），形成移轴效果。
- **像素骑士**：24×48 精灵，调色板 描边 `#141528`、亮甲 `#C9D4E8`、中甲 `#8B9BB4`、暗甲 `#566C86`、红缨 `#B13E53`、披风 `#6D1F3A`、金 `#F4B41A`、剑刃 `#E6F2FF`。
- **片名**：Noto Serif SC 700，76px，字距 18px，`#FFF1D2`，暖色外发光（阴影模糊 30），放在画面下方 y=632，下面一条细金线。

## 4. 动作语言

- 门：两扇门绕门轴向大厅内转 0 → 0.47π，smoothstep 缓动 2.1 秒。
- 骑士：门外时只从门缝里露出来（按两扇门的内缘投影裁切）；走路 4 帧循环、每拍两步、步伐带 1 像素上下颠；从 z=12 走到 z=7.1。
- 精灵缩放：每个精灵像素占 `round(210×1.95/距离/30×4×2)/2` 个高清像素，永远是半像素的整数倍，放大不糊。
- 逆光：精灵整体压一层深蓝 rgba(22,26,60, a)，a = 0.15 + 开门程度 × (0.62 − 0.22 × 行走进度)，从门口的 0.77 逐渐减到走近后的 0.55，再在左右上三个方向偏移 0.35 个精灵像素画金色剪影，形成轮廓光。
- 尘埃：260 颗三维粒子缓慢漂移上升；只有“沿阳光反推能穿过门洞”的粒子被照亮，火把附近的粒子微亮。
- 镜头：整个 15 秒缓慢推进 2.2 个单位，smoothstep。

## 5. 镜头语言

一个机位、一条中轴线：门在画面正中，地毯把视线从下边缘引向门。镜头只做缓慢的推轨（HD-2D 常见的“斜俯立体透视”在这里换成了中轴对称的纵深，更有仪式感）。开场 0.6 秒从黑场淡入，结尾 0.55 秒淡出到黑。

## 6. 声音

- **管弦铺底**：低音弦乐 Dm 和弦开场，门开后转 D 大调；行进段 D – Bm – G – A – D，每个和弦 1.5 秒（半小节）。
- **竖琴**：三角波 + 2、3 次泛音，1.6 秒衰减；开场零星拨弦，门开时 10 个音 55ms 间隔的上行刮奏，行进段三连音琶音。
- **钟声**：门全开（D5 + D4）、举剑（A5 + A4）、片名（D5）各一次。
- **合成合唱**：锯齿波过两个元音共振峰（800 / 1150 Hz）+ 5 Hz 颤音，0.8 秒起音，门开和举剑时各一段。
- **拟音**：敲门 = impact + 两下低音 tom；门轴吱呀 = 每秒 22–58 次、中心 260–780 Hz、Q=9 的摩擦脉冲；门缝风声 = 带通噪声扫频；盔甲脚步 = 低闷 thud + 2.1 / 3.2 kHz 金属叮，每半拍一步。

## 7. 文字与标题

全片只有一个片名“晨光神殿”，最后 2 秒出现在画面下方，不和角色抢位置。HD-2D 的魅力在光，不在字。

## 8. 踩过的坑

- **门还没开就是亮的**：门关着时门板和后墙在同一平面，求交时 `tt < t` 比不过后墙，门洞被当成“门外”画成了亮白色。改成 `tt < t + 1e-3`，门板优先。
- **骑士被光洗白**：一开始先画骑士、再叠光柱和泛光，骑士变成一块白色剪影，看不清像素细节。改成先叠光柱和泛光、再画骑士，最后用 0.28 透明度补一遍光柱。
- **轮廓光太粗像贴纸**：轮廓光偏移一整个精灵像素，骑士像被描了一圈黄边；改成 0.35 个精灵像素。
- **骑士太大、和片名撞车**：原本走到 z=5.8，占了半个画面，举起的剑正好顶到放在上方的片名。改成停在 z=7.1，片名移到画面下方。
- **前景像观众的后脑勺**：左下右下两团模糊暗块被看成观众剪影，换成左侧一根近景暗柱 + 一道暖色边光。
- **整体一片紫灰**：环境光太亮、火把光半径太大，没有明暗对比。环境光从 (58,64,118) 压到 (40,46,98)，火把半径 420/d → 300/d。
- **举起的剑被裁掉**：精灵画布原来 24×40，剑尖超出画布顶部，只剩半截。画布加高到 48，并整体下移 8 像素。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部按拍定义 `T_KNOCK / T_OPEN / T_WALK / T_STOP / T_RAISE / T_TITLE`，以及 `camZ(t)`、`doorAng(t)`、`knightZ(t)` 三条运动曲线。
2. 抽帧：`node _engine/render.cjs hd-2d stills 1,3.3,4.5,5.6,7,8.5,10,12.3,13.8`，拼 3×3 联系表检查亮度、光柱、骑士可读性。
3. 出片：`node _engine/render.cjs hd-2d`（每帧都要重跑光线投射，比平面风格慢一些）。封面取 9.4 秒：骑士走在光柱中间。
4. 验收：时长 15.0，响度约 −17.6 LUFS。

## 10. 引擎用法

- `renderWorld(camZ, 门角度)`：逐像素光线投射，只写材质色到 320×180 的 `ImageData`。
- `proj(x, y, z, camZ)`：3D → 低分辨率像素坐标，光照贴图、光柱、尘埃、骑士都用它对齐到同一个空间。
- `lmap` / `rays`：两张 320×180 画布，分别用 `multiply` 和 `screen` 叠加，放大时开平滑。
- `drawKnight(帧, 是否举剑)`：在 24×48 画布上用 `fillRect` 拼精灵，同时生成金色剪影 `rim`。
- `archTop(x)`：门洞拱顶高度，门洞、光柱、地面光斑和“尘埃是否被照亮”都靠它判断。
- 移轴：`tmp` 画布复制当前帧，再按 4 条带子用 `filter = blur()` 重画。
