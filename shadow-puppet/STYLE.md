# 皮影戏 — 风格提示词（v1）

> 一块被油灯照亮的幕布，彩色半透明的皮影人偶贴着幕布演：镂空花纹透出光，关节处有铆钉，细细的操纵杆从台下伸上来。适合民间故事、非遗、节日短片。
> 样片：《渔夫与金鱼》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **皮影戏** 风格演一出默剧小戏。用户给你一个故事，你把它压成 4–6 个“能用胳膊和道具演出来”的动作（撒网、拉网、捧起、放生、跃起、鞠躬），每个动作卡在锣鼓点上；人物不说话，最多用一个云朵气泡写两个字。

---

## 1. 这个风格是什么

观众看的是“幕布上的影子”，不是人偶本身，所以一切都要经过灯光：人偶的颜色是光透过染色驴皮后的颜色（用 multiply 叠在幕布上），镂空的地方直接透出灯光，离幕布远一点的东西（操纵杆、半影）是虚的。人偶是平的、侧脸的、由几块皮子用铆钉连起来的，动作靠关节转动，不变形。这三样（透光的镂空、关节铆钉、操纵杆）缺一样就不像皮影。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **关节转动** | 大臂、小臂、头都是单独的零件，绕铆钉转。抡胳膊撒网、捋胡子、点头、鞠躬都靠它。 |
| **道具飞出去** | 网、鱼可以离手飞行，走抛物线；落水溅起几颗“皮子做的”水花。 |
| **一句话气泡** | 默剧里唯一的文字：云朵形的皮影气泡，两个字（“放我”“谢谢”）。 |
| **跃出水面** | 前后两层镂空水波，鱼从两层之间穿出来，是全片最亮的一刻。 |
| **灯暗收场** | 船往右漂出，油灯慢慢暗下去，最后黑场。 |

**结构**：锣鼓开场 + 灯亮 + 影子片名（0–2.4 秒）→ 船划进来 → 撒网（拍点出手、拍点落水）→ 鱼游进网 → 拉网上来 → 鱼开口（金光 + 气泡）→ 渔夫吃惊、捋胡子想、点两下头 → 双手捧鱼、抛回河里 → 鱼跃起道谢，渔夫挥手、鞠躬 → 船漂走，灯暗。

## 3. 视觉语言

- **幕布**：区域 `(70, 46, 1140, 566)`；灯光径向渐变，中心 `rgb(255,238,196)` → 45% `rgb(244,205,140)` → 边缘 `rgb(150,84,36)`，半径 820，灯位左右慢晃 ±22px。叠 128px 布纹（每 3px 一道经纬线 + 噪点，multiply 35%）。四周再压一圈暗角。
- **油灯闪烁**：8Hz 平滑噪声，亮度在 0.93–1.00 之间抖；开场 1.2 秒从黑到亮，13.9 秒起慢慢暗到 45%。
- **皮子配色**：描边 `#2B1409`、红 `#B7322A`、青绿 `#2F6E62`、金 `#E3A21E`、土黄 `#C98A33`、脸/手 `#EBD3A0`、鳍 `#D14A26`、水波 `#3C8C94 / #23607A`、远山 `#6F8F8A`。
- **镂空**：每块皮子都要打洞——团花（6 瓣椭圆）、月牙、圆点排、柳叶缝；正派人物用“空脸”（脸部整块挖空，只留眉眼线）。洞用 `destination-out` 打在贴图上，所以真的透光。
- **描边**：3px 深褐，`lineJoin: round`；小零件 2px。皮面上叠一层随机斑驳纹理（`source-atop`，只在皮子上）。
- **铆钉**：半径 4 的深色圆 + 半径 1.6 的浅色芯，画在每个关节上。
- **半影**：人偶层先画一遍 `blur(7px)`、30% 不透明、偏移 (8, 5) 的虚影，再画一遍 90% 的实影。操纵杆 `blur(2.5px)`、55% 不透明——它们离幕布最远，所以最虚。
- **戏台框**：深木 `#2B120B`，金线 `#B8893A` 双框；顶上红帷 `#7E1C14` 带一排半圆垂边和金点；底板 `#3A1810` 上刻回纹。框上有幕布漏出来的暖光。
- **字体**：马善政毛笔楷 Ma Shan Zheng。片名 84px 深褐影子字（带 1px 模糊）；气泡字 46px 红色。

## 4. 动作语言

- **只转不变形**：所有动画都是零件的平移和旋转，关节角用 `keyframes([[时间, 大臂角, 小臂角], …])` 插值；0 = 下垂，负值 = 往前抬。
- **抡与停**：撒网先用 0.35 秒往后抡（大臂 +2.0），再用 0.22 秒甩到前上方（-2.1）——慢蓄快出，出手点正好在拍上。
- **整体晃**：船一直上下浮 ±6px、摇 ±0.02 弧度，人跟着船晃；吃惊时上身后仰 0.16，鞠躬前倾 0.38。
- **鱼**：尾巴是单独零件，一直以 12–17 rad/s 摆；在网里挣扎时摆得更大，开口说话那两秒安静下来。
- **气泡**：`back` 缓动 0.25 秒弹出，结束 0.25 秒缩回。
- 人偶层整体放大 1.2 倍（以 (640, 600) 为中心），操纵杆的端点也要走同一个变换 `Z()`。

## 5. 镜头语言

固定机位，永远是“坐在台下看幕布”。不推不摇，不切镜头；景别靠人偶大小解决。开场灯亮、结尾灯暗就是转场。

## 6. 声音

- 100 BPM，一拍 0.6 秒。开场锣鼓经：板鼓越打越密（8 下，间隔从 0.32 秒缩到 0.06 秒）→ 1.2 秒“仓”（大锣 + 钹）→ “才”（钹）→ 小锣。
- 旋律：自己合成的板胡（锯齿波 + 5.8Hz 揉弦 + 起音前 60ms 从低 6% 滑上来 + 1600Hz 带通），D 宫五声音阶，从 2.4 秒进，最后一个音是长 D。低音用 `pizz` 隔拍点根音。
- 节奏：梆子每拍一下（小节头重），大鼓每小节一下。
- 同步音效：撒网 `swish → whoosh`，落水自制 `splash`，鱼开口 `shimmer` + 小锣 + 钹，点头各一下板鼓，放生 `whoosh → splash`，跃起 `riser` + `chime`，鞠躬再来一次“仓”，收尾小锣 + 低一点的大锣。
- 锣是 6 个不成谐波的正弦分音（1、1.52、2.18、2.73、3.41、4.3 倍），大锣音高往下滑（×0.93），小锣往上滑（×1.12）。

## 7. 文字与标题

全片只有三处字：开场影子片名“渔夫与金鱼”（0.3–2.4 秒），和两个气泡“放我”“谢谢”。气泡字用红色，其余一律是影子的深褐色。不要加字幕条。

## 8. 踩过的坑

- **片名撞人**：片名原本放在 (640,190)、到 2.9 秒才消失，船划进来时斗笠正好顶进字里；后来改成 1.9–2.4 秒淡出，位置挪到 x=610，同时避开右上角的柳枝。
- **网兜挡脸**：拉网后手举得太高（大臂 -1.9），网兜和鱼全挂在渔夫脸前；改成手平伸（大臂 -1.5、小臂 -0.3），鱼挂在胸口高度，气泡往右挪。
- **捧鱼高过斗笠**：捧鱼姿势小臂角原来是 -0.55，鱼举到了头顶；改成 +0.2，鱼落在胸前。
- **“谢谢”气泡盖住跃起的鱼**，挪开后又钻进柳枝里；最后放到鱼的左边、气泡尾巴镜像指向鱼。
- **人偶太小**：第一版渔夫只占幕布高度三分之一，像远景；整个人偶层放大 1.2 倍。放大后操纵杆位置对不上，补了坐标变换 `Z()`。
- 调试时留了一行在 (0,0) 画空气泡的代码，左上角多出半个气泡——抽帧一眼就能看到。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部的时间表 `T` 和关节关键帧 `KF`；`score()` 里的音效时间直接引用 `T`。
2. 抽帧检查：`node _engine/render.cjs shadow-puppet stills 1.5,2.3,5.2,7.4,9.3,12.3,12.6,13,14.7`，再用 ffmpeg `tile=3x3` 拼成联系表看。
3. 出片：`node _engine/render.cjs shadow-puppet` → `demo.mp4` + `poster.jpg`（封面取 7.6 秒：鱼在网兜里说“放我”）。
4. 检查：时长 15.0 秒，响度约 -15.4 LUFS。

## 10. 引擎用法

- `sprite(x0, y0, w, h, fn)`：初始化时把一块皮子画进 2 倍超采样的离屏画布，原点就是关节；画完自动叠皮纹。
- `leather(g, 颜色, 线宽)` 填色 + 描边；`punch(g, fn)` 在里面打镂空；`flower / crescent / dot / slit` 是四种常用刀口。
- `put(g, 零件, x, y, 角度)`：按关节位置放零件；`rivet(g, x, y)` 画铆钉。
- `pose(t, F)`：由船的位置、身体前倾、头的角度和 `KF` 关节表算出肩、肘、手的世界坐标，网、鱼、操纵杆都挂在这些点上。
- 人偶层 `PL`（1920×1080）每帧先清空再画，最后用 `multiply` 画两遍（虚影 + 实影）叠到幕布上。
- 锣、钹、梆子、板鼓、板胡、水花都是 `X.*` 里自己合成的，在 `fn(w, B)` 里用 `B.sfx.context` 建节点，接到 `B.sfx / B.drum / B.lead` 总线。
