# 积木玩具 — 风格提示词（v1）

> 木桌上的塑料积木定格动画：凸点圆柱、倒角高光、半透明车窗，一块块从积木堆里飞过来“咔哒”吸附到位，画面按 12 帧 / 秒一格一格地走。
> 样片：《拼一辆小车》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **积木玩具** 风格讲一个“拼出来 → 用起来”的小故事。用户给你一个东西（车、火箭、房子、机器人），你把它拆成 8–12 块积木，按节拍一块块拼好，然后让它真的动起来，最后留一个俏皮的收尾。

---

## 1. 这个风格是什么

观众看到的是一张真实木桌上的玩具积木，被人逐帧摆拍。它的辨识度来自三样东西：**凸点**（每块积木顶上的小圆柱，带一道白色高光弧）、**塑料感**（顶面最亮、两个侧面明暗不同、外沿一圈倒角亮边、面上有一道淡淡的斜向光泽）、**定格顿挫**（所有运动按 12fps 量化，相机和灯光每格微抖）。积木是通用的，不出现任何商标，小人也不是官方人仔：方块头、方块身体、圆片帽子。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一块块拼** | 从底盘开始，先装轮子再装车身，最后装“点睛”的小件（车灯、尾翼）。每块落定一个“咔哒”。 |
| **小人是主角** | 小人在旁边每落一块就蹦一下；拼好后跳上车、挥手、说一句话。 |
| **动起来** | 拼好的东西必须真的用一次：车开走、火箭起飞、房子亮灯。 |
| **出点小意外** | 开过头掉下桌——但不能伤感：小人自己跳回来，帽子蹦一下。 |

**结构**：空桌 + 积木堆 + 小人（标题 1.9 秒）→ 底盘 → 4 个轮子 → 车尾、车头、座椅、车窗、2 个车灯、尾翼（每拍或半拍一块）→ 小人跳上车 → 发动抖动 + 气泡“出发！”→ 加速开向桌边，镜头跟拍 → 车头一沉翻出桌边 → 桌下“咚” → 小人跳回桌边，举手，帽子蹦起 → 淡出。

## 3. 视觉语言

- **投影**：真等距。一格（凸点间距）U = 60px，x 轴朝右下 `(51.96, 30)`，y 轴朝左下 `(−51.96, 30)`，z 向上 60px；视线方向 V = (1,1,1)，`x+y+z` 越大越靠前。
- **积木尺寸**（以格为单位）：砖高 1.2，薄板高 0.4；凸点半径 0.3、高 0.19；圆形 1×1 片半径 0.45。
- **光照**：光方向 L = (0.25, 0.55, 1) 归一化；面亮度 `0.5 + 0.55·max(0, n·L)` —— 顶面 ≈ 0.97、左侧面（+y）≈ 0.76、右侧面（+x）≈ 0.62。圆柱侧面按 18 段分别算，`n·L > .75` 的那一段额外 +0.25 当作高光。
- **塑料质感**：每个面叠一道对角线性渐变（白色 16% → 0，顶面）/ 10%（侧面）；顶面外沿画 1.4px 白色 50% 亮边，其余外沿画 1px 深棕 35% 暗缝；凸点顶面左侧一道 1.6px 白色 75% 弧线。
- **配色**：车身红 `#D8342B`、底盘灰 `#5B6168`、黑件 `#2A2D33`、车窗 `#9ED8F2`（透明度 .55，不画凸点）、车灯黄 `#FFD23F`、轮胎 `#26272B`、轮毂 `#C9CDD2`；积木堆黄 `#F3C623` / 蓝 `#3A7BD5` / 绿 `#43A047` / 白 `#F5F1E6` / 橙 `#FB8C00` / 紫 `#8E44AD`。小人：腿 `#34495E`、身体 `#2F80ED`、头 `#F4C58E`、帽子 `#E53935`。
- **桌面**：512px 木纹纹理（4 条木板、260 条正弦木纹、3 个木节），用 `transform(AX, AY, −AX, AY, OX, OY)` 仿射贴成等距菱形，1 格 = 16 纹理像素；左上暖光、右下压暗；桌沿厚 1.4 格 `#7A4B26`，边上一条 2px 暖白高光。桌外是 `#3A2B20 → #16100C` 的暗地板。
- **阴影**：零件在桌面上的投影 = 底面矩形向 +x 偏 `0.35 + 0.25·高度`，三层外扩 0.18 格叠出柔边，离地越高越淡。
- **字体**：站酷庆科黄油体（ZCOOL QingKe HuangYou），黄字 `#FFD23F` + 12px 深棕描边；气泡白底、4px 描边、红字 `#E53935`。

## 4. 动作语言

- **12fps**：`t = floor(t·12)/12`，所有位置都用量化后的时间；相机每格随机偏 ±0.6px，灯光亮度每格 ±1.75%。
- **飞入**：每块零件提前 0.5 秒从积木堆顶上起跳，`easeOut` 平移 + 5 格高的抛物线；最后 20% 停在目标上方 0.5 格，然后一格之内“吸附”到位——不做回弹，吸附本身就是动作。
- **落定**：两格（1/6 秒）的四道白色短线闪光；小人同时蹦 0.6 格。
- **发动**：车身每隔一格上下抖 0.06；小人挥手（手臂每 2 格换一次高度）。
- **开车**：匀加速 4.6 格 / 秒²，轮子按 `−距离 / 半径` 转三根辐条；重心过桌边后绕桌沿旋转（角度 = 9·t² + 1.2·t，最大 1.25 弧度），0.12 秒后开始自由落体。
- **收尾**：桌下“咚”时画面抖两格（±4px），小人从桌沿下 5 格处跳回来，举手，帽子弹起 1.2 格再落回。

## 5. 镜头语言

固定的等距俯视机位，像把相机架在桌边。唯一的镜头运动是出发后跟拍：从出发前 0.2 秒到翻出桌边后 0.4 秒，画面整体向左上平移 (330, 190)px（`ease`，同样按 12fps 走），把桌沿推到画面中间。

## 6. 声音

- 120 BPM。马林巴八分琶音 C – Am – F – G（高八度，弱拍 70%），拨弦贝斯（根音 / 五度 / 八度），从第 2 小节起加沙锤、边击和轻底鼓，最后一拍收在 C 和弦。
- 每块积木：起飞 `whip`，落定自建“咔哒”（1900Hz + 2600Hz 两下方波，间隔 28ms）+ `rim` + `tick`，再按顺序弹一个上行音阶音（C5 → G6）。
- 小人：开场两下 `boop`，起跳 `boing`，落座“咔哒 + thud”，欢呼时 `jump` + 马林巴琶音 + `chime`。
- 车：发动是 18Hz 颤动的锯齿波（55 → 70Hz，900Hz 低通），出发后升到 190Hz；翻车时一个 1400 → 260Hz 的下滑哨音；桌下 `thud` + 7 下渐弱的散落咔哒。

## 7. 文字与标题

只有两处：开场标题“拼一辆小车”（1.9 秒，从上面弹下来），和小人头旁的气泡“出发！”。其余全部靠动作讲。

## 8. 踩过的坑

- **画面太小**：最初 U = 40，车只占画面十分之一，积木质感看不清。改成 60，并把车放到画面中心。
- **桌边看不到**：放大后桌沿挤到右下角，“开出桌边”读不出来。加了出发后的跟拍平移。
- **手臂变成翅膀**：积木按 1×1 格子拆分时没处理小于 1 格的零件，0.4 格宽的手臂被画成整格，看起来像两片翅膀。改成每格取 `min(1, 剩余)`。
- **跳上车时头出画**：跳跃高度 3.5 格太高，降到 2.2。
- **气泡被裁**：气泡放在头顶正上方，车在画面上半部时出画；改到头的右侧，尾巴朝左指向小人。
- **音乐提前停**：配乐只写了 6 小节（12 秒），结尾 3 秒只有音效，补到 7 小节并加收尾和弦。
- 积木堆原位置在画面外，飞过来的零件像凭空出现，挪到画面左侧可见处。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部改时间常量（`T_PLATE`、`T_WHEEL`… 都是拍号 × `BEAT`）；零件在 `part(落地时刻, {x,y,z,w,d,h,col})` 里定义，`score()` 用同一组常量排咔哒声。
2. 抽帧检查：`node _engine/render.cjs brick-toy stills 0.5,2.2,4.3,6.8,7.3,8.4,9.8,10.8,11.3,11.7,13.1,14`
3. 出片：`node _engine/render.cjs brick-toy` → `demo.mp4` + `poster.jpg`（封面 8.4 秒：车拼好、小人说“出发！”）。

## 10. 引擎用法

- `P([x,y,z])`：等距投影（含跟拍平移和定格微抖）。
- `brick({x,y,z,w,d,h,col,alpha,studs,T})`：把一块积木拆成 1×1 格子加入绘制队列；只画积木外沿的面和边，顶面没被盖住才画凸点。`T = {f: 点变换, r: 法向变换}`，用于飞行中和翻车时的旋转。
- `cyl(底心, 轴向, 半径, 高, 颜色, T)`：通用圆柱（凸点、轮子、车灯、帽子），侧面分段打光 + 顶面高光弧。
- `items` 队列按 `x+y+z` 排序后统一绘制（飞行中的零件加 60 的偏置，永远画在最上层）。
- `flyT(落地时刻, 目标)`：从积木堆到目标的抛物线变换；`carT`：开车 + 翻出桌边的变换。
- `shadow(x0,y0,x1,y1,高度)`：桌面柔边投影。
