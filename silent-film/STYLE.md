# 1920s 默片 — 风格提示词（v1）

> 黑白画面整体泛棕，胶片划痕、尘点、闪烁、片门轻轻抖；动作略快、一顿一顿；圆形光圈开场和收场，中间插一张带花边的字幕卡；从头到尾一架酒吧钢琴伴奏，事件全靠钢琴“拟音”。适合复古喜剧、默剧小故事和怀旧品牌短片。
> 样片：《追帽记》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **1920s 默片** 风格拍一出一分钟以内的追逐小喜剧。用户给你一个人物和一个“丢了的东西”，你把它拍成：片名字幕卡 → 光圈打开 → 平静日常 → 意外（一阵风）→ 一句话字幕卡 → 快动作追逐（至少一次扑空）→ 出人意料的落点 → 一个体面的收尾动作 → 光圈收拢 → “剧终”。人物造型原创，不借用任何默片明星的标志性形象。

---

## 1. 这个风格是什么

观众看到的是一卷老胶片被放映出来：画面本身（公园、人、狗）用纯灰阶平涂，所有“年代感”都来自叠在上面的放映层——棕褐色调、每帧变化的亮度、竖向划痕、黑白尘点、片门抖动、圆角片框、粗颗粒。角色动作按每秒 16 帧取整，比 30 帧的视频更“跳”，配合略快的节奏，就是手摇摄影机欠速拍摄的效果。没有对白，一切靠肢体和字幕卡。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一件小物件** | 帽子、手帕、信——小到可以被风吹走、被狗叼走。 |
| **快动作追逐** | 背景横向卷动、人腿抡成风车、燕尾往后飘，中间一次飞扑扑空。 |
| **字幕卡** | 只在关键处插一张，一句话（“我的帽子！”），给观众半秒读完。 |
| **体面的收尾** | 绅士没有抢回帽子，而是对戴着帽子的狗鞠了一躬——礼貌就是笑点。 |

**结构（15 秒版，100 BPM，一拍 0.6 秒）**：片名卡“追帽记”0–1.8 秒 → 第 3 拍光圈打开，绅士从左边踱步进场 → 第 7 拍（4.2 秒）一阵风吹飞礼帽，绅士跳起、双手抱头 → 第 8–10 拍字幕卡“我的帽子！”（4.8–6.0 秒）→ 追逐：帽子在地上一路蹦，镜头跟着绅士卷动 → 第 13 拍（7.8 秒）飞扑扑空、趴地、爬起再追 → 第 16 拍（9.6 秒）帽子被风卷上天 → 第 19 拍（11.4 秒）落在路灯下一只小狗头上 → 喘气、伸手、犹豫 → 第 21 拍（12.6 秒）对狗鞠躬“脱帽”致意，狗点头、帽子滑到眼睛上 → 第 22 拍光圈收拢到狗身上 → 第 23 拍（13.8 秒）“剧终”→ 14.45–15 秒淡出。

## 3. 视觉语言

- **场景只用灰**：天空 `#C8C8C8 → #F0F0F0` 竖向渐变，远树 `#646464 / #565656`（0.5 倍视差），铁栅栏 `#2E2E2E`，小路 `#C9C9C9`，路灯和长椅近黑。人物：燕尾服 `#161616`、衬衫 `#E4E4E4`、条纹裤两腿 `#5C5C5C / #6E6E6E`、脸 `#E2E2E2`；狗白底 `#E6E6E6` 黑斑 `#2A2A2A`。
- **棕褐色**：整帧 `multiply` 一层 `#F2D8AE`（白变奶油、黑还是黑），再 `screen` 一层 `#17110A` 把纯黑抬成旧片的深棕。
- **闪烁**：每 1/24 秒取一个 hash，一半概率提亮（最多 7% 暖白）、一半概率压暗（最多 11% 黑）。
- **划痕**：最多 3 条竖线，每条持续 1/(2+k) 秒、在原位附近轻微摆动，宽 1.5–3px，亮痕或暗痕随机，长度不一定贯穿全屏。
- **尘点和毛发**：每帧 14 个候选点，过半出现，70% 是黑点、30% 是白点，半径 0.8–4.3px；18% 的帧出现一根弯曲的“毛”。
- **片门**：每帧抖 ±1.5 / ±2px，3% 的帧跳 8 / −10px；四周一个圆角 46px 的黑色片框（跟着抖一半）；暗角强度 0.75；颗粒 0.1。
- **字幕卡**：黑底 `#0E0E0E`；外框 980×540（4px）+ 内框 944×504（2px），四角卷草花饰，上下中点一枚菱形；米白字 `#E8E2D2`，站酷小薇体 ZCOOL XiaoWei，100–120px，字距 12–40px。
- **人物造型**：高瘦绅士——高礼帽、圆框眼镜、两头上翘的小胡子、长燕尾服、条纹裤、夹一把长柄伞，走路腰板笔直。（刻意避开圆顶礼帽、手杖、牙刷胡、大号鞋这些经典默片形象。）

## 4. 动作语言

- **欠速**：角色动作用 `ta = floor(t × 16) / 16`，一秒只动 16 次；胶片瑕疵按 24 帧/秒变化——两套节奏错开，更像真胶片。
- **踱步**：腿按正弦摆（幅度 0.42 弧度），手臂和伞反向摆。
- **惊吓**：原地跳起 40px、双手举过头、眼睛放大、嘴张成“O”，0.35 秒。
- **奔跑**：步频是踱步的 2.4 倍、腿摆 0.95 弧度、身体前倾 0.28 弧度、燕尾往后飘，身后三团尘土。
- **飞扑**：整个人绕脚尖转 1.4 弧度、抛物线抬高 70px、双臂前伸；落地后平躺 0.3 秒，身旁冒出撞击短线，再在 0.3 秒里弹回站姿。
- **帽子**：在地上一跳一跳（每秒 2.6 下，扑空那段跳得更高）同时旋转；最后一段被风卷起走 380px 高的弧线，旋转收住，稳稳落在狗头上并弹一下。
- **鞠躬**：上身绕胯前倾 0.8 弧度，另一只手在头顶做“脱帽”动作——虽然帽子不在自己头上。

## 5. 镜头语言

- **全景、平视、侧面走位**：人物永远在画面中下部横向移动，像舞台剧。
- **跟拍卷动**：追逐段镜头 x = 绅士 x − 470（限制在 0–2400），远树 0.5 倍、栅栏 0.9 倍视差。
- **圆形光圈**：开场以 (400, 420) 为圆心、0.6 秒从 0 张到 820；收场以狗为圆心、0.6 秒从 900 收到 0。光圈画在“镜头里”（在棕褐和瑕疵之前），所以黑色光圈上也有划痕和尘点。
- **硬切字幕卡**：字幕卡和画面之间直接切，不淡入淡出。

## 6. 声音

- **酒吧立式钢琴**：每个音两根三角波“弦”分别低 / 高 0.35%（走音的 honky-tonk 感）+ 2、3 次泛音，4 ms 起音后迅速回落再慢慢衰减，过 3.2 kHz 低通。
- **Ragtime**：左手每半小节“嗵（低音）…嚓（和弦）”，和弦进行 C – C – F – C – G7 – C – A7 – D7 – G7 – C；右手按十六分音符网格写的切分旋律，重音落在反拍。字幕卡期间钢琴不停（默片伴奏从不停）。
- **钢琴拟音**（这个风格的灵魂）：一阵风 = 14 个音、35 ms 间隔的上行音阶；帽子每蹦一下 = 一个高音断奏；飞扑落地 = 低音区五个相邻键一起砸下；帽子飞上天 = 高音颤音；落到狗头 = C 大调和弦 + 上行琶音；鞠躬 = F → G7 的慢收束；剧终 = 大 C 和弦 + 三个下行音。在这些时刻旋律让开。
- **放映机**：带通噪声（2.6 kHz）被 24 Hz 方波调制出“嗒嗒嗒”，底下一层 48 Hz 锯齿波低通嗡声，再随机撒 60 个爆豆声。

## 7. 文字与标题

全片三张字幕卡：片名“追帽记”、台词“我的帽子！”、“剧终”。字少、字大、居中，每张至少停 1.2 秒。画面里不出现任何其他文字。

## 8. 踩过的坑

- **整片一片黑**：片框蒙版写成 `rect(整屏) + F.rrect(圆角框)` 再 `fill('evenodd')`，但引擎的 `F.rrect` 自己会先 `beginPath()`，把整屏矩形清掉了，结果只填了圆角框——整个画面被涂黑。改用原生 `ctx.roundRect()`。
- **“伸手”变成了“举伞”**：手臂角度约定是正值朝前（人物面朝右），伸手时写了负角度，手臂往后上方抬，伞被举了起来。改用另一只手、正角度向前伸。
- **站着时两条腿并成一根**：停步时腿摆幅为 0，两条腿完全重叠，像踩高跷。给两腿各加 ±0.09 弧度的固定分开。
- **灰蒙蒙没对比**：树太浅、黑位抬得太高、颗粒太重，整体一片灰棕。树压暗一档，`screen` 抬黑从 `#231A10` 降到 `#17110A`，颗粒从 0.14 降到 0.1。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部按拍定义 `T_IRIS_IN / T_GUST / T_CARD2 / T_CHASE / T_DIVE / T_LIFT / T_LAND / T_BOW / T_IRIS_OUT / T_END`；追逐段的世界坐标写在 `GENT_X`、`HAT_X` 两张关键帧表里，镜头自动跟随。
2. 抽帧：`node _engine/render.cjs silent-film stills 1,2.3,3.4,4.35,5.4,6.8,7.95,8.3,9.9,11.6,12.9,13.6`，拼 3×4 联系表。
3. 出片：`node _engine/render.cjs silent-film`。封面取 12.3 秒：绅士伸手、戴着礼帽的狗坐在路灯下。
4. 验收：时长 15.0，响度约 −16.4 LUFS。

## 10. 引擎用法

- `card([[文字, y, 字号, 字距]])`：带花边的字幕卡。
- `gent(x, 脚底 y, {phase, amp, lean, rot, bow, armA, armB, hat, surprise, flap, umbrella})`：绅士骨架，腿和手臂都是“角度 → 两段线”，`rot` 让整个人绕脚尖转（飞扑、趴下）。
- `drawHat(x, y, 旋转, 缩放)`、`dog(x, y, 看向, 摇尾相位, 点头)`。
- `kf(表, t)`：分段线性插值，用来排追逐的世界坐标。
- `iris(圆心 x, 圆心 y, 半径)`：`evenodd` 挖洞的光圈。
- 放映层：`multiply` 棕褐 → `screen` 抬黑 → 闪烁 → 划痕 → 尘点 → 暗角 → 圆角片框 → `F.grain`，全部用 `F.hash(帧号)` 取随机，逐帧导出结果可复现。
- `score()` 里的 `piano(w, B, 音高, 力度, 时长)`、`chord()`、`projector()`。
