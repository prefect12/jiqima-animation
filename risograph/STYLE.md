# Risograph 孔版印刷 — 风格提示词（v1）

> 荧光粉、蓝、黄三种油墨一版一版叠印在米白纸上，重叠处用正片叠底混出橙红、绿、靛紫；每版都有几像素的套色错位、针孔漏墨和 45° 网点。适合生活小品、市集 / 活动海报、独立杂志感的品牌短片。
> 样片：《周末早市》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **Risograph 孔版印刷** 风格做一支“边印边看”的短片。用户给你一个主题，你把它拆成 3–5 张“印张”，每张只画一样东西；每张纸都按 黄 → 粉 → 蓝 的顺序一版一版印出来，最后一张把前面的东西拼成一张小海报。

---

## 1. 这个风格是什么

孔版印刷机一次只印一种颜色，多色画面要换油墨鼓一版一版叠上去。它的可爱之处全在“不完美”：油墨是半透明的，两色重叠会变出第三种颜色；每一版都对不太准，边缘露出一两像素的彩色毛边；大色块里有没吃上墨的小白点；浅色调只能靠网点表现。观众看到的是“一张纸正在被印出来”，所以**印刷过程本身就是动画**。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一版一版显影** | 同一张图先出黄版（底色、高光），再出粉版（主体），最后蓝版（阴影、叶子、文字），观众每一拍都看到颜色“混”出来。 |
| **叠色变色** | 番茄 = 黄 + 粉，叶子 = 黄 + 蓝，鱼鳍 = 粉 + 蓝。设计时先想“哪两版要重叠”，而不是直接选颜色。 |
| **换纸** | 一张印完就被传送带送走，下一张白纸从右边进来，一小节一张。 |
| **盖章标签** | 每张的最后一拍“啪”地盖一个标签（名字 / 价签），告诉观众这张是什么。 |
| **合订收尾** | 最后一张把前面每样东西缩小进三个方框，加大标题，像一张活动传单。 |
| **套色抖动** | 高潮时三版油墨各自晃一下再落回原位，暴露“这是叠出来的”。 |

**结构（80 BPM，一小节 = 3 秒 = 一张纸）**：标题张（遮阳棚 + 太阳 + 大标题）→ 番茄 → 鱼 → 花 → 合订海报（半拍一版，快速印完）→ 两次套色抖动 → 淡出到纸色。
选题：日常、市集、食物、植物、小动物这种“能用 2–3 个色块概括”的东西最合适；复杂场景、写实人物不合适。

## 3. 视觉语言

- **油墨**（全部 `multiply` 叠在纸上）：黄 `#FFE800`、荧光粉 `#FF48B0`、蓝 `#0078BF`。叠色结果约为：粉×黄 = 橙红 `#FF4100`，蓝×黄 = 绿 `#006D00`，粉×蓝 = 靛紫 `#002284`。不要加第四种墨，也不要用纯黑。
- **纸**：米白 `#F4EFE4`，叠一层随机短纤维纹理（320px 平铺，初始化时生成）；纸下面是灰色传送台 `#C9C1B1`，每 6px 一道 2px 暗纹；纸边有 18px 投影。
- **套色错位**：黄版为基准不动，粉、蓝两版各自固定偏移 x ±4px、y ±3px（按张号用 `hash()` 取，每帧一样）。
- **漏墨**：每版上色前先用两张纹理“挖洞”——① 2×2px 的针孔，5% 全透、9% 半透；② 64×36 的低频斑块拉伸到整张（1.1 倍），以 55% 强度削淡，造成墨色不匀。两张纹理在每版上都换一个偏移，保证三版的瑕疵不重合。
- **网点**：45° 网屏，网格 7px（图块 14px 放两颗点，按设备像素生成保证锐利），点半径 = 图块/2 × √(2×覆盖率/π)；常用覆盖率 .1 / .28 / .34 / .42 / .5 / .7。鱼身的明暗渐变用手摆的网点：网格 9px，覆盖率从背上的 .92 线性降到腹部的 .17。
- **形状**：只用平涂色块和网点，不描边；线条（茎、鱼鳞、蝴蝶结）线宽 3–8px、圆头。
- **字体**：站酷庆科黄油体（ZCOOL QingKe HuangYou）。大标题 184px，合订海报标题 112px，标签字 58px，副标题 40px（在蓝色色带里反白挖空）。
- **角线**：四角各一个套准十字（半径 10、线宽 2），三种墨都印一遍，错位一眼可见。

## 4. 动作语言

- **一版 = 一拍**：每版用一道刮板从左往右扫过（0.42 秒，`easeOut`），刮板是 16px 深灰条 + 5px 当前墨色条 + 一道高光，身后拖 90px、35% 的湿墨渐变。
- **换纸**：旧纸向左、新纸从右同时平移（0.4 秒，`ease`），两纸之间露出 40px 传送台。
- **盖章**：标签从 1.5 倍缩回 1 倍，`back` 缓动 0.16 秒，略转 -0.06 弧度。
- **套色抖动**：粉 / 蓝 / 黄版分别以 [7, −9, 11]px（x）和 [−4, 6, 3]px（y）为幅度做衰减正弦（频率 38 rad/s，衰减系数 9，持续 0.45 秒），然后回到原来的错位。
- 画面里没有别的运动：印刷品就该是静的，动的只有“印”这件事。

## 5. 镜头语言

固定机位，正对纸面，纸张铺满画面。不推不摇，镜头语言靠“换纸”完成。最后一张合订海报用三个等宽方框（360×356，圆角 18）并排，内容缩到 0.46 倍。

## 6. 声音

- 配乐：Lo-fi，80 BPM，摇摆 16%。电钢琴（`keys`）每小节一个长和弦（Fmaj7 → Em7 → Dm7 → Cmaj7），第 2.5 拍补一个高八度的短和弦；鼓从第二小节进：底鼓 0 / 1.5 / 2.75 拍，军鼓 2、4 拍（0.45），八分踩镲；贝斯根音 + 五度 + 八度；全程 110 个随机黑胶噼啪声；第 2、4 小节各一句拨弦旋律。
- 每一版印刷 = 一个“油墨鼓”声：带通噪声 500→2400Hz 扫 0.42 秒（刮板）+ `thud`（0.45）+ 1300Hz 短噪声“咔” + 结束时一下 `click`。
- 盖章：`thud` + `pop`（音高随张数升）。换纸：`paper` + 轻 `whoosh`。套色抖动：`boing` + `marimba`。合订开印：`shimmer`；结尾：两下自行车铃（`bell` 91）+ C 大七和弦。

## 7. 文字与标题

整片只有 7 个词：标题“周末早市”、副标题“星期六 · 早上七点半”、三个标签“番茄 / 鱼 / 花”、合订页的“番茄 · 鱼 · 花”。标签一律 1–2 个字，印在蓝版里；大标题印在粉版里、压在黄色太阳上，让一半字变橙红。

## 8. 踩过的坑

- 副标题一开始糊成一排带网点的方块：上一句 `dots()` 把 `fillStyle` 设成了网点图案，写字时没改回来。现在每次写字前都重设 `#000`，副标题改成在实心蓝带里挖空。
- 太阳的放射纹一直伸到副标题上，两者撞在一起：太阳上移到 y=386、半径 180，放射纹收到 204–252，并整体转半格；副标题挪进底部蓝带。
- 鱼的背鳍和腹鳍是“飘”在身体外面的三角形，粉版和蓝版之间有一条缝：把鳍的多边形伸进鱼身，让重叠处混出紫色，鳍就“长”在身上了。
- 在蓝版里先画了鱼身网点又挖掉再画一遍（重复绘制），网点密度会翻倍；改成先画冰块、再挖掉鱼的轮廓、最后画一次鱼身。
- 每张纸开印前会有约 0.1 秒白纸：这是故意的（纸刚送到），但不要超过半拍，否则像“空白太久”。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 里给每张纸写一个函数 `(g, L)`，`L` 是 `'y' | 'p' | 'b'`，在同一个函数里分三段画三版；时间由 `passT(k, i)` / `stampT(k)` 统一给出。
2. 抽帧检查：`node _engine/render.cjs risograph stills 0.3,1.2,2.6,3.5,5.0,7.0,10.0,12.4,13.6`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "risograph/stills/*.jpg" -vf "scale=640:360,tile=3x3:padding=6:color=white" -frames:v 1 /tmp/riso.jpg`
4. 出片：`node _engine/render.cjs risograph` → `demo.mp4` + `poster.jpg`（封面 13.2 秒，合订海报印完、抖动之前）。

## 10. 引擎用法

- `layer(name)`：取一张与画布同尺寸的离屏层，先清空，再设好缩放，返回上下文；一版墨用一层。
- `dots(g, 覆盖率, 网格=7)`：返回 45° 网点图案（按设备像素缓存）。
- `hdots(g, x0, y0, x1, y1, 网格, tone(x, y))`：按函数摆网点，做渐变。
- `inkDown(c, name, 颜色, dx, dy, 种子)`：挖针孔 + 斑块 → `source-in` 上色 → `multiply` 叠到画面，dx / dy 就是套色错位。
- `reg(g)`：四角套准十字；`tag(g, 文字, x, y, 进度)`：盖章标签。
- `SHEETS[k](g, L)`：四张纸 + 合订页的内容函数；`passT(k, i)`、`stampT(k)`、`JIG` 是画面和配乐共用的时间表。
