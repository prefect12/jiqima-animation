# 低多边形 — 风格提示词（v1）

> 一片三角面片组成的海，每个面片随波起伏、各自平涂明暗；一座小岛由 50 块三角形一块块从海里浮上来，然后长出树、盖起房子，天色从白天转到黄昏，最后亮起一盏灯。
> 样片：《一座岛》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **低多边形** 风格讲一个“世界一块块被搭起来”的安静故事。用户给你一个场景（岛、森林、村子、星球），你把它拆成三角面片，按音乐一块块升起来，再放上几个简单几何体（棱锥树、盒子房子），最后用光（灯、日落、篝火）收尾。

---

## 1. 这个风格是什么

每个面都是一个平面三角形，每个三角形只有一个颜色——颜色由“面的法线 · 光的方向”决定。没有纹理、没有渐变、没有描边线，立体感完全靠相邻面片的明暗差。它看起来像模型、像游戏，又很安静，适合世界观、放松内容、游戏预告。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一块块长出来** | 地形面片按离中心的距离依次升起，从海里浮上来、放大、落定时闪一下亮。 |
| **几何体道具** | 树 = 两层五棱锥 + 方树干；房子 = 盒子 + 两片坡屋顶；路灯 = 细盒子 + 灯箱 + 四棱锥灯罩。 |
| **天色变化** | 同一个场景白天 → 黄昏，所有面片的颜色跟着光变，不用换任何模型。 |
| **最后一个光源** | 天暗下来时亮起一盏灯，是天然的结尾。 |

**结构**：只有海（1.4 秒，确立“海也是三角面”）→ 岛的 50 块面片按 32 分音符依次浮出（约 4.5 秒）→ 6 棵树每半拍弹出一棵 → 房子墙升起、屋顶落下、烟囱、路灯 → 天色转黄昏 → 灯亮（光晕 + 窗户变暖黄）→ 片名“一座岛” → 淡出。

## 3. 视觉语言

- **海**：34×34 格、每格 3.4 米，顶点横向随机偏 ±0.7 米（初始化时一次），每格切两个三角，对角线方向交替；外圈再铺一圈 13.6 米的大格子一直铺进雾里。波浪 = 三组正弦叠加（振幅 0.32 / 0.22 / 0.12）。海色在深 `rgb(34,118,150)` 和浅 `rgb(70,178,196)` 之间按顶点高度和受光插值，加一点 60 次方的太阳镜面高光；黄昏时变成 `rgb(40,70,110) / rgb(120,110,150)`。
- **岛**：三角点阵，点距 2.7 米，随机偏 ±0.45 米；高度 `3.8·(1 − r/R)^1.3`（R = 8），外圈压到水下 −0.4。颜色：沙 `#E9D8A6`（面中心 < 0.35 米）、岩 `#9A8F85`（坡陡或 > 2.45 米）、草 `#7FB069 / #6FA05C` 交替。
- **道具色**：树 `#3E8E5E / #4E9F6A / #5DB077`，树干 `#7A5230`；墙 `#F2E8CF`，屋顶 `#C8553D / #B04A36`，山墙 `#E9DCC0`，门 `#8A5A3B`，窗 `#5B7083`（亮灯后 `#FFD27A`）；路灯杆 `#3D405B`，灯箱亮起 `#FFE9A8`。
- **光照**：每个面 `颜色 × (环境光 + 0.78·max(0, n·L)·太阳色)`；环境光白天 (0.46, 0.5, 0.56)、黄昏 (0.34, 0.3, 0.42)；太阳色从 `rgb(255,248,232)` 变到 `rgb(255,176,120)`，太阳高度角 0.62 → 0.1 弧度。
- **雾**：面片到相机的距离从 22 米开始混入雾色，到 132 米混满（上限 96%）；海平线以下先整块铺雾色，所以远处的接缝看不出来。
- **天空**：顶部 `rgb(96,170,222)` → 地平线 `rgb(214,236,240)`，黄昏变 `rgb(44,42,104)` → `rgb(246,150,112)`。太阳是六边形 + 半透明大六边形光圈；三朵多边形云慢慢飘。
- **缝**：每个三角形用同色 0.8px 描边，盖住相邻面片之间的抗锯齿白缝。
- **字体**：站酷小薇体（ZCOOL XiaoWei），片名 64px 暖白 `#FFF4E0` + 3px 阴影。

## 4. 动作语言

- **面片升起**：每块 0.42 秒——以自己的中心 `back` 放大（0 → 1，带一点过冲），同时从水下 1.6 米 `easeOut` 浮上来；落定前后 0.3 秒提亮 35% 再退回。面片在水线（z = 0）处实时裁开，所以看起来是“从水里冒出来”，不会浮在水面上。
- **顺序**：按离岛中心的距离排序，再加一点随机，一圈一圈往外长。
- **道具**：树 0.45 秒 `back` 整体放大；墙 0.5 秒从地里升起；屋顶从 3 米高处 0.45 秒落下；路灯杆 0.4 秒 `back` 长高。
- **灯亮**：0.15 秒亮起，其间闪两下（像通电）。

## 5. 镜头语言

一个缓慢的环绕：15 秒内绕岛转约 52°（偏航 −0.62 → 0.28 弧度），距离 25 → 17.5 米，高度 7 → 5 米，全程 `ease`。视线略高于地平线三分之一处，天空留足位置给黄昏。不切镜头。

## 6. 声音

- 84 BPM。温柔的锯齿 pad（过 1000Hz 低通）Cmaj7 – Am7 – Fmaj7 – G6，一小节一个和弦，下面垫次低音；每半小节一次低通噪声“海浪”涨落。
- **每块面片升起一个铃音**（`bell`，五声音阶 C D E G A 循环，前 1/3 在 C5 一带、中段高八度、后段回落），32 分音符的密度听起来像一串闪光。
- 树：每棵一个八音盒音（G4 → C6）+ `pop2`；墙：低铃 + 轻 `whoosh`；屋顶落定 `thud` + 铃；路灯 八音盒一声。
- 灯亮：`click` → `chime` + `shimmer` + 四个上行铃音 + 一个长 pad 和弦。

## 7. 文字与标题

全片只有灯亮后 0.6 秒淡入的片名“一座岛”，放在画面上方正中。

## 8. 踩过的坑

- **岛边缘像海星**：外圈顶点原来沉到水下 −0.9，形成一圈又陡又长的尖三角，岸线像锯齿王冠。改成 −0.4 并换成更平缓的高度曲线，岸边变成沙滩斜坡。
- **岛面片“漂”在海上**：海和岛混在一起按深度排序时，水下的面片会画到水面上面，还出现海面被挖空的洞。改成三层（海 → 地形 → 道具），并把地形面片在 z = 0 处裁开，只留水面以上的部分。
- **地形盖住房子**：大三角形的中心比房子离相机更近，被画在房子前面，墙上出现一条绿色斜坡。道具单独一层画在地形之后。
- **海平线是一条平的色带**：海面网格太小，远处露出一整条雾色平台。外面加一圈大格子铺进雾里，雾的距离拉长到 110 米。
- **太阳出画**、灯的光晕太大太白：太阳位置改为地平线上 120px，光晕半径 150 → 105、透明度 .55 → .45。
- 面片落定的闪光一开始提亮 55%，像一片片冰，降到 35%。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部改时间常量（`T_ISL`、`STEP`、`T_TREE`、`T_WALL`、`T_ROOF`、`T_POST`、`T_LAMP`、`T_DUSK`，都以 `BEAT` 为单位）；岛的形状在初始化块里（`R`、`SP`、高度公式）。`score()` 直接遍历 `ISL` 的 `t0` 排铃音。
2. 抽帧检查：`node _engine/render.cjs lowpoly stills 1.2,3.2,5,6.8,8.2,9.8,11.2,12.4,14`
3. 出片：`node _engine/render.cjs lowpoly` → `demo.mp4` + `poster.jpg`（封面 13.2 秒：黄昏、灯亮）。

## 10. 引擎用法

- `P([x,y,z])`：环绕相机的透视投影。
- `push(三个顶点, 颜色, {n, flash, glow, land})`：投影一个三角形并放进对应的层（海 / 地形 / 道具）；`tri_n()` 算法线（统一朝上）。
- `clipZ(三角)`：在水线处裁三角，返回 0–2 个三角形。
- `cone()` / `boxT()` / `quad()`：棱锥、盒子（带背面剔除）、四边形 → 三角面片。
- 绘制：三层各自按深度从远到近排序，逐个 `fill` + 同色 `stroke`；颜色在绘制时按法线、光、天色、雾统一计算，所以天色变化自动影响所有面。
