# 80 年代赛璐璐 — 风格提示词（v1）

> 雨夜的天台，城市还没醒。少女把挂在脖子上的橙色耳机戴上，“咔”的一声音乐进来，对面的楼一拍亮一栋，粉、青、琥珀、紫，霓虹招牌闪着点亮，镜头光晕扫过画面。平涂 + 一层硬阴影 + 深紫线稿，老动画 MV 的味道。
> 样片：《雨夜天台》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **80 年代赛璐璐** 风格拍一段音乐 MV 式的短片。用户给你一个情绪或一首歌的意境，你用“远景建立 → 特写一个小动作 → 远景让世界回应 → 特写收在表情上”四个镜头讲完，世界的变化全部踩在拍子上。

---

## 1. 这个风格是什么

八十年代日本动画和 city-pop 唱片封面的质感：角色是赛璐璐片——颜色平涂，每种材质只有“亮面 + 一层硬边阴影”两档，线稿是深紫色而不是纯黑；背景是手绘的，可以有柔和渐变；夜景里全是霓虹色和泛光，镜头会有横向拉丝光晕和六边形鬼影。它靠“剪辑”讲故事：硬切镜头、远近交替，而不是一镜到底。角色是原创的短发少女，不借任何已有作品的人物。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **远景 + 背影** | 天台、栏杆、湿地面、远处楼群，少女只是一个小小的背影——先给情绪。 |
| **特写一个动作** | 双手把耳机举上来扣到耳朵上，眼睛随之睁大，眼里反射的霓虹随拍换色。 |
| **声音开关** | 戴上耳机前只有雨声和闷闷的 pad，扣上的那一拍鼓和贝斯一起进来。 |
| **世界回应拍子** | 十栋楼每拍亮一栋（窗户从下往上逐排亮），两块霓虹招牌闪烁点亮，最后一拍全城闪一下。 |
| **表情收尾** | 闭眼微笑、轻轻点头，背景是满屏虚焦光斑，片名淡入。 |

**结构（96 BPM，一拍 0.625 秒）**：远景，雨，城市稀疏几盏灯（0–3.75）→ 硬切特写，耳机从画外举上来（3.9–4.9），5.0 扣上 → 硬切远景（6.25），十栋楼按 6.25 + n × 0.625 依次亮，招牌 7.5 / 10.0 点亮，光晕 8.75 起变强，11.25 全城一闪 → 硬切特写（12.5），片名（13.0）→ 淡出（14.5）。

## 3. 视觉语言

- **线稿**：深紫 `#2A1840`，角色外轮廓 3–3.5px，细节 2–2.5px，圆角圆头。
- **霓虹四色**：粉 `#FF4FA3`、青 `#3FE0FF`、琥珀 `#FFC857`、紫 `#B07CFF`；窗户偶尔夹一盏暖白 `#FFF3E0`。
- **夜空**：`#07061A → #1E1242 → #5A1E5C`（地平线发品红）。远处楼群 `#2A1F55` 剪影；中景楼 `#17123A`，右侧一条 12px 的 `#231B4F` 硬阴影面，楼顶一条深色檐口；未亮窗户 `#241D4A`（11×14，间距 20×24），亮窗下 5px 压一层 25% 黑，像窗帘。
- **角色（一层硬阴影）**：头发 `#2B2350` / 阴影 `#1A1538` / “天使光圈”高光 `#6B5BB5`；外套 `#2F8C9A` / `#1C566A`；裙子 `#3B2B63` / `#261B45`；皮肤 `#F2C4C0` / `#B77FA8`（夜里偏粉紫）；耳机 `#FF7A3D` / `#C9502A`，耳垫 `#3A2A55`。眼睛：虹膜 `#4A2A7A`，下半硬边亮一档 `#B05AC8`，瞳孔 `#1E0F36`，两颗白高光。腮红用 4 道斜排线 `#E26A8E`。
- **轮廓光**：面向城市的一侧（脸前沿、刘海边、外套右边、头发右边）用一道硬边青色 `#3FE0FF`，这是“霓虹打在人身上”的关键。
- **地面**：`#120E26`，亮了的楼在地面拉出 7 条细长竖向倒影（2–6px 宽、60–190px 长，颜色 → 透明），再用 16 条暗色波纹线横切碎；三个水洼 + 不断扩散的雨滴涟漪。
- **雨**：两层斜线。远层 120 根、1.1px、34px 长、1100px/s；近层 60 根、2px、70px 长、1700px/s，都向左斜 18%。
- **泛光**（只在远景）：把整帧缩到 480×270 的离屏画布，用 `brightness(.7) contrast(3.2)` 只留下亮灯，再 `blur(10px)` 以 55% `lighter` 叠回来。
- **镜头光晕**：光源处 220px 径向亮斑（白 → 粉 → 透明），一条横贯 1400px、5px 高的青色拉丝，沿光源到画面中心的连线放 5 个六边形鬼影（22% 透明度，粉 / 青 / 紫 / 琥珀 / 青）。
- **字体**：片名 Noto Serif SC 700 64px + 粉色外发光；英文小字 Monoton 22px 青色；招牌字 Noto Serif SC 700 40px，点亮后白字 + 同色外发光。
- **收尾**：颗粒 0.06，暗角 0.5（`10,5,25`）。

## 4. 动作语言

- **戴耳机**：耳机和手一起从画外 330px 处 `easeOut` 举上来（1 秒），扣上前停一下，5.0 扣上时耳机压扁 6% 再弹回，手在 0.45 秒内 `easeIn` 放下。眼睛同时从半睁（0.55）在 0.15 秒内睁满。
- **点头**：扣上之后，头和身体每拍按 `|sin(π·拍)|³` 上下 5–6px，头轻微转 ±0.04 弧度。
- **头发**：发梢、刘海尖用 `sin(t·2.4 + k)` 做 2–3px 的飘动；裙摆随 `sin(t·2.2)` 摆 3px。
- **亮灯**：每栋楼的窗户从下往上逐排亮，整栋在 0.28 秒内亮完；约 68% 的窗户会亮，10% 的窗户开场就亮着。
- **招牌**：点亮后 0.5 秒内 20Hz 随机闪烁，然后常亮。
- **全城一闪**：11.25 秒远处楼群的灯全部亮起，按 `exp(−3·Δt)` 衰减。

## 5. 镜头语言

- 四个镜头、三个硬切（3.75 / 6.25 / 12.5），切点都在拍点上。
- 远景一：1.0 倍，缓慢横移 40px。远景二：从 1.14 倍推到 1.24 倍，同时反向横移，少女更大、更靠前。
- 特写：头部放大 1.35 倍，侧脸朝向画面左边（朝着城市），背景是虚焦光斑（34 个，18–68px），戴上耳机后光斑逐拍亮起。
- 光晕位置：第一个远景在右上角很弱（25%），第二个远景从 8.75 秒开始增强，全城一闪时冲到最亮；特写里光晕在左上角，随拍脉动。

## 6. 声音

- city-pop / synthwave，96 BPM，“王道进行” Fmaj7 – G7 – Em7 – Am7。
- 雨声：自己用 `B.sfx.context` 建一段循环白噪声，高通 900Hz + 低通 7000Hz，全片持续；戴上耳机后音量减半，让位给音乐。
- 戴上前：只有两段轻 pad（本身走 1000Hz 低通，听起来闷）。5.0 扣上：`click` + `pop`，同时进来八分音符八度跳的合成贝斯、四拍底鼓 + 反拍 hi-hat、2、4 拍军鼓 + 拍手 + 一段送进混响的噪声尾巴（大混响军鼓）。
- 每亮一栋楼 = 一声钟（`bell`），十栋楼连起来是一段琶音；招牌点亮 `shimmer` + 四个 `tick`。
- 8.75 秒进合成器主旋律；全城一闪前 `riser`，一闪时 `impact` + `chime`；切到最后特写 `whoosh` + 长和弦，片名 `shimmer`。

## 7. 文字与标题

- 片中文字只有招牌（“咖啡”“唱片”，竖排两字）和最后的片名（“雨夜天台” + 小字 NEON RAIN）。
- 片名放左下角，给右边的人物留空；像 MV 的曲名条，不要做成大字报。

## 8. 踩过的坑

- 耳机头梁第一版用一段圆弧，圆心算错，头梁从耳罩外侧翘起来悬在头顶上方，像一个问号钩子；改成一条贴着头顶的贝塞尔曲线，并且画在刘海之前，让末端被刘海盖住。
- 上一条修完后，扣上后的样子是对的，但举耳机那约 1 秒里头梁只有近侧半截，末端悬在空中，又读成问号钩子（戴上后末端靠刘海盖住，举起时没东西盖）。解法：补上远侧耳罩和整条头梁，两个耳罩 + 头梁共用一个变换 `hp()`（平移 `hy` + 随举起回正的轻微倾斜 + 扣上时的挤压），任何时刻头梁两端都连着耳罩；头梁在头顶正中一分为二，远侧半边 + 远侧耳罩画在后脑头发之前（戴上后被头和脸挡住，只在头顶露出弧线），近侧半边照旧画在刘海之前。整个过程图层顺序不变，所以扣上那一下不会跳。两段都用平头线帽，近侧半边沿远侧曲线多走一小段，盖住接缝和后脑头发的收口线。
- 举耳机的手第一版只是一块竖长条，看起来像一条白带子；改成袖口 + 前臂 + 手掌 + 四根扣在耳罩前沿的手指。
- 全屏泛光把特写里的皮肤也冲成了白色；泛光只在远景做，皮肤颜色同时压暗到 `#F2C4C0`。
- 地面倒影第一版是整块半透明色块，像一排木箱；改成细竖条 + 波纹线横切。
- 楼亮起时整栋叠一层颜色闪一下，结果读成一块灰黄色的空白矩形；删掉，只保留窗户从下往上的逐排点亮。
- 招牌一开始写“喫茶”，“喫”是不常用的异体字，换成“咖啡”。

## 9. 制作流程（本仓库）

1. 在顶部定切点（`CUT1`、`ON`、`CUT2`、`CUT3`）、十栋楼的几何 `BLD` 和亮灯顺序 `ORDER`；`LIGHT(g)` 同时给画面和配乐用。
2. 抽帧：`node _engine/render.cjs cel-anime stills 1.5,4.4,5.6,7.0,9.0,10.6,11.6,13.0,14.2`
3. 出片：`node _engine/render.cjs cel-anime`

## 10. 引擎用法

- `wide(横移, 缩放, 第几个远景)`：天空 → 远景楼 → 中景楼（亮灯）→ 招牌 → 地面倒影 → 栏杆 → 少女背影 → 泛光 → 雨 → 光晕。
- `closeUp(是否收尾)`：虚焦光斑 → 雨 → `face()` 侧脸特写（用朝右的坐标画，再 `scale(−1.35, 1.35)` 翻转）。
- `girlBack(x, y, 是否戴着耳机)`：背影，第一个远景耳机挂在脖子上，第二个远景戴在头上。
- `sign(x, y, 两个字, 颜色, 点亮时刻)`、`rain(强度)`、`flare(x, y, 强度)`。
- 泛光用的离屏画布 `bloom` 每帧先 `clearRect` 再画。
