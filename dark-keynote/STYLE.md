# 暗色科技发布 — 风格提示词（v1）

> 纯黑舞台上几条发光的渐变光带缓缓流动，毛玻璃卡片浮在光带前面，一个大号数字砸出来，一次撞击之后产品登场。镜头始终在慢慢往前推，像发布会大屏上的开场片。
> 样片：《拾页》（虚构笔记 App，15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **暗色科技发布** 风格给一个产品做发布片。用户给你一个产品和它解决的问题，你把它压成“一句痛点 → 一个大数字 → 一个动作把问题收拢 → 产品亮相 → 三个数据 → 名字和口号”六拍，每一拍都卡在小节线上。

---

## 1. 这个风格是什么

大公司发布会开场片的那种“贵”感：黑、静、慢，只有光在动。信息密度很低，一屏只说一件事，用字号和光来制造分量。它的质感来自三样东西：会呼吸的渐变光带、透出背后光带的毛玻璃、带发光的超大数字。产品名是自拟的虚构产品（“拾页”），不模仿任何真实品牌的发布会。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **散落 → 收拢** | 很多毛玻璃小卡片散在不同深度，一个光标点一下，卡片逐张飞进光标下面叠成一摞——“把乱的东西收好”。 |
| **大号数字** | 一个会滚动计数的数字（2,847）+ 一行小字，把痛点量化。 |
| **撞击变形** | 叠好的卡片在一次低频撞击 + 闪白里变成产品（一本玻璃书）。 |
| **数据卡** | 三张横向玻璃卡，每张一个大数字 + 单位 + 一句说明，依次滑上来。 |
| **名字收尾** | 黑场中央：标志 + 名字 + 一句口号 + 角落一行“概念演示 · 虚构产品”。 |

**结构（96 BPM，每小节 2.5 秒）**：一句话“每天，你都写下很多想法。”+ 卡片逐张浮现（0–2.5）→ 大数字 2,847 滚动（2.5–5.0）→ 光标入场、点击（5.625），8 张卡每 1/16 音符飞一张（5.94–7.43）→ 7.5 撞击，书出现 → 名字（8.125）、口号（8.75）→ 书左移，三张数据卡（10.0 / 10.31 / 10.63）→ 12.5 撞击，片尾 → 14.5 淡出。

## 3. 视觉语言

- **背景**：纯黑 `#000`，只在底部加一层紫色地面反光（径向渐变，`rgba(110,90,255,.18)`，撞击时加亮）。
- **光带**：三条正弦曲线，颜色 `#6B4CFF→#2FA8FF`、`#FF4FD8→#7B5CFF`、`#2FA8FF→#39E6C8`，两端渐隐到透明。每条画三遍（`lighter` 叠加）：线宽 46 / 透明度 .18 / 模糊 14px，线宽 14 / .45 / 模糊 4px，线宽 2.2 / .95 / 不模糊——外晕、光身、亮芯。画在 640×360 的离屏画布上，每帧先清空。
- **毛玻璃**：底色 `rgba(10,10,16,.55)` + 大投影（blur 40、y 18、60% 黑）；卡片里面把光带离屏图用 `blur(18px) saturate(1.4)` 叠进来（这就是“透出背后的光”）；再盖一层白色竖向渐变（13% → 3%）；1.2px 描边用斜向渐变（55% / 12% / 25% 白），左上角最亮。圆角：笔记卡 16、数据卡 22、书 12。
- **大号数字**：Inter 800，180px（数据卡 78px），填充 `#FFFFFF → #A99CFF` 竖向渐变（数据卡第二、三张换成 `#FF9AE8`、`#8FE3FF`），外发光 `rgba(120,100,255,.55)` blur 40。
- **中文**：Noto Sans SC，正文 300（细）、卡片标题 500、名字 700。白字，次要信息 70% 白。
- **书**：深色底 `#05050A` 上盖紫蓝色玻璃（30% → 10%），内圈 2px 发光描边，右下露出 14px 厚的书页，粉色书签丝带 `#FF6FDF`，封面白色“打开的书”标志 + 字母间隔拉开的 `S H I Y E`。
- **收尾**：颗粒 3.5%，暗角 55%。

## 4. 动作语言

- 一切都慢：淡入 0.5–0.8 秒 `easeOut`，只有撞击是瞬间的。
- 散落的卡片按深度 z（0.65–1.15）决定大小、透明度和漂移幅度，远的先画；随时间整体向外扩一点（`1 + .04·t·z`），配合镜头推进形成视差。
- 大数字出现时，背后卡片压暗到 38%，数字从 0 滚到 2,847 用 1.25 秒 `easeOut`。
- 收拢：每张卡 0.4 秒 `ease` 飞到光标下，途中抬高 40px，旋转归零，尺寸变成 1.25 倍，底色不透明度从 .55 升到 .94（叠起来时下面的字不再透出来）。
- 撞击：书用 `back` 在 0.4 秒内弹出，整屏径向闪白，按 `exp(−2.2·Δt)` 衰减；封面一道白色高光 1 秒扫过。
- 书之后始终轻微上下浮动（±6px）并左右微倾（`transform` 斜切 ±0.05）。

## 5. 镜头语言

一镜到底的慢推：缩放 `1 + 0.07·t/15`，撞击瞬间额外 +2.5% 再回落。不切镜头，靠“内容淡出 / 淡入”换段落。构图居中对称；数据段改成左书右卡。

## 6. 声音

- 96 BPM，D 小调：Dm9 – B♭maj7 – Gm9 – A7sus 的长 pad，7.5 秒（第 4 小节）起叠弦乐；每小节一个 sub 低音。
- 开场两下低频 `thud` 像心跳；卡片浮现是一串八音盒（`mbox`）高音。
- 数字滚动：密集 `tick`，越来越轻；数字落定时 `impact` + 一个长 sub。
- 光标 `click` + `pop2`；每张卡飞走一个 `swish`、落下一个 `blip`（音高依次升）。
- 撞击前 1.9 秒 `riser`，7.5 秒 `impact` + 底鼓 + sub + `shimmer`；之后两小节轻鼓 + 反拍 hi-hat。
- 名字、口号各一声钟（`bell`）；数据卡每张 `whip` + 八音盒；12.5 再一个 `impact` 和长和弦，片尾 `shimmer`。

## 7. 文字与标题

- 一屏最多一个主信息：一句话 / 一个数字 / 一个名字。
- 数字要“可以念出来”：2,847、0.3 秒、100%。单位用小一号的中文字贴在数字右下。
- 产品名是自拟的虚构产品，片尾角落写“概念演示 · 虚构产品”。不出现任何真实公司名、logo、发布会口号。

## 8. 踩过的坑

- 卡片叠成一摞时每张都是半透明玻璃，下面几张的标题和线条透上来糊成一团；收拢时把玻璃底色从 .55 渐变到 .94。
- 第一版书的颜色偏灰紫、发白，像一块塑料板：玻璃着色太重，而且书页那块浅色底透了过来。改成先铺一层深色底、降低着色、再加内圈发光描边。
- 散落的卡片太小，卡片标题读不出来；散落时放大到 0.92·z，叠起来 1.25 倍。
- 数字段用 180px 大字，背后卡片如果不压暗会和数字抢；压到 38%。
- 响度：这支片子动态大（两次撞击），出片后整体响度 −19.1 LUFS，在 −20 ~ −14 范围内，没有再加音量。

## 9. 制作流程（本仓库）

1. 先在顶部定时间表（`LINE1`、`CARD_IN`、`NUM`、`CLICK`、`GATHER`、`BOOK`、`STATS`、`END`）和 8 张卡片 `NOTES`（标题、位置、深度、角度）。
2. 抽帧：`node _engine/render.cjs dark-keynote stills 2,4,6.4,7.2,7.8,8.6,9.3,11.2,14`
3. 出片：`node _engine/render.cjs dark-keynote`

## 10. 引擎用法

- 离屏光带：`band`（640×360）每帧 `clearRect` 后重画三条光带；主画面用 `lighter` 把它贴满全屏。
- `glass(x, y, w, h, 圆角, 透明度, 着色, 底色不透明度)`：毛玻璃卡片，内部用 `c.filter = 'blur(18px) saturate(1.4)'` 贴模糊光带。
- `noteCard(i, x, y, 缩放, 角度, 透明度, 实心度)`：一张笔记卡。
- `drawBook(x, y, 缩放, 斜切, 透明度)`：玻璃书。
- `flare`：撞击后的衰减量，同时驱动闪白、光带亮度和镜头额外推进。
