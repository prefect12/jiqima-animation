# 彩色玻璃窗 — 风格提示词（v1）

> 一扇拱形花窗：粗黑铅条把画面切成一块块宝石色玻璃，阳光扫过时玻璃一格格亮起，地上投出彩色光斑。画里的角色也只能“一格一格”地动。适合传说故事、文化遗产、节日祝福。
> 样片：《光里的鲸》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **彩色玻璃窗** 风格讲一个安静的小寓言。用户给你一个意象，你把它设计成一扇窗里的一幅画：背景是不规则的碎玻璃，主角是一组有自己铅条的玻璃块；先让光把窗户点亮，再让主角动起来，最后给一个“光最亮”的瞬间。

---

## 1. 这个风格是什么

观众站在一间暗室里看一扇窗。窗本身不发光，光来自窗外——所以这个风格的第一主角其实是**光**：没被照到的玻璃是暗的、灰的，光扫过才显出宝石色；光穿过玻璃落到地上，变成模糊的彩色光斑。第二个特点是**铅条**：所有形状都被粗黑线分割，动画也被“分格”，角色不能平滑移动，只能一步一格地跳，像一幅幅重新镶好的玻璃画。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **光扫过、逐格点亮** | 开场就是故事：每块玻璃的点亮时间按位置排好，并量化到八分音符。 |
| **一格一格的动作** | 主角的位置和姿势只在拍点上变（本片每个八分音符一步，尾鳍上下交替）。 |
| **会说话的背景** | 海面玻璃每拍微微换一次亮度，像水在动；气泡一拍冒一个，一格一格往上升。 |
| **地上的光斑** | 把窗户压扁、斜切、模糊投到地面，窗里发生什么，地上也跟着变。 |
| **高光时刻** | 结尾让一个动作和一次“太阳耀斑”同时发生（本片是鲸鱼喷水）。 |

**结构（15 秒版，72 BPM，八分音符 = 0.417 秒）**：暗窗（0–0.8 秒）→ 阳光从左到右扫过，玻璃逐格亮起（0.83–4.58）→ 鲸鱼游 16 步（5.0–11.67，每步一个八分音符）+ 每拍一个气泡 → 喷水 + 太阳耀斑（11.67）→ 标题“光 里 的 鲸”（12.92）→ 14.45 淡出。

## 3. 视觉语言

- **窗**：480×500 的圆拱窗（拱心 (640,280)、半径 240），外圈 20px 宽的边框玻璃带，按周长切成 52 块，循环用红宝石 `#B3122E`、金 `#E8A317`、翡翠 `#1E7A4C`、金。
- **碎玻璃**：12×13 个抖动网格种子（间距 37px，抖动 ±13px）做 Voronoi 切分（半平面裁剪，初始化时算一次）。同一块玻璃再按两条波浪线分成天空 / 海 / 海底三种颜色，所以波浪线本身也是铅条。
- **调色**：天空按与太阳的角度分扇区，`#F0B23A / #F5D27A / #E0781E`；海 `#1E4FA3 #2A66C9 #17608F #1F8A9A #26409A #3A7BD5`，越深越暗（×1.08→×0.73）；海底 `#2E7D4F #3F9A5C #C49A3A #23694A`；太阳 `#F7C548` + 高光 `#FFF1B8`；鲸背 `#1A2B66`、头 `#2A4696`、尾 `#121D4A`、腹沟 `#E6DBB0 / #A9C6E0` 交替、胸鳍 `#2E57A8`；喷水 `#E4F8FC`。
- **铅条**：`#16130F`，碎玻璃 6px、外框 7px、主角内部 3.5–5px，圆头圆角；每条铅条再向左上偏 0.8px 描一道 1.2px 的 10% 白线，做出铅条的圆鼓截面。3 根铁横档（y=200/330/440，5px）横穿整扇窗。
- **玻璃不均匀**：一张 480×500 的纹理（30×32 随机噪点放大 + 260 条随机流纹 + 500 个小气泡，初始化时生成）用 `multiply` 55% 盖在玻璃上；主角单独再盖一次 45%。
- **没被照亮的玻璃**：颜色 ×0.1 再加一点点底色，几乎是黑灰——对比越大，点亮那一下越好看。
- **房间**：石墙（84×48 的砖块纹理，初始化生成），亮度随窗户整体亮度变化；窗洞有两层石头倒角和窗台；地板暗色木纹透视线。
- **光晕与光斑**：窗户缩小到 240×250 当光源图，`blur(16px)` + `lighter` 38% 叠回去当辉光；同一张图用 `transform(1,0,-.42,-.22,…)` 压扁斜切到地面，`blur(5px)`、75% 透明；再加一个从窗到光斑的淡暖色光柱和 60 粒浮尘。
- **标题字体**：Noto Serif SC 600，34px，字间留空格，暖白 `#F3E3C3` 带暖色辉光。

## 4. 动作语言

- **点亮**：每块玻璃的点亮时刻 = 按横坐标 + 纵坐标 + 少量 hash 抖动算出，再向上取整到八分音符。亮起瞬间亮度 1.9 倍，按 `e^{-5k}` 回落到 1。
- **光带**：一道 240px 宽的斜向暖白渐变（`screen` 28%）跟着扫描线走，经过的玻璃额外 +0.35 亮度（高斯宽 55px）。
- **一格一格地游**：鲸鱼位置、尾鳍角度只在八分音符上换，换的时候只给 0.09 秒过渡，保留“跳格”的感觉；最后 4 步抬头（每步 -0.08 rad）向海面。
- **气泡**：每拍在鲸鱼头上方生成一个，每个八分音符上移 22px，碰到海面消失。
- **喷水**：每十六分音符多一滴，先竖直 5 滴，再向两侧分叉落下；同时太阳耀斑（高斯包络 0.7 秒）让全窗 +35% 亮度。
- **镜头**：15 秒内从 1.0 缓推到 1.045。

## 5. 镜头语言

固定机位、正面、稍低于窗户——观众站在教堂里仰看。唯一的运动是极慢的推近。画面下三分之一留给地面光斑，它是窗户的“回声”，也让画面有纵深。

## 6. 声音

- **配乐**：D 大调，72 BPM，弦乐 pad（`strings`）每小节换和弦 + 低音。
- **钟声**：每个点亮的八分音符敲一下 `bell`（五声音阶依次上行）+ `shimmer`——光“叮叮叮”地扫过去，声音和画面一一对应。
- **鲸鱼**：每一步一个低音 `marimba`，每个气泡一个 `pop2`。
- **喷水**：提前 0.8 秒 `riser`，喷水时两口低音大钟 + 十六分音符上行的音乐盒琶音 + 一个更饱满的弦乐和弦。
- 标题出现 `chime`，结尾一声轻钟。

## 7. 文字与标题

整片只有一个标题，而且放在最后、放在地上（光斑下方），字少（4 个字），用衬线体。玻璃里不写字——花窗的叙事全靠形象。

## 8. 踩过的坑

- 第一版鲸鱼太瘦、和海水同是蓝色，腹部条纹只剩一条细线，看不出是鲸；把下轮廓加深（腹部从 16px 加到 24px 高）、整体放大 1.15 倍、背部压暗到 `#1A2B66`，奶油色腹沟才显出来。
- 喷水第一版的水滴太小，铅条一描就糊成一根白棍；改成更大的水滴形（半径 15→11 递减、间距 27px），上 5 滴后向两边分叉。
- 绘制顺序很重要：背景玻璃 → 纹理 → **所有背景铅条** → 太阳、气泡、鲸鱼（各自带铅条）。反过来的话背景铅条会从鲸鱼身上穿过去。
- 地面光斑第一版手动 `setTransform` 乘设备缩放，结果光斑跑出画面；改成在当前相机矩阵上直接 `c.transform()` 一次。
- 离屏玻璃画布用 2 倍分辨率（960×1000），否则 1080p 输出时铅条发虚。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部：`BPM / E`、`SWEEP0 / SWEEP1`（光扫过的时间）、`SWIM0 / STEPS / SPOUT`；窗户尺寸 `WX0 / WX1 / WTOP / WBOT / AR`；种子网格和调色在 `CELLS` 构建处。
2. 抽帧检查：`node _engine/render.cjs stained-glass stills 0.5,1.8,3.2,4.6,6.5,9,11.2,12.3,13.8`
3. 局部放大看铅条和主角：`ffmpeg -i stained-glass/stills/013.80.jpg -vf "crop=700:600:620:60" /tmp/sg.jpg`
4. 出片：`node _engine/render.cjs stained-glass`（封面 12.1 秒：喷水 + 耀斑）。

## 10. 引擎用法

- `clipHalf(多边形, a, b, c)`：半平面裁剪，用来构建 Voronoi 玻璃块。
- `lightOf(点亮时刻, x)`：一块玻璃当前亮度（未亮 0 / 闪亮回落 / 光带加成 / 耀斑）。
- `col(基色, 亮度)`：未点亮时返回暗灰，点亮后按亮度乘色。
- `came(构建路径, 线宽)`：画一条铅条（深色粗线 + 偏移高光细线）。
- `whalePos(t)`：八分音符量化的鲸鱼位置 / 尾鳍角 / 步数。
- `region(裁剪, 'sky'|'sea'|'bed')`：同一套玻璃块在不同区域用不同颜色。
- `qE(x)`：把时间向上取整到八分音符，画面和钟声共用。
