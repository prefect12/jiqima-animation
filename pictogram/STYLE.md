# 象形图形运动 — 风格提示词（v1）

> 纯色背景上一个几何小人：圆头 + 圆角条肢体，四肢和躯干之间留一圈“切口”。它每一拍换一个姿势，背景和音效都跟着这一拍走。适合体育赛事、活动开场、视觉识别系统的动态演绎。
> 样片：《铁人三项》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **象形图形运动** 风格把一件事拆成“一拍一个动作”。用户给你一个主题，你把它拆成 3–5 个可以用一个小人演出来的场景，每个场景配一种纯色和一种地面暗示（水面、道路、跑道），每一拍一个姿势、一个声音。

---

## 1. 这个风格是什么

这是体育场馆和赛事标识里那种象形图（pictogram）动起来的样子。它的力量来自**极度的简化**：一个人只用 1 个圆 + 5 根圆角条就能表达，一个场景只用 1–2 个色块就能交代。因为元素少，所以每一次姿势变化都非常醒目——正适合严格卡在节拍上的剪辑。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一拍一个姿势** | 姿势是关键帧，不是连续动画：拍点上 0.11 秒“啪”地切到新姿势（带一点回弹）。 |
| **小人组装** | 开场一拍长出一个部件：头 → 躯干 → 手臂 → 腿，同时报出标题。 |
| **换场 = 换色** | 每个项目一种纯色，新颜色在该场第一拍用斜切色块扫进来。 |
| **地面暗示** | 泳道浮标、公路虚线、跑道分道线——都按拍子“一步一格”往后退，而不是匀速卷动。 |
| **拍子进度条** | 右上角 3 组 × 8 格，每拍亮一格，观众能“看到”节拍。 |
| **冲线收尾** | 撞线（彩带断开）→ 双手举起 → 大字 → 彩纸。 |

**结构（15 秒版，128 BPM，32 拍）**：组装 + 标题（第 0–3 拍）→ 01 游泳（第 4–11 拍）→ 02 骑车（第 12–19 拍）→ 03 跑步（第 20–27 拍）→ 冲线（第 28 拍）、“完赛！”（第 29 拍）、彩纸（第 30 拍）→ 14.45 秒淡出。
**顺序说明**：示例故事写的是“跑步、游泳、骑车”，样片按真实铁人三项的比赛顺序改成了游泳 → 骑车 → 跑步。

## 3. 视觉语言

- **每场一色**：开场 `#15151C` 底 + 黄色小人 `#FFC93C`；游泳 `#1E7FE0`（水下 `#1769C2`）；骑车 `#2FA35B`（山 `#27904F`、路 `#34353F`）；跑步 `#F0532B`（跑道 `#C8401E`）；冲线 `#FFC93C` 底 + 黑色小人 `#15151C`，彩带 `#E4572E`。除开场和冲线外小人都是纯白。
- **身体比例（局部单位）**：头半径 21，躯干 70（线宽 27），上臂 44 / 前臂 42（线宽 17），大腿 54 / 小腿 52（线宽 21），全部 `lineCap: round`。
- **切口**：每个部件先用背景色描一圈更粗的线（每边宽 5），再画本体——前后肢体、头和躯干之间自然出现一圈缝，这是象形图最重要的质感。
- **远侧肢体**：颜色向背景混 38%，不用描边或阴影区分前后。
- **镜头缩放**：姿势在“髋部 = 原点”的局部坐标里定义，每场一个相机 `[x, y, 倍数]`：开场 2.1、游泳 2.2、骑车 1.9、跑步 2.3、冲线 1.7——小人要大，占画面高度一半以上。
- **字体**：中文 Noto Sans SC 900（场名 76px、标题 120px、“完赛！”140px）；英文和数字 Archivo Black（序号 64px、距离 24px）。
- **不用渐变、不用阴影、不用描边**：所有东西都是纯色平涂。

## 4. 动作语言

- **姿势切换**：`back(clamp((t - 拍点) / .11))`，0.11 秒到位并略过冲。每个姿势是 11 个数字：髋部 x/y、躯干角、两臂（上臂角、前臂角）、两腿（大腿角、小腿角），角度 0° 朝下、90° 朝前、180° 朝上。
- **游泳**：两个姿势交替（一臂前伸、另一臂高肘出水），每拍在入水点溅 6 个白点；水面盖住身体下半部（55% 透明水色 + 7px 白色波浪线）。
- **骑车**：曲柄每拍转 90°，两腿用两节骨骼 IK 追踪脚踏，手用 IK 抓车把，车轮辐条同步转；拍点后 0.35 秒内出现三道速度线。
- **跑步**：两个步态交替，每拍身体腾空 14 个单位（正弦），速度线同上。
- **背景步进**：`steps(t / 拍)` = 整数拍 + 0.22 秒回弹——浮标每拍退 40px、路面虚线 80px、跑道刻度 100px、远山 30px。
- **换场**：前一场颜色的斜切色块在半拍内被推出画面。
- **彩纸**：46 片，从头部附近向外抛出再受重力下落，颜色取全片的 5 个场景色。

## 5. 镜头语言

固定机位，侧面平视。不推不摇——运动感全部来自姿势切换和背景的步进。每个场景第一拍换相机倍数，相当于一次硬切。

## 6. 声音

- **配乐**：E 小调电子，128 BPM；游泳到跑步四拍底鼓 + 反拍踩镲 + 每两拍一个拍手；贝斯八分音符八度跳；pad 铺底。
- **一个动作一个音**：组装的 4 拍各一个 `pop` + 上行 `lead`；游泳每拍一个自制水花（带通噪声 1800→600Hz）+ `chip`；骑车每拍两下 `tick`（链条）+ `pluck`；跑步每拍一个 `thud`（脚步）+ `lead`。
- **换场**：提前 0.3 秒 `whoosh`，拍点上一记 `snare`。
- **冲线**：`swish + impact` → “完赛！”铜管和弦 → 10 个连拍手 + `chime`。

## 7. 文字与标题

每场只有三行字：序号（01/02/03）、项目名（2 个字）、距离（SWIM 1.5 KM 这种）。开场标题 4 个字，结尾 2 个字加感叹号。字都在左上角，永远不压小人。

## 8. 踩过的坑

- 第一版小人按 1:1 画，只有两百多像素高，在大色块里像一个小图标；改成每场一个相机倍数（1.7–2.3），小人立刻有了海报感。
- 冲线时双手举起再加起跳，手伸出画面顶部还压到右上角的节拍进度条；把冲线相机降到 1.7、髋部下移到 y=440。
- 骑车腿长 106，而最初髋部到脚踏的距离最远有 140，IK 直接拉直穿帮；重新摆了车座、中轴和 22 的曲柄长度，保证最远不超过 101。
- 游泳者一开始整个浮在水线之上，看不出在游泳；髋部下移到水线，让水面盖住身体下半。
- 给骑车的 `drawRig` 传一条“空腿”占位时，圆头线帽在髋部画出一个圆点；改成传 `null` 跳过。
- 所有随机（彩纸方向、速度）都用 `hash(i)`，不要 `Math.random`。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部：`BPM`、`SC`（各场起始拍）、`THEME`（颜色）、姿势常量（`SWIM_A / RUN_A / WIN` …）、相机 `CAM`、自行车几何 `BK`。
2. 抽帧检查：`node _engine/render.cjs pictogram stills 0.3,1.2,2.2,3.0,4.5,6.4,8.1,10.2,12.0,13.4,14.2,14.7`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "pictogram/stills/*.jpg" -vf "scale=640:360,tile=3x4:padding=6:color=white" -frames:v 1 /tmp/pictogram.jpg`
4. 出片：`node _engine/render.cjs pictogram`（封面 10.2 秒：跑步大姿势）。

## 10. 引擎用法

- `P(x, y, 躯干, 臂1上, 臂1下, 臂2上, 臂2下, 腿1上, 腿1下, 腿2上, 腿2下)`：定义一个姿势；`lerpPose(A, B, u)` 插值。
- `figure(姿势, 部件数)`：正向运动学算出关节后交给 `drawRig`。
- `drawRig(髋, 颈, 头, 臂1, 臂2, 腿1, 腿2)`：按“远腿 → 远臂 → 躯干 → 近腿 → 近臂 → 头”顺序画，每个部件先描背景色切口。
- `ik(起点, 目标, 长1, 长2, 弯向)`：两节骨骼 IK（骑车的腿和手）。
- `steps(x)`：整数拍 + 回弹的步进函数，背景卷动都用它。
- `slam(文字, x, y, 字号, 颜色, 开始)`：1.6 倍 → 1 倍砸入的大字。
