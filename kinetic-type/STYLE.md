# 大字动态排版 — 风格提示词（v1）

> 画面里只有字和色块：粗黑中文、Anton 英文数字、奶白 / 墨黑 / 橙三色，每个词都砸在拍点上，砸下去的瞬间画面震一下。适合片头、金句、合集预告。
> 样片：《风格库预告》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **大字动态排版** 风格做一支快节奏文字短片。用户给你一段文案，你把它切成 6–8 个“画面”，每个画面 1.5–2 秒、最多 3 行字，每行落在一个拍点上。

---

## 1. 这个风格是什么

没有角色、没有插画，靠字号、颜色、节奏讲故事。观众记住的是一句句“砸”进来的话。它最依赖**音画同步**：字进场 = 底鼓，画面切换 = 小节线。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **逐词砸入** | 一句话拆成三行，一拍一行，最后一行换颜色、字号最大。 |
| **描边 → 填色** | 名字 / 型号先出空心描边，再从左到右刷上颜色。 |
| **数字计数** | 0 → 44 快速滚动，再弹出补充说明胶囊。 |
| **快闪列表** | 一拍两个词，每个词配一个专属底色。 |
| **上下对切** | 两个对立的词各占半屏，从左右两边滑入。 |
| **胶片条** | 表示“逐帧 / 导出 / 视频”。 |
| **收尾 logo** | 标题 + 下划线 + 一个小吉祥物在下划线上跳。 |

**结构（120 BPM，一小节 2 秒）**：钩子句（1 小节）→ 主角名（¾ 小节）→ 数字（1 小节）→ 快闪（1 小节）→ 卖点对切（1 小节）→ 节奏句（¾ 小节）→ 技术点（1 小节）→ 标题收尾（1 小节）。

## 3. 视觉语言

- **三色**：奶白 `#F3EDE2`、墨黑 `#15130F`、橙 `#D97652`。背景在三色间硬切，字用另外两色。快闪段每个词有专属配色（水墨米白 / 像素藏青 / 剪纸红……），暗示对应画风。
- **字体**：中文 Noto Sans SC 900（Google Fonts，用 `text=` 参数只下载用到的字）；英文和数字 Anton；代码 Roboto Mono。
- **字号**：主句 120–170px，型号 260px，数字 330px，快闪 230px；一个画面最多三种字号。
- **留白**：永远居中对齐，四周至少 150px 空。

## 4. 动作语言

- **slam**：0.14 秒内从 1.7 倍缩到 1 倍，同时淡入（`easeOut`）。
- **震屏**：每个重拍后 0.12 秒内画面随机抖动，幅度 6px 线性衰减。
- **逐字母弹入**：间隔 0.07 秒，`back` 缓动从下方 120px 弹上来。
- **刷色**：裁切矩形从左到右 0.35 秒。
- **转场**：硬切为主；段落之间可以用一块色块从下往上盖满（0.5 秒）。
- **弹跳**：吉祥物每拍一跳，落地压扁 0.8。

## 5. 镜头语言

没有镜头运动，只有震屏。所有“运动感”都来自字的进出场和背景色切换。

## 6. 声音

- 四拍底鼓 + 二四拍拍手 + 反拍踩镲，贝斯跟和弦根音，Pad 铺底，120 BPM。
- 字进场叠 `thud`；描边字母逐个 `tick`；计数时快速 `tick` 连打；快闪每个词 `whip + blip`（音高依次升）；对切 `whoosh`；标题落定 `impact` + 大和弦；吉祥物起跳 `jump`、落地 `thud`；结尾 `ding`。

## 7. 文字与标题

每个画面最多 3 行、每行最多 6 个字；数字和英文用 Anton 形成对比。最后一个画面一定是标题 + 一行英文小字副标。

## 8. 踩过的坑

- 标题下的小吉祥物一开始跳得太高、下划线离字太近，挡住了“格”字：标题上移到 y=270、下划线下移到 452、跳高压到 34px。
- 中文粗体一定要真的加载 900 字重，不能靠 `bold` 假粗。

## 9. 制作流程（本仓库）

1. 在 `draw()` 里按时间段 `if (t < …)` 分画面；`slam()` 的开始时间都用拍点（0.5 的倍数）。
2. 抽帧：`node _engine/render.cjs kinetic-type stills 1.2,3.4,4.9,6.1,8.8,12.3,14.2`
3. 出片：`node _engine/render.cjs kinetic-type`

## 10. 引擎用法

- `slam(文字, x, y, 字号, 颜色, 开始, 字体, 对齐)`：砸入。
- `kick`：震屏强度，由重拍时间表算出。
- `NAMES`：快闪词和配色表。
