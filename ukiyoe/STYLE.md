# 浮世绘 — 风格提示词（v1）

> 木版套色的横向长卷：先印一版墨线，再一块一块套上平涂色版；顶部一道深蓝暈し，粗墨线、套色错位、和纸纹，自然全部图案化（青海波、霞云、雨丝、雪点）。适合旅行、季节、诗意短片。
> 样片：《屋檐四季》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **浮世绘** 风格做一段“一路走过去”的诗意短片。用户给你一个主角和一段旅程，你把它拆成 3–4 个“场”，每一场用一种季节 / 时辰的套色方案，主角在同一条横线上走，场与场之间用霞云扫过去换版。

---

## 1. 这个风格是什么

浮世绘是“印出来的画”：每种颜色是一块木版，所以颜色是**平的**（一块一色，最多一道渐变暈し），**墨线最后压在上面**，各色版和墨线之间总有一两个像素对不齐。自然物不画写实，而是画成**纹样**：海是青海波，雨是一根根斜直线，雪是白点，云是一串椭圆拼成的霞。画面四周留一圈纸边，右上角有题签。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **开场印版** | 0–0.35 秒只有墨线版，0.35 秒套上蓝灰版，0.7 秒套上其余色版——观众看到一张版画被“印”出来。 |
| **长卷横移** | 主角固定在屏幕 x=440 走路，世界往左卷；远景 0.15–0.25 倍、远处屋顶 0.5 倍、前景花枝 1.3 倍视差。 |
| **霞云换版** | 每一季开始前 0.35 秒，一簇霞云从右往左以 2600 px/s 扫过，云后面的天空、屋面、飘落物全部换成下一季的色版。 |
| **一季一纹样** | 春：樱花瓣 + 雪顶远山 + 粉霞；夏：青海波 + 白帆 + 积云 + 阵雨；秋：满月 + 雁阵 + 红叶；冬：夜空 + 雪点 + 积雪屋面 + 红灯笼。 |
| **停下来坐好** | 卷轴 11.0–11.8 秒减速停住，猫在灯笼旁坐下、抬头看雪、眨一下眼。 |

**结构**：印版开场 → 春（0–3.2 秒）→ 夏（3.2–6.4）→ 秋（6.4–9.6）→ 冬夜（9.6–15，最长，是收尾）→ 淡到纸色。

## 3. 视觉语言

- **画心**：`(18, 18, 1244, 684)`，四周纸边 `#EDE2C6`，2.4px 墨线框。整张叠 512px 和纸纹（初始化时用随机数生成的深浅纤维 + 噪点，静止不动）。
- **墨线**：`#1C1A17`，大轮廓 3px，小物 1.6–2.6px，圆头圆角。猫腿、尾巴用“粗墨线 + 细色线”两遍画（墨线宽 = 色线宽 + 5.5）。
- **套色错位**：每块色版有固定偏移——蓝灰版 `(-1.6, 1.8)`，主色版 `(2.6, 1.4)`，点缀版 `(1.2, -1.8)`。墨线不偏。
- **天空暈し**（上 → 30% → 70%）：春 `#284F7E → #9DB6C4 → #F1E3C6`；夏 `#16457E → #4F86B8 → #E8E6D2`；秋 `#2A335E → #C06A4A → #EFB76A`；冬 `#0E1530 → #22345E → #3F5580`。
- **屋面**：屋脊 y=478（高 18px），瓦面到 y=590，每 18px 一条瓦垄（亮条 7px + 暗缝 2px + 1.3px 墨线），檐口一排半径 8 的瓦当；冬天瓦面换成雪白 `#DCE2EA`，檐口压一排波浪雪檐。墙 `#EDE2C8`，每 150px 一根 `#4A3426` 木柱，隔一间一扇格子窗，冬夜窗纸变 `#F2C66B` 亮起来。
- **图案**：青海波三层同心半圆（半径 20/13/6，行距 18，错半格）；霞云是 3–8 个横向椭圆（长短轴 1.7:1）拼成一条，外轮廓 5px 描边再用填色盖掉内部线；雨丝 1.6px、斜率 0.16；雪点半径 2.2–6.7，大的描一圈细线。
- **猫**：三花，奶白 `#F4EAD5`、橘 `#C8762F`、黑 `#26221E`，金色眼 `#C9A227` 竖瞳；整体放大 1.45 倍。
- **灯笼**：朱红 `#D0452B`，黑色上下箍，9px 一道竹骨，中间奶白圆里一个“福”；三圈平涂暖光圈（半径 150/105/70）。
- **题签**：右上 58×214 的淡黄条 `#E9DBA8` + 红色内框，竖排“屋檐四季”（Noto Serif SC 900，36px）；左边 60×60 红方印 `#B8402A` 里写当季的字，每换一季弹一次。

## 4. 动作语言

- **步态**：一拍 0.8 秒 = 一个完整步态周期，四条腿按侧对步错开 1/4 周期；抬脚 8px、前后摆 13px，身体随步子上下起伏 2.5px。步态相位由卷轴距离算出，所以减速时脚步也跟着慢下来，不会“滑步”。
- **坐下**：身体绕臀部 (-38, -14) 旋转 -0.82 弧度，前腿变成竖直，后腿收成一只平放的脚掌 + 一个圆鼓鼓的大腿，尾巴从竖起慢慢绕到前脚，用 0.6 秒 `ease`。
- **抬头**：13.0–13.8 秒头仰 0.35 弧度再回来；13.9 秒眨一下眼（0.15 秒）。
- **飘落物**：全是 `hash(i)` 决定起点和速度，位置是 t 的函数，只画在本季的窗口里。
- 灯笼一直以 1.6 rad/s 小幅摆动，猫坐下后多晃一下。

## 5. 镜头语言

一个机位的横向长卷：镜头不动，世界横移，像把一卷绘卷慢慢拉开。不推不拉。结尾让卷轴停下来，最后 3 秒是一张静止的“名所”构图（猫在左、灯笼在右、雪在飘）。

## 6. 声音

- 75 BPM。筝（`koto`）用平调子（D E F A B♭），每季一句八个八分音符——一个八分音符正好是猫走一步。低音也是筝，每小节根音 + 五度。秋季起加一层很轻的弦乐铺底。
- 开场三下“刷版”：`paper` + 很轻的 `thud`，分别在 0 / 0.35 / 0.7 秒。
- 每次换季：霞云扫过时一声 `whoosh`，进季节那一拍一下 `rim`（木鱼感）+ `paper`（盖印）。
- 夏季阵雨：自制带通噪声（5200Hz），3.8 秒淡入、6.2 秒淡出。
- 猫坐下时一声低低的寺钟（`bell` D4 + D3），抬头看雪 `shimmer`，13.6 秒一个筝的琶音收尾。

## 7. 文字与标题

只用竖排题签：标题 4 个字，季节 1 个字，灯笼上 1 个“福”。字体 Noto Serif SC 900（宋体的刀刻感接近版画题字）。不要横排字幕。

## 8. 踩过的坑

- **霞云像按钮**：第一版的霞是圆角矩形（pill），像 UI 控件；改成一串横向椭圆拼起来、外描边内填色。
- **季节交界老挂在屏幕上**：一开始把交界做在世界坐标里跟着卷轴走，每条交界要在画面里停 4 秒，全片几乎一直能看到一排云；改成屏幕空间的快速扫版（2600 px/s，约 0.7 秒扫完）。
- **冬天瓦面像琴键**：在瓦垄上画白色竖条当积雪，看起来像钢琴键；改成整片雪白瓦面 + 淡蓝瓦垄 + 一排波浪雪檐。
- **猫坐下像狗立起来**：直接把走路的身体旋转，四条腿还是长棍；改成前腿竖直、后腿收成脚掌、加一个大腿椭圆，而且大腿要画在近侧后腿之后，不然后腿的线会穿过大腿。
- **灯笼消失**：冬季灯笼用 `rect(edges[3], 0, W, H)` 裁切，扫版结束后 `edges[3]` 变成 -4600，裁切框整个跑到屏幕外；宽度改成 1e5。
- **塔每 5 栋重复一次**，秋天正好在猫身后；只留在春天。
- **云挡猫头**：春、秋两季的霞云高度正好和猫头一样，改到 y=290–352。
- 初始化时就会画一次封面帧，`CAT_S` 写在函数后面会触发 TDZ 报错，常量要放在文件顶部。
- **阵雨太响**：雨声那两秒响度 -12 LUFS，别的段落只有 -20；雨声增益从 0.18 降到 0.08，弦乐铺底提前到秋季，换季加 `whoosh` 把空档填上。

## 9. 制作流程（本仓库）

1. 改顶部常量：`SEASON`（换季时间）、`PRINT`（印版时间）、`V / STOP / CATX`（卷轴速度和停点）、`SIT / LOOKUP`；每季的颜色都在 `PAL` 里。
2. 抽帧检查：`node _engine/render.cjs ukiyoe stills 1,2,4.4,7,8,9.7,11.5,12.3,14.2`，拼 3×3 联系表看。
3. 出片：`node _engine/render.cjs ukiyoe` → `demo.mp4` + `poster.jpg`（封面 12.9 秒：雪夜灯笼旁坐好的猫）。
4. 检查：时长 15.0 秒，响度约 -16.3 LUFS。

## 10. 引擎用法

- `blk(路径函数, 填色, 色版号, 墨线宽)`：浮世绘的核心——按色版号偏移填色，再在原位压墨线；色版号大于当前已印版数 `G` 时只画墨线。
- `cloud(cx, cy, w, h, 颜色, 种子)`：椭圆拼成的霞云。
- `scrollAt(t)`：卷轴位置（匀速 + 最后 0.8 秒二次减速），猫的步态相位 = `scrollAt(t) / (V × 一拍)`。
- `bnd(k)`：第 k 季的屏幕交界；每一季都在 `edges[k]..edges[k+1]` 的波浪形窗口里画天空、远景、屋面、飘落物。
- `drawCat(c, x, y, 步态相位, 坐下程度, 抬头程度, t, blk, F, G)`：可走可坐的猫。
- 雨声 `rainNoise(w, B, 时长)` 用 `B.sfx.context` 自己建噪声源接到 `B.sfx`。
