# 情景喜剧卡通 — 风格提示词（v1）

> 粗黑描边、平涂色块、固定客厅机位：一家人排成一排站在沙发后面，对着一件小事瞪眼、掉下巴，罐头笑声一响就是一个包袱。适合 15–60 秒的生活小喜剧和产品“翻车”短片。
> 样片：《扫地风波》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **情景喜剧卡通** 风格拍一出“客厅里的小事故”。用户给你一个物件或一件日常小事，你把它写成：开场（片名卡）→ 全家期待 → 物件出状况 → 全家惊呆（包袱）→ 事故升级 → 意外落地、皆大欢喜 → 定格收尾。所有角色都是原创，不借用任何已有动画的造型。

---

## 1. 这个风格是什么

观众坐在“演播室观众席”，看一个永远不动的客厅景片。角色像话剧演员一样排成一排面向镜头，笑点全靠表情的突变和时机：先是笑眯眯，下一拍眼睛放大一倍、下巴掉到胸口。画面是 2D 平涂 + 6px 黑描边，没有渐变、没有光影，信息全靠轮廓和颜色块。声音上，每个包袱后面跟一段罐头笑声，这是它和普通卡通最大的区别。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **固定客厅** | 所有事都发生在同一个景里，观众不用重新认识空间，注意力全在人和事上。 |
| **一排反应** | 三个角色同时做同一个反应（一起瞪眼），比一个人反应好笑三倍。 |
| **物件闯祸** | 新买的东西（机器人、智能音箱、微波炉）最适合当“惹事的人”。 |
| **安全落地** | 喜剧收场：没人受伤，动物毫发无损，事故变成笑料（猫最后稳稳坐在爸爸头上）。 |

**结构（15 秒版，120 BPM，一拍 0.5 秒）**：片名卡 0–1.5 秒（第 3 拍切客厅）→ 第 5 拍（2.5 秒）爸爸按遥控，机器人开工、边走边吃饼干渣 → 第 12 拍（6.0 秒）机器人盯上猫，头上弹出“!” → 第 13–14 拍吸住猫尾巴、猫惊醒炸毛 → **第 15 拍（7.5 秒）全家惊呆 + 爆笑** → 机器人驮着猫满屋乱窜 → 第 21 拍（10.5 秒）撞沙发，猫被弹飞 → 第 22 拍（11.0 秒）落在爸爸头上 + 笑声掌声 → 第 24 拍“喵～” → 第 27 拍（13.5 秒）定格 + 片名贴纸 → 14.45–15 秒淡出。

## 3. 视觉语言

- **描边**：统一深棕黑 `#1B1612`，角色 6px、道具 4–5px、窗框 7px，`lineJoin/lineCap = round`。先填色再描边，所有形状都描。
- **客厅配色**：墙 `#86CDB9`，每 72px 一条 30px 宽的竖条纹 `#78BFAB`；顶线和踢脚线 `#F6EBD3`；木地板 `#D9914F`，板缝 `#B9713A` 3px（越靠近镜头行距越大，给一点纵深）；地毯 `#E8483B` 带 `#FFD95A` 内圈；沙发 `#E0703E` / 坐垫 `#EC8752`；窗帘 `#E8483B`；灯罩 `#FFD95A`。
- **角色**：爸爸（方脸 `#F1C29B`、平头 `#5A3A22`、大胡子、绿 polo `#5FA35A`）、妈妈（圆脸 `#C98A5B`、蓬松短发加发髻 `#3A2A22`、金色大耳环、黄衬衫 `#F3C33C`）、孩子（`#F7D3AE`、反戴橙色棒球帽 `#F07A2A`、雀斑、蓝白条纹衫 `#3F7FD1`）、橘猫 `#F29B38`。肤色、发型、脸型三样都不同，站成一排也一眼分得清。
- **机器人**：顶面 `#EEF0F2`、侧面 `#6E7780`，前方一颗 LED：正常绿 `#39D353`，发现“垃圾”后红 `#FF3B30` 以 8 Hz 闪。
- **片头**：20 瓣旋转放射背景（`#FFB627` / `#FFD95A`），红椭圆 `#E8483B` 里写片名，米白字 `#FFF3D6` 配 18px 黑描边，下方黑胶囊“第一集”。
- **字体**：ZCOOL KuaiLe（站酷快乐体），只用在片名、“喵～”气泡、结尾贴纸上。

## 4. 动作语言

- **待机**：全家每拍轻轻上下弹 5px（错开 0.13 秒），惊吓之后幅度降到 40%。
- **瞪眼**：眼白从 15×19 放大到 23×31，瞳孔从 7 缩到 4，眼睛整体上移 10px；用 `back` 缓动 0.18 秒弹出，会过冲一点。
- **掉下巴**：嘴变成深红竖椭圆，高度 `12 + 44 × 惊吓程度`，脸也跟着拉长 30–40px；爸爸头发整块弹起 60px，孩子帽子飞起 40px，妈妈双手捂脸。
- **惊吓线**：每个头外面 7 根放射短线，随时间轻微抖动。
- **眼神**：瞳孔永远盯着“焦点”（机器人 → 猫 → 飞起的猫 → 爸爸头顶），观众顺着他们的视线看。
- **机器人**：前半段走走停停（关键帧 + smoothstep），后半段驮猫沿 Catmull-Rom 样条高速乱窜，身后留 5 团尘土。
- **猫**：睡觉（闭眼 + 飘 Z）→ 被吸（身体横向拉长 45%、尾巴被拉成直线伸进机器人、爪子在地毯上划出红痕）→ 炸毛（锯齿轮廓）→ 骑乘（尾巴竖直炸开）→ 飞（四肢张开转一圈）→ 坐在头上（眯眼、尾巴慢摇）。

## 5. 镜头语言

**机位永远不动**，这是情景喜剧的规矩：不推、不摇、不切特写。唯一允许的是两次 0.25 秒的镜头抖动（惊呆那一拍和撞沙发那一拍，最大 16×12px）。前景是地板（事故发生区），中景是沙发和一排人（反应区），背景墙上的一幅鱼的画给猫做个小伏笔。结尾定格：画面停在 13.5 秒那一帧，闪一下白，右下角弹出星形贴纸“扫地风波 · 完”。

## 6. 声音

- **配乐**：F 调放克，slap 贝斯八分音符 riff `[41, –, 53, 41, –, 51, 53, 48]`（第二小节移到 B♭），电钢在反拍点和弦，军鼓在每个段落前滚一小节；片头铜管三连音。
- **罐头笑声**（最重要）：在 `score()` 里用 `B.sfx.context` 自己合成。每段 10–22 个“观众”，每人一个音高（男声 120–190 Hz、女声 210–360 Hz）、一个语速（每秒 5.2–7.8 个“哈”）和一个起笑时间；每个“哈”是锯齿波过两个带通共振峰（700–1200 Hz 与其 1.6 倍）+ 一点气声噪声，音高每个音节往下滑 18%，整段越笑越弱。
- **掌声**：每秒 70 下短促带通噪声（1.1–2.9 kHz），开场、落地和定格各一段。
- **拟音**：机器人开机两声方波“滴”、低频电机嗡声；发现猫三声高“滴”；吸尘 riser；惊呆时唱片刮擦 + 撞击 + 铜管不和谐和弦；撞沙发 thud + boing；猫飞起用滑哨（500 → 1700 → 480 Hz）；落地 pop；“喵”用共振峰合成，后面跟 24 Hz 脉冲的呼噜。

## 7. 文字与标题

画面里的字越少越好：片名“扫地风波”、副标“第一集”、机器人头上一个“!”、猫的“喵～”、结尾“扫地风波 · 完”。台词不用字幕，全靠表情和音效讲。

## 8. 踩过的坑

- **`lineWidth = 0` 不会生效**：写“喵～”时传了描边宽度 0，canvas 忽略这个值、沿用上一次的 6px，结果字被描成一团黑块。现在描边宽度为 0 时直接跳过 `strokeText`。
- **遥控器那只手藏到了妈妈脑袋后面**：爸爸在右侧举遥控，手臂被后画的妈妈挡住，只剩一根怪线。改成左手举起（朝窗户那边）。
- **机器人跑出画面**：驮猫乱窜的样条有一个点在 y=690，机器人底边被画框裁掉；路线最低点收到 y≈664。
- **沙发底下露出彩条**：角色身体画到 y=480，沙发底边只到 470，沙发腿之间露出绿、黄、蓝三条衣服。身体改成画到 455。
- **结尾贴纸被裁**：星形贴纸半径 118、中心 y=626，下沿出画，“扫地风波”四个字也超出星形。缩到半径 120、中心上移到 (1096, 584)，字号 36。
- **掌声太小**：看频谱图发现开场掌声几乎没有能量，把单下掌声增益从 0.09 提到 0.17。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部用拍号定义所有事件（`T_ROOM`、`T_ON`、`T_SPOT`、`T_SHOCK`、`T_BONK`、`T_LAND`、`T_FREEZE`……），`draw()` 和 `score()` 都读它们。
2. 抽帧检查：`node _engine/render.cjs sitcom-toon stills 0.8,2.6,4.5,6.8,7.9,9.2,10.8,12.3,14.0`，再用 ffmpeg 拼成 3×3 联系表看。
3. 出片：`node _engine/render.cjs sitcom-toon` → `demo.mp4` + `poster.jpg`（封面取 8.25 秒：全家下巴掉地、猫骑在机器人上）。
4. 验收：`ffprobe` 时长 15.0；`ebur128` 响度 −17 LUFS 左右。

## 10. 引擎用法

- `fs(填色, 线宽)`：当前路径先填后描，统一描边色。`ell()`、`line()`、`burst()`（锯齿星形）、`txt()`（带描边的字）。
- `eyes(x, y, 间距, {shockK, target, mood, cross})`、`mouth(x, y, {shockK, mood})`：表情系统，`mood` 有 smile / curious / laugh / content，`shockK` 控制瞪眼和掉下巴的程度。
- `dad()` / `mom()` / `kid()`：三个角色，先画在沙发之前（身体被沙发挡住），表情由 `moodAt()` 按时间段切换。
- `robotPos(t)`：前半段 `kf(ROAM)` 关键帧，后半段 `spline(RIDE)` 样条，撞沙发后弹回；饼干渣按机器人经过的时间自动“被吃掉”。
- `catLying / catRide / catFly / catSit`：猫的四种状态。
- `score()` 里的 `laugh(w, B, 时长, 人数, 音量, 种子)`、`applause()`、`slide()`、`meow()`、`purr()`、`scratch()`：自建音色，全部用 `F.hash` 取随机数，每次渲染一样。
