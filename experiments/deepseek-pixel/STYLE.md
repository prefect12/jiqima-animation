# 像素游戏 — 风格提示词（v1）

> 320×180 的像素画面放大到 1080p：有限调色板、横版卷轴、HUD 血条经验条、扫描线，配 8-bit 芯片音乐。每一次跳跃都落在拍点上。
> 样片：《BUG HUNT》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **像素游戏** 风格把一件事拍成“一关游戏”。用户给你一个主题，你把它拆成：小怪（日常问题）→ 升级（获得能力）→ BOSS（最大的难题）→ 通关（结果）。

---

## 1. 这个风格是什么

所有东西先画在一张 320×180 的离屏画布上，坐标取整，再关闭平滑放大 6 倍。观众一眼就懂游戏语法：HUD、血条、+10XP、LEVEL UP、STAGE CLEAR，所以不用解释就能讲“进度”和“难度”。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **小怪 = 小问题** | 一拍踩掉一个，节奏感强，可以放很多个。 |
| **经验条 / 升级** | 表示积累、学到新东西。 |
| **BOSS 血条** | 最难的问题，三格血，三下打完。 |
| **通关 + 分数** | 结尾给一个具体数字（分数 / 耗时 / 成果）。 |

**结构（15 秒版，128 BPM）**：标题 BUG HUNT（1.4 秒）→ 第 4/8/12 拍踩三只小 BUG → LEVEL UP → 第 16 拍 BOSS 登场 → 第 20/22/24 拍三连击 → 爆炸 → STAGE CLEAR。

## 3. 视觉语言

- **画布**：320×180，`imageSmoothingEnabled = false`；每帧先 `clearRect`，天空铺满。
- **调色板**：天空四档蓝 `#8BD3FF → #52A6E3`（色带分层，不要渐变）；远山 `#3C6E9E` 带白色雪顶；草 `#34C759`；土 `#9A5A32 / #A8643A` 交替；主角橙 `#FF8C42`；BUG 红 `#E0504A`；文字阴影 `#1D1D24`；高亮黄 `#FFF27A`。
- **视差**：云 0.25 倍、山 0.5 倍、地面 1 倍速度卷动。
- **字体**：Press Start 2P，6–16px（画布像素），所有字带 1px 深色投影。
- **HUD**：左上角色名 + 等级 + 经验条，右上 BOSS + 三格血；半透明深色底。
- **扫描线**：放大后每 4px 一条 8% 黑线。

## 4. 动作语言

- 跳跃：0.45 秒正弦弧，**落点正好在拍点上**；落地后小弹 0.3 秒。
- 走路：两帧腿交替（8 fps）。
- 踩扁：BUG 变成扁条 + 飘 “+10XP”。
- 受击：BOSS 白闪 0.15 秒 + 抖动；死亡：10 个像素方块向外炸开。
- 升级：主角周围 4 颗黄色像素绕圈，LEVEL UP 闪烁。

## 5. 镜头语言

横版卷轴，镜头跟主角；BOSS 出现后卷动停止，BOSS 从右边走进来。最后 0.5 秒黑场淡出。

## 6. 声音

- 方波主旋律（`chip`）+ 三角波低音（`chipTri`），BOSS 段换小调、十六分音符；通关段旋律升八度。
- 鼓：底鼓 + 军鼓 + 八分踩镲，第 2 小节进。
- 音效：起跳 `jump`、踩中 `coin`、打击 `thud + pop`、BOSS 登场 `riser`、爆炸 `impact`、升级 / 通关用芯片琶音。

## 7. 文字与标题

全部英文大写短语（BUG HUNT / LEVEL UP! / STAGE CLEAR! / SCORE 1250）；Press Start 2P 没有中文字形，要中文就换像素中文字体或做成图片。

## 8. 踩过的坑

- 离屏画布不清空会留下残影和黑带，每帧必须 `clearRect`。
- 山用“三角 + 固定底座”会画成房子形状，改成纯三角 + 雪顶才像山。
- 受击抖动现在用的是 `Math.random`，逐帧导出时每次渲染略有不同，影响很小；要严格可复现就换成 `hash(t)`。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部用拍号定义事件（`STOMP`、`HITS`、`LVUP`、`BOSS_IN`……），画面和音效都读这些常量。
2. 抽帧：`node _engine/render.cjs pixel-game stills 1,5.8,9.8,13`
3. 出片：`node _engine/render.cjs pixel-game`

## 10. 引擎用法

- `rect(x, y, w, h, 颜色)`：取整画像素块；`txt(字, x, y, 颜色, 字号, 居中)`。
- `hero(x, y, 帧, 闪光)`、`bug(x, y, 帧, 压扁, 倍数, 受击)`。
