# 来源、许可与版本边界

- 精选30套 `demo.html`、`STYLE.md` 和 `_engine/core.js` 来自作者自有的 Claude 动画风格库。历史项目记录表明其为独立编写的故事、代码和规范。历史动画由Claude制作；本公开版本的打包、预览、渲染兼容和合集工具由Codex整理。
- 本仓库的自有代码和文档采用MIT许可证。品牌名称、标识与公众号二维码保留品牌权利；开源许可不表示可以冒充机器马玩AI。
- 门类参考 [LemoLab / lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)。保留这项署名。本仓库未复制该参考库的源码、STYLE.md或影片，也不捆绑其submodule。
- 另一提示词参考库 [awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos) 不包含在本项目中；未转载其中的第三方提示词、截图或视频。
- 源码里的Google Fonts是外部字体依赖，不在本包内重新许可或转存。联网时可加载；离线使用系统回退字体，字形、字宽可能不同。需严格匹配时安装样片STYLE.md中列明的字体，并遵守各字体许可。
- 原库 `clawd-paper-cartoon` 为别的影片节选，无独立完整源码；`kill-bill-fold` 是照片驱动的独立模板，依赖素材未包含。两者不计入本次30套可运行源码，更不冒称已完整开源。
- 本次精选30种全部包含可编辑源码。本次主分支与新版发布包仅提供这30种，额外13种已从当前目录移出；旧提交作为历史版本保留。后来新增的Codex实验/Claude重制未验收样片不在此稳定版内。
- `prompts/` 是根据规范整理的复用指令，并非历史Claude聊天原文。
- v1.1.0 Release中的150秒视频为用户选定的历史成片；v1.2.0移除玻璃产品，加入历史暗色科技发布原片并前置到第3种，其余29种保留原片与相对顺序。每支15秒原片一次压为5秒，另附Codex制作的8秒文字预告。重新运行源码可能因字体、浏览器版本、噪声采样及编码器产生差异。渲染器固定伪随机种子以帮助同环境重复，不承诺跨平台逐像素一致。
- DeepSeek独立重建实验单列在 `experiments/`，只供比较，不替换历史Claude源码。技术解码、动作语义、艺术效果与用户验收分别记录。
