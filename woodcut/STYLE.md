# 木刻版画 — 风格提示词（v1）

> 黑白木刻：黑是没刻掉的木面，白是刀刻掉的地方，天空、海、光全靠一道道两头尖的刀痕粗细表现明暗；黑色里透出木纹，只加一块暖黄套色版给“灯火”。动作按 12 帧/秒走，刀痕每 1/6 秒重刻一次。适合民间故事、手作品牌、书籍预告。
> 样片：《守灯人》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **木刻版画** 风格讲一个“黑暗里有光”的故事。用户给你一个主角和一个夜晚，你把它拆成“摸黑 → 点灯 → 光带来什么 → 天亮”四段：画面从几乎全黑开始，每一次亮都是刀刻出来的白，最后让白压过黑。

---

## 1. 这个风格是什么

木刻的画面语言是**减法**：先是一整块黑，想要哪里亮就刻掉哪里。所以明暗不是渐变，而是刀痕的疏密和粗细——靠近地平线的天空刀痕粗（亮），天顶刀痕细（暗）；近处的浪刻得宽，远处的浪刻得细。每一刀都是两头尖、中间鼓的柳叶形（V 形刀的痕迹）。强烈的黑白对比之外，只允许一块套色（暖黄），而且要对不准一点。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **揭纸开场** | 0.1–0.9 秒，一张白纸从左往右掀开，露出下面的版画——像把印好的纸从木版上揭下来。 |
| **黑里的一点光** | 守灯人提着一盏小灯上山：画面里唯一的暖色是他手里那一点。 |
| **一格一格亮起来** | 进门后塔身三扇窗由下往上亮（拍点上），然后灯室“轰”地刻出一圈放射线。 |
| **光束扫过** | 两道光束绕着塔转，扫到哪里哪里被整片刻白，只留几根黑色放射线。 |
| **一艘一艘靠岸** | 三艘船从海平线驶来，越来越大，按拍点依次靠上码头，每艘桅上一盏暖黄小灯。 |
| **天亮收尾** | 太阳从海平线升起（套色 + 22 道放射刀痕），天空刀痕整体变粗，灯灭，守灯人在回廊上挥手。 |

**结构**：揭纸（0–0.9 秒）→ 上山（0.9–3.0）→ 进门、窗亮（3.0–4.5）→ 点灯（5.25）→ 光束转起来（6.0）→ 三艘船靠岸（7.5 / 9.0 / 10.5）→ 天亮（12–14）→ 守灯人挥手、片名 → 淡出。

## 3. 视觉语言

- **两色 + 一块套色**：墨 `#17130F`、纸 `#ECE4D2`、套色暖黄 `#E4A83A`（整体偏移 (3, -2) 印，故意对不准）。
- **画心** `(24, 24, 1232, 672)`，四周留纸边；版框是 3px 的黑线，每个点 ±1px 抖动，像木版边缘。
- **天空**：每 8px 一行横向刀痕，一行拆成 70–260px 的若干刀、刀间 5–17px；刀宽 = `0.2 + 1.9 × v^2.2`（v 从天顶 0 到地平线 1），天亮时再加 `1.3 + 1.6v`。
- **海**：地平线一道 1.4px 白线；往下 24 行浪，行距按 1.55 次方拉开；每行是一排往上拱的弯刀（`gougeArc`），浪长 30→150px、拱高 1.5→10.5px、刀宽 0.45→2.85px，月亮正下方那一条刀宽再乘 2.4（月光路）。
- **云**：一条黑色云带，下沿一排扇贝弧，每个弧里刻三道同心回纹（刀宽 2.2 / 1.4 / 0.9），上沿两道细光边；天亮时云肚子里也刻出横线。
- **塔**：白塔（整块刻空）+ 5px 墨线外框，右侧 14 根竖排线由细到粗做阴影，两道黑环里刻细横线；窗、门是黑拱形，亮了以后填套色 + 一圈短放射刀。
- **灯**：灯室亮起时 28 道放射刀（长短交替、缓慢转动），点灯那 0.5 秒放射线额外伸长 60px。光束：夹角 ±0.075（朝向镜头时加宽），内部全刻白，只留 13 根由细到粗的黑放射线。
- **人物和船**：守灯人是黑剪影，外面先刻一圈 3.2px 的白边，不然在黑崖上看不见；船身黑、帆刻白加 6 根黑竖线、船帮和船底各刻一道白线，桅灯下面有 4 道倒影短刀。
- **质感**：木纹贴图（浅色弯曲纹路 + 漏墨白点）用 `screen` 55% 叠在画心上；纸纤维用 `multiply` 叠在整张上。
- **字体**：Noto Serif SC 900，36px，白字刻在 150×52 的黑块上，外加一道白框线——像刻在版角的题名。

## 4. 动作语言

- **12 帧/秒**：`t = floor(t × 12) / 12`，所有运动（浪、云、船、人、光束）都一格一格地走。
- **重刻抖动**：每刀端点有 ±0.4–2px 的抖动，种子里带 `floor(t × 6)`，所以线条每 1/6 秒“重刻”一次，有手工版画动画的呼吸感，但不会 30 帧乱闪。
- 船：`1 - (1-u)^2.2` 减速靠岸，缩放 0.26 → 1.2，上下浮动 3px、摇摆 ±0.04 弧度，航行时船尾拖两排白色尾迹。
- 光束：每秒转 1.5 弧度，长度 = 1100 × |cos|，灯灭时 0.8 秒收回。
- 太阳：2 秒内从海平线下 70px 升到露出大半，放射刀痕同时变长变粗。

## 5. 镜头语言

一张固定构图的版画：左边海和码头，右边崖上的灯塔，左上月亮，地平线在 y=400。不动镜头——版画是“一张图”，所有变化都发生在刀痕里。

## 6. 声音

- 80 BPM。低音弦乐 Dm – B♭ – F – C，最后一小节落到 D 大三和弦；`subbass` 托底；自制大提琴（锯齿 + 三角波、5Hz 揉弦、1100Hz 低通、慢起音）拉一条下行再上行的旋律，最后停在高音 D。
- 海浪一直在：自制布朗噪声 + 低通扫频（400 → 1400 → 300Hz），每 2.2 秒一浪，天亮后小一点。
- 同步音效：揭纸 `paper + whoosh`；上山每半拍一声轻脚步；进门 `thud + rim`；三扇窗三声高音 `bell`；点灯 `riser → impact + shimmer`；光束开转和两小节后各一声自制雾笛（65 + 97.5Hz 锯齿、420Hz 低通）；每艘船靠岸一声港口钟（G / E / D）+ 船帮碰码头；天亮 `chime` + 两声自制海鸥叫；14 秒低音钟收尾。

## 7. 文字与标题

只有一个刻在黑块上的片名“守灯人”，开场 0.9–3.2 秒出现一次，结尾 13.2 秒起再出现。字要少、要粗，笔画细的字体刻出来会糊。

## 8. 踩过的坑

- **天和海分不清**：第一版天空和海都是横向直刀，整张画像一块布；改成天顶刀痕很细、靠地平线才变粗，海改成一排排往上拱的弯刀，再刻一道海平线。
- **云像铁链**：用一串椭圆各自描边，重叠处全是断开的弧，看起来像链子；改成一条云带、下沿扇贝弧、每个弧里三道回纹。
- **守灯人和船身看不见**：黑剪影放在黑崖、黑海上，只剩一点灯；给人物外面刻一圈白边，船帮和船底各刻一道白线，人物放大 1.5 倍，山路刀痕加宽到 2.6。
- **标题字认不出**：站酷庆科黄油体的“守”刻出来像“与”；换成 Noto Serif SC 900。
- **崖和海糊在一起**：崖顶沿轮廓刻一道白边，岩面刀痕从 70 刀加到 110 刀、加长加粗。
- **崖脚浪花像烟花**：放射状直刀像烟花，改成几道弯的短弧。
- **天亮以后云变成黑疙瘩**：天空刀痕都变粗了，云还是实心黑；天亮时在云肚子里也刻横线。

## 9. 制作流程（本仓库）

1. 改顶部时间表 `T`（揭纸、上山、窗、点灯、光束、三次靠岸、天亮、挥手、片名）；船的起点终点在 `BOATS`，山路在 `PATH`。
2. 抽帧检查：`node _engine/render.cjs woodcut stills 0.5,1.5,5.25,6.9,8.4,11.9,12.5,13.2,14.7`，拼 3×3 联系表看。
3. 出片：`node _engine/render.cjs woodcut` → `demo.mp4` + `poster.jpg`（封面 10.2 秒：光束拉到最长，第三艘船正在靠岸）。
4. 检查：时长 15.0 秒，响度约 -15.7 LUFS。

## 10. 引擎用法

- `gouge(c, x1, y1, x2, y2, 宽)`：一刀直刀（柳叶形）；`gougeArc(c, x1, y1, x2, y2, 宽, 弯度)`：一刀弯刀。都只往当前路径里加形状。
- `carve(fn)`：把 `fn` 里所有刀痕合成一条路径，一次填纸色——刻得再多也只 fill 一次，速度快。
- `spot(fn)`：套色版，偏移 (3, -2) 填暖黄。
- `jit(k, 幅度)`：带 `floor(t × 6)` 的固定种子抖动，用来“重刻”。
- `keeper(x, y, 步态, 挥手, 提灯, 缩放)`：先画白边再画黑剪影的守灯人。
- 海浪 `sea()`、大提琴 `cello()`、雾笛 `foghorn()`、海鸥 `gull()` 都在 `fn(w, B)` 里用 `B.sfx.context` / `B.pad.context` 自己建节点。
