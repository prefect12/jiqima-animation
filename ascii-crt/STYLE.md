# ASCII 终端 — 风格提示词（v1）

> 一台老式单色显示器：开机自检、命令行、然后用字符“画”出画面。荧光绿为主、琥珀色点睛，扫描线、辉光、屏幕弯曲一样不少。适合开发者工具、科幻、科技品牌。
> 样片：《字符长出来的植物》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **ASCII 终端** 风格做一支“程序跑起来”的短片。用户给你一个主题，你先写一段 3 秒的开机 / 输入命令，再让程序用字符画把主题演出来（生长、加载、计算、绘制），最后打印一行结果并关机。

---

## 1. 这个风格是什么

画面上的一切都是字符：图像先画在一张很小的位图上，每 4×8 个像素算一个亮度，再换成对应的字符。观众知道“这是一台电脑在画”，所以画面粗糙反而可信。显示器本身是第二个主角：开机时一条亮线展开、屏幕四边鼓出的弧度、扫描线、刷新光带、关机时缩成一条线——这些 CRT 细节决定了风格像不像。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **开机自检** | BIOS 名称、CPU、内存计数、显示、磁盘，一行行打出来，最后“A>”等命令。 |
| **敲命令** | 逐字输入 `RUN GROW.BAS`，每个字一个键盘声，回车后清屏。 |
| **字符画** | 主角由亮度 → 字符映射生成，会“长”、会动，边缘自动出现 `/ \ |`。 |
| **状态栏** | 顶部程序名 + 计数器（DAY），底部进度条 `[####....]`，数值和画面同一个变量。 |
| **颜色切换** | 全片绿色，只把最重要的东西（花、太阳、“GROWTH COMPLETE”）换成琥珀色。 |
| **关机** | 画面竖向压成一条线，再横向缩成一个点。 |

**结构（15 秒版，100 BPM，1 拍 = 0.6 秒）**：黑屏 → 0.3 秒开机亮线 → 自检（0.7–2.3）→ 输入命令（2.75–3.35）→ 清屏（3.6，第 6 拍）→ 每拍长高一格共 12 拍，第 8/10/12/14/16 拍各长一片叶 → 第 17 拍花苞 → 第 18 拍开花（10.8）→ 第 20 拍打印“GROWTH COMPLETE”（12.0）→ 14.35 关机 → 14.55–15 黑场。

## 3. 视觉语言

- **显示器**：外壳 `#34312B → #1F1D19` 竖向渐变，屏幕外圈 `#15130F`；屏幕 1100×640、圆角 48；左下角铭牌“PHOSPHOR-80”，右下角电源灯（开机时 `#52FF8F` 带光晕，关机后 `#1F3A28`）。
- **字符网格**：80 列 × 26 行，格子 12.5×21.8，VT323 30px（离屏画布按 1.5 倍渲染），字符在格子里居中。
- **颜色**：荧光绿 `#5CFF98`（正文）、暗绿 `#23B057`（标签、分隔线、LOADING）、琥珀 `#FFB84D`（花、太阳、完成）、近白 `#E2FFEC`（最亮的像素、BIOS 标题）；屏幕底 `#031006`。
- **亮度 → 字符**：`" .:-=+*#%@"` 十级；按四个象限的亮度差判断斜线 `/ \`，左右均匀的中等亮度且是绿色时用 `|`。位图用红通道画琥珀、绿通道画绿，逐格比较决定颜色。
- **桶形畸变**：先按行切 4px 细条、每行横向缩放 `1 - 0.07·v²`，再按列切 4px 细条、纵向缩放 `1 - 0.091·u²`——分隔线和进度条会自然弯成弧。
- **辉光**：整屏缩到 412×240，`lighter` 叠两层：`blur(6px)` 90% + `blur(24px)` 55%。
- **扫描线**：每 3px 一条 1.1px、28% 黑线；一条 120px 高的绿色刷新光带以 0.35 屏/秒向下滚；屏幕玻璃再加径向暗角（75%）和左上角一块 7% 白色反光。
- **闪烁与故障**：整屏亮度随帧 `0.94–1.0` 抖动；约 4% 的帧随机挑一行横向错位 ±7px——全部用 `hash(帧号)`。

## 4. 动作语言

- **打字**：自检行每字 0.01 秒，命令每字 0.05 秒（和键盘声一一对应），“GROWTH COMPLETE”每字 0.03 秒。
- **光标**：`_` 每半拍闪一次。
- **生长**：高度在每拍用 0.35 秒 `easeOut` 长一格，茎随时间轻轻摇（正弦，幅度和高度成正比）。
- **叶子**：1.2 拍内从 0 长到全长，同时从贴着茎（抬起约 46°）慢慢张开到约 20°，左右交替。
- **开花**：5 片花瓣 1.5 拍展开，缓慢旋转；太阳的 8 道光芒每拍错开半格并伸缩一次。
- **开机**：0.35 秒内画面从一条线纵向展开，同时整屏泛白 → 淡去。**关机**：0.25 秒压成横线，再 0.25 秒缩成点。

## 5. 镜头语言

固定机位，正对显示器，屏幕占满画面，只露出一圈边框。不推不摇——“镜头”就是屏幕上的内容切换：自检 → 清屏 → 程序画面 → 关机。

## 6. 声音

- **CRT 本底**：开机后一直有 60Hz 正弦 + 120Hz 锯齿的电源嗡声（走低音总线，被 700Hz 低通削掉刺耳部分），关机时一起消失。
- **开机**：`thud` + 55→38Hz 的低频“咚”（消磁）+ `whip` 静电声；自检一声方波“哔”，内存计数一串 `tick`，完成再一声高“哔”；磁盘读写两串短方波。
- **键盘**：每个输入字符一个 `key`，回车再加 `click`。
- **芯片音乐**：清屏后开始，三角波贝斯每拍根音 + 反拍八度、方波主旋律；每长一片叶两个上行 `chip` 音，开花一串 8 音琶音 + `shimmer`，完成时一个方波和弦 + 一串键盘声。
- **关机**：2400→60Hz 的下滑“啾”+ `thud`。

## 7. 文字与标题

所有字都是“电脑会打印的字”：大写英文、等宽、缩写（CPU、DISK A:、GROW.BAS）。不要中文、不要口号、不要花体。数字用补零（`064K`、`DAY 041`），单位缩写（CM）。一屏上同时出现的字不超过 6 行。

## 8. 踩过的坑

- 第一版 VT323 用 25px，在 12.5px 宽的格子里字母之间空得很开，像加了字距的海报字；改成 30px 才像终端。
- 叶子的旋转角写反了（canvas 正角度是顺时针），叶子全部向下垂，整株植物像一座宝塔 / 圣诞树；改成向上抬、再变细变长，才读得出是嫩苗。
- 辉光太弱时字是暗绿色的，缺少荧光屏“发光”的感觉；把两层模糊辉光分别提到 90% 和 55%。
- 位图读回（`getImageData`）要在创建画布时加 `willReadFrequently`，并且每帧先涂黑再画，否则上一帧的叶子会残留。
- 行错位和亮度闪烁都必须用 `hash(帧号)`，用 `Math.random` 的话抽帧和成片会不一样。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部：`BPM`、`ON / CLS / BLOOM / DONE / OFF`、`LEAVES`、命令 `CMD` 和打字速度 `KEY`；字符网格 `COLS / ROWS / CW / CH`；颜色表 `COL`；字符表 `RAMP`。
2. 主角画在 `pl`（320×208 的位图）上，绿通道 = 绿色字符，红通道 = 琥珀字符。
3. 抽帧检查：`node _engine/render.cjs ascii-crt stills 0.45,1.6,3.3,4.5,6.5,8.8,10.5,11.9,13.2,14.5`
4. 出片：`node _engine/render.cjs ascii-crt`（封面 11.9 秒：开花 + 太阳 + 满进度条）。

## 10. 引擎用法

- `put(行, 列, 文字, 颜色号)`：写进字符网格；`typed(行, 列, 文字, 开始, 每字秒数)`：逐字打出。
- 亮度映射循环：每格读 4×8 像素，得到四象限均值 `q[0..3]`、平均亮度 `L`、红绿通道和，选字符和颜色。
- 桶形畸变：`TXT → TMP`（行条）→ `WARP`（列条），系数 `KB = .07`。
- 开关机包络：`sx / sy / flash` 三个量，作用在 `WARP` 贴回屏幕时的缩放上。
- 声音：`osc(w, B, 波形, 频率, 时长, 峰值, 总线, 终点频率)`，通过 `B.sfx.context` 自建振荡器；CRT 嗡声挂在 `B.bass`。
