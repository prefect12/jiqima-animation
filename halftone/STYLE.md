# 复古半调印刷 — 风格提示词（v1）

> 泛黄的旧报纸：粗网点照片（点的大小跟着明暗走）、粗宋体大标题、红色“号外”套印错位、滚筒拖墨和漏墨。报纸转着飞进画面，镜头在版面上推拉，照片里的网点还会“活”过来。适合“假新闻”式的趣味公告、复古发布会、年代感栏目片头。
> 样片：《本市一只柯基宣布竞选市长》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **复古半调印刷** 风格做一张“号外”头版。用户给你一条（虚构的）新闻，你把它写成一张完整的报纸头版：报头、大标题、一张网点照片、一栏小字和一个方框要点，然后让镜头像读报一样依次看过去，最后一沓报纸“加印”落在桌上。

---

## 1. 这个风格是什么

老报纸只有一种黑墨（加一块专色红），照片靠网点表现：暗处点大、亮处点小，离远看是灰度，凑近看全是圆点。纸是黄的，边缘更黄，有霉斑和折痕；印刷是粗糙的：红版对不准、滚筒拖出一道重影、局部墨不够。这个风格的魅力在于**离远看是信息，凑近看是材质**，所以镜头必须有一次“贴脸”推到网点上。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **转报纸** | 开场报纸从一个小点转 2.5 圈放大落定，落定的一瞬间大标题正好能读。 |
| **盖号外** | 落定后一拍，红色“号外”章砸在报头右侧，套印故意错开。 |
| **活照片** | 网点照片每帧重新采样，所以照片里的角色可以动：柯基点头、张嘴叫、观众跟着拍子晃，闪光灯一闪网点全缩小。 |
| **贴脸看网点** | 推到 5 倍，画面里只剩大圆点，让观众看清“照片是点组成的”。 |
| **打字机** | 图注和“政见三条”一个字一个字打出来，每行末尾“叮”。 |
| **加印** | 结尾 4 份报纸从四个方向飞来叠成一沓，每份的红版错位都不一样。 |

**结构（120 BPM，一小节 2 秒）**：转报纸（1 小节）→ 全版停留 + 号外章（½ 小节）→ 推到照片、打图注、照片活起来（2 小节）→ 闪光 + 贴脸看网点（¾ 小节）→ 摇到政见框打字（1 小节）→ 拉回全版（½ 小节）→ 加印四份（½ 小节）→ 定格 + 淡出。
新闻内容一律虚构且无害：动物、邻里、天气、小店。**不要**用真实报纸名、真实人物或真实事件。

## 3. 视觉语言

- **纸**：底色 `#E7D8B5`；从中心 200 到 760 半径的径向渐变把边缘压暗到 `rgba(150,105,45,.38)`；14 块霉斑（半径 8–42，棕色 16%→0）；512px 纸纹（稀疏褐点 + 700 根纤维）；y=470–490 一道横向折痕（暗线 + 亮线）；背面文字透印 5%（左右镜像）。
- **墨**：黑 `#1E1B16`，专色红 `#C4301C`，都用 `multiply` 叠。桌面 `#221D18` + 台灯暖光径向渐变。
- **网屏**：45°，网距 7（版面单位），采样格 112×112。点半径 = 7 × 0.72 × √暗度 × (1 ± 11% 随机)，暗度 = (1 − 灰度/255)^1.2。照片框 580×370，外加 2px 黑框。
- **照片内容**（先画灰度小图再转网点）：天空 246→212、楼 112、窗 70、彩旗黑白相间；柯基毛色 160–172，白脸 246–250，**头、耳、身体外加 5px、灰度 50–55 的描边**，眼睛半径 13；讲台 52、麦克风 25–35；前排观众 40–58。
- **版式**（页面 1160×960）：报头“梧桐巷晚报”思源宋体 900、92px、字距 10；左右报耳（期数 / 定价）22px；双线规 7px + 2px；日期行 20px；大标题两行 136px；照片左、右栏引语 34px + 灰块模拟正文 + 双线框“政见三条”（标题 28px、条目 26px）。
- **错版**：① 红版每份错开 (7,−5) / (−9,4) / (12,6) / (−5,−8) / (15,−7)px；② 第二行标题下沿 y 452–486 的条带里，同一行字向右重复 6 次、透明度 22%/k——滚筒拖墨；③ 一条 180px 宽、38% 纸色的竖带，模拟局部缺墨；④ 2600 个纸色小点（0.6 倍平铺）盖在全页，落在黑墨上就是针孔。
- **号外章**：208×132 红块、旋转 −0.08，字用纸色 86px 反白。

## 4. 动作语言

- **转报纸**：0–2 秒，缩放 0.03→0.64（指数 1.3），旋转 −5π→0，用 `1 − (1 − p)^2.2` 减速，最后一刻才停稳。
- **砸下**：落定、号外章、每份加印落下时，画面抖 0.18 秒、最大 7px。号外章从 2.2 倍 `back` 缩回（0.16 秒）。
- **活照片**：柯基每拍上下点 5px；叫声在 5.0 / 6.0 / 7.5 / 8.0 秒，嘴按 0.32 秒的正弦张开，耳朵同时外翻；观众头按拍子交替起伏 6px；7.0 秒闪光（白色 85% 按平方衰减 0.5 秒）。
- **打字**：图注 4.5–5.5 秒逐字出现；政见每行 0.45 秒，分别从 9.0 / 9.6 / 10.2 秒开始。
- **加印**：4 份报纸分别从 12.0 / 12.25 / 12.5 / 12.75 秒起飞，0.28 秒 `easeOut` 落到各自略歪的位置，最后一份端正压在最上面。

## 5. 镜头语言

镜头 = 在版面上移动的放大镜，用 `keyframes` 描述（中心 x、y、缩放）：全版 0.64 → 微推 0.7 → 照片 1.3→1.55 → 柯基脸 4.6→5.0 → 政见框 1.45→1.55 → 全版 0.6 → 0.56 → 0.62。镜头之间一律 `ease` 平移，不硬切——读报的感觉是“视线移动”。

## 6. 声音

- 配乐：号外进行曲 / 拉格泰姆，C 大调 120 BPM。开场 0–3.75 秒印刷机八分音符“咔嚓”渐强 + 1–2 秒军鼓滚奏 + 噪声 riser，落定时 `impact` + 镲 + 铜管 C 大三和弦；之后“嘭–恰”：低音在 1、3 拍，铜管短和弦和军鼓在 2、4 拍，八分踩镲；2.5 秒和 6.5 秒各一句铜管号角旋律。
- 音效和画面同步：号外章 = 印刷机重击 + G 和弦；每个打出来的字一下打字机 `clack`（按键声 + 2400Hz 噪声 + 180Hz 低频），行末 `ding`；柯基叫 = 锯齿波 420→190Hz 过 900Hz 带通；闪光 = `pop` + 高通噪声；镜头大移动配 `whoosh`；每份加印 = `swish` + 重击 + 逐次升高的铜管短音；13 秒结尾长和弦 + 镲 + 低音。

## 7. 文字与标题

大标题两行、每行 6 个字，主谓宾讲完一件事；报头 5 个字以内；照片必须有图注（“图：……”）；要点框最多三条、每条 10 字以内，用“一、二、三、”。正文一律用灰块代替，不写真字。所有名字（报纸、街道、候选人）都是编的。

## 8. 踩过的坑

- 照片一开始整体歪成一条斜带、柯基也是斜的：采样时已经把 45° 网格换算回照片坐标，画点时又 `rotate(45°)` 了一次。去掉第二次旋转就正了。
- 网点化以后柯基认不出来，只剩一个白三角：毛色 160 和背景楼 140 太接近。把楼压到 112、天空提到 246，给头 / 耳 / 身体加 5px 深描边，暗度加 1.2 的伽马，网距 8→7，轮廓才出来。
- 眼睛半径 9 只占两三颗点，推近时看不到：放大到 13 并加高光。
- 响度第一次测是 −19.0 LUFS（压着下限但合格）：印刷机重击和 `impact` 的峰值让 loudnorm 抬不上去；如需更响，先降这些瞬态再出片。

## 9. 制作流程（本仓库）

1. 改版面在 `page()` 里（页面坐标 1160×960），改照片在 `scene()` 里（照片坐标 ±290 × ±185，只用灰度），改镜头在 `draw()` 的 `keyframes` 表里。
2. 抽帧检查：`node _engine/render.cjs halftone stills 0.8,2.2,3.2,4.8,6.2,7.5,9.8,12.4,13.4`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "halftone/stills/*.jpg" -vf "scale=640:360,tile=3x3:padding=6:color=white" -frames:v 1 /tmp/half.jpg`
4. 出片：`node _engine/render.cjs halftone` → `demo.mp4` + `poster.jpg`（封面 13.4 秒，一沓报纸 + 全版）。

## 10. 引擎用法

- `scene(g, t)`：在照片坐标里画灰度画面（可以动，是 t 的函数）。
- `photoDots(t)`：把 `scene` 画进 112×112 的离屏小图（带 −45° 旋转），`getImageData` 读灰度 → 返回 [x, y, r, …]；每帧只算一次，所有报纸共用。
- `page(c, t, v, dots, F)`：画一整份报纸；`v` 是第几份（0 = 主报纸，1–4 = 加印），决定红版错位、拖墨距离和打字是否已完成。
- `greek(c, x, y, 宽, 行数, 行距, 种子)`：灰块假正文。`txt(…)`：思源宋体排字（支持字距）。
- 时间常量 `LAND / STAMP / CAP / BARKS / FLASH / PLANKS / COPIES` 在画面和 `score()` 里共用。
