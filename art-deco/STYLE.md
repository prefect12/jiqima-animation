# 装饰艺术 — 风格提示词（v1）

> 深色墙面上的金色细线：阶梯形门框、放射纹、半圆楼层指针、扇形壁灯，一切左右对称。一部老式电梯从一楼升到顶楼，每停一层，雕花铜门滑开就是另一场派对：爵士乐队、香槟塔、舞会，最后推门进入满天烟花的屋顶。适合高端品牌、酒店 / 活动邀请、年会开场、复古奢华主题。
> 样片：《电梯直达顶楼》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **装饰艺术** 风格做一支“一扇门后面一个世界”的短片。用户给你一个主题，你设计一个对称的金线建筑立面（门、拱、指示盘），然后按拍子让门打开 3–4 次，每次门后是一个颜色不同的小场景，最后一次镜头穿过门，落在标题上。

---

## 1. 这个风格是什么

1920–30 年代的装饰艺术（Art Deco）是机器时代的奢华：几何化、对称、阶梯状的轮廓，扇形与放射纹（日出、喷泉），金 / 黄铜细线勾在黑色或深色漆面上。它不画写实细节，而是把一切变成**图案**——人是剪影，灯是扇子，楼是阶梯。动画里要保持“庄重的对称”，所有运动都沿中轴展开，节奏跟着摇摆大乐队。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **中轴展开** | 开场整座立面从中线向两边擦出，像幕布拉开。 |
| **楼层指针** | 门上方的半圆表盘（1–12）指针随电梯上升扫动，当前楼层的数字发光，上行箭头亮起。 |
| **铜门滑开** | 两扇门各带半个放射纹圆盘，向两侧滑进墙里，门缝先露出一道彩色光。 |
| **门后一个世界** | 每层一个主色 + 一个剪影场景：翡翠绿爵士乐队、酒红香槟塔、深蓝舞会、紫夜屋顶。 |
| **光溢出** | 门开时，门后场景的颜色洒到门前地面上。 |
| **穿门而出** | 最后一层镜头推进 2.15 倍，门框退到画外，屋顶景色铺满画面，金色标题浮现。 |

**结构（144 BPM，一小节 ≈ 1.67 秒，全片 9 小节）**：立面展开（4 拍）→ 上行（2 拍）→ 三楼开门、停 4 拍、关门 → 上行 → 六楼 → 上行 → 九楼 → 上行（带 riser）→ 顶楼开门 → 推进（2 拍）→ 标题 → 淡出。
适合“层层递进、最后揭晓”的内容：楼层、章节、年份、菜单。每一层只放一件事，别塞字。

## 3. 视觉语言

- **颜色**：金 `#D4AF5A`、亮金 `#F3DD95`、暗金 `#8E6E2E`；墙 `#0C1214`、嵌板 `#141C1F`、铜门 `#1B2124`（门面横向渐变 `#12171A → #262D31 → #12171A`）。
- **派对主色**：爵士 `#0D3A32`（翡翠绿）、香槟 `#4A1422`（酒红）、舞会 `#15203D`（深蓝）、屋顶夜空 `#080C26 → #2B1C48`。门前地面的溢光分别用对应的浅色、35% 透明。
- **线**：主结构 1.5–3px 金线，装饰细线 1px；墙面每 22px 一根 10% 透明的竖向凹槽线；表盘后面 37 根放射线（半径 118 → 640，35% 透明）。
- **立面**（1280×720 内完全左右对称）：门洞 400×440 位于 (440, 240)；三层阶梯门框（外扩 14 / 28 / 42px，中间一层 3px）；两根凹槽壁柱（330–380、900–950，顶部三层叠檐）；两块侧墙嵌板（70–270、1010–1210），各挂一盏扇形壁灯（半径 60、8 根扇骨、190px 暖光）和底部四道人字纹；顶部一条锯齿饰带。
- **铜门**：两扇各 200 宽，金线内框；合起来是一个半径 130 的双圈放射纹圆盘（36 根线长短交替），圆心在门缝上；下方五道人字纹。
- **表盘**：圆心 (640, 190)、半径 100 的半圆，数字 1–12 用 Limelight 18px 排在半径 74 上，指针长 58；表盘下方 200×30 铭牌写当前楼层名。
- **字体**：Limelight（表盘数字）、Poiret One（英文小标题）、站酷小薇 ZCOOL XiaoWei（中文铭牌 18px 字距 4；标题 150px 字距 40，金色竖向渐变 + 20px 投影）。
- **质感**：颗粒 0.05，纯黑暗角 0.55。

## 4. 动作语言

- 所有动作都落在拍子上（一拍 0.417 秒）：开门 / 关门各 1 拍，上行 2 拍，门开着停 4 拍。
- **门**：`ease` 滑开，两扇门同时向外移、被门洞裁掉，像滑进墙里。
- **指针**：楼层用 `keyframes` 插值，指针连续扫过；最近的整数楼层发光（`shadowBlur 12`）。上行时整体上下颤 1.2px，箭头灯亮。
- **门后**：乐手每拍点头 6px、小号每两拍抬起一次；香槟气泡持续上升，每拍一个星形闪光；舞会两对舞伴每拍转半圈（横向缩放最小 0.35），吊灯 ±0.03 弧度轻摆，金色纸屑飘落；屋顶从第 30.5 拍起每拍一朵烟花（16 根放射线，1.1 秒散开下坠）。
- **推进**：第 31–33 拍以 (640, 460) 为中心 `ease` 放大到 2.15 倍；第 32.5 拍标题淡入，两侧双金线向外生长 260px。

## 5. 镜头语言

正面、居中、对称的固定机位，像站在电梯厅里等电梯；整片只有一次镜头运动——最后穿过门的推进。门洞就是“画中画”，所有场景都在门洞的 400×440 里完成构图（人物、吊灯、塔都放在中轴附近）。

## 6. 声音

- 配乐：摇摆大乐队，144 BPM，切分在 2/3 拍。和弦 F6 – D7 – Gm7 – C7 每小节一个；行走贝斯每拍一音；叮当镲每拍 + 切分、军鼓轻点 2、4 拍、底鼓 1、3 拍；钢琴在“2 拍后半”和第 4 拍垫和弦。
- **编曲跟着门走**：门关着时只有节奏组（像隔着门听），门一开铜管就进来——三楼小号独奏、六楼开瓶 `pop` + 四声碰杯（2400→3300Hz 正弦）、九楼铜管齐奏 + 拍手、顶楼六声部 F 和弦 + `impact`。
- **电梯**：上行时 70→130Hz 正弦嗡声；到站“叮–咚”（`bell` 88 → 84，间隔 0.18 秒）；开关门是低通噪声 500→200Hz 的滑动声。
- **屋顶**：每朵烟花一次低通噪声爆裂（1800→300Hz）+ 噼啪；顶楼前 2 拍一个 `riser`；第 34 拍（14.17 秒）F6/9 收尾和弦 + 高音铃 + 镲。

## 7. 文字与标题

画面里的字只出现在两个地方：门上方铭牌（“一楼 · 大堂”“三楼 · 爵士乐队”“六楼 · 香槟塔”“九楼 · 舞会”“顶楼”）和最后的标题（“顶楼” + “THE ROOF”）。铭牌每层 2–6 个字，中文用间隔号分开；标题只用 2 个字，大字距，金色渐变。楼名、建筑都是虚构的。

## 8. 踩过的坑

- 第一版立面只占画面中间 600px，两侧是大片空黑墙，显得小气：加了侧墙嵌板、扇形壁灯和暖光、人字纹、顶部锯齿饰带，对称感和“满”的奢华感才出来。
- 结尾推进到 1.9 倍时，门上铭牌被画面顶边切掉一半，月亮也和“顶楼”两个字撞在一起：推进改到 2.15 倍让门框上沿完全出画，月亮挪到左上，烟花限定在左右两个区域（不压标题）。
- 舞会的舞伴转身时横向缩放降到 0.15，看起来像一根竖线：最小缩放提到 0.35，并把人物放大到 1.2 / 0.95 倍。

## 9. 制作流程（本仓库）

1. 在 `STOPS`（开门拍、关门拍、楼层、铭牌）和 `FLOOR`（楼层关键帧）里排时间，全部以拍为单位（`b(n)` = 第 n 拍的秒数）；`SCENES` 里每层一个场景函数，坐标是门洞内的 0–400 × 0–440。
2. 抽帧检查：`node _engine/render.cjs art-deco stills 0.8,2.2,3.5,5.4,6.8,9.9,11.5,13.0,14.2`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "art-deco/stills/*.jpg" -vf "scale=640:360,tile=3x3:padding=6:color=white" -frames:v 1 /tmp/deco.jpg`
4. 出片：`node _engine/render.cjs art-deco` → `demo.mp4` + `poster.jpg`（封面 7.0 秒：酒红香槟塔在金色立面里）。

## 10. 引擎用法

- `architecture(c, t, F, open, 楼层, 是否上行)`：墙、嵌板、壁灯、阶梯门框、壁柱、表盘、铭牌底、地面。
- `frameSteps(c, 外扩)`：阶梯门框轮廓（三层嵌套各调一次）。
- `doorFace(c)`：两扇门合起来的整幅图案，开门时各自平移并裁到自己那一半。
- `jazz / champagne / ballroom / roof(c, t, F)`：四个派对场景，门开时裁在门洞里绘制。
- `b(n)`、`STOPS`、`FLOOR`、`PUSH`、`TITLE`：画面和 `score()` 共用的拍点表。
