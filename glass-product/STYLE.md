# 玻璃质感产品 — 风格提示词（v1）

> 深色无缝棚里，一只虚构的玻璃香水瓶慢慢自转：条形灯从左后方绕到正面再转到右后方，高光带扫过瓶身，逆光时光在玻璃里折成一道彩虹，地板上落下带彩边的焦散。最后字卡“折光”。
> 样片：《折光》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **玻璃质感产品** 风格给一个虚构的透明产品（香水、玻璃杯、手机背板、护肤品瓶）拍一支 15 秒的发布片。不写真实品牌，不仿真实瓶型；用户给你产品和一句卖点，你用“灯怎么走”来讲故事：先勾轮廓，再扫高光，最后逆光出彩虹，收在字卡上。

---

## 1. 这个风格是什么

高级产品广告的“暗场布光”：背景接近黑，玻璃本身几乎没有颜色，它的形状完全由**光**画出来——轮廓上的细亮线、表面上扫过的高光带、厚玻璃内侧的暗带、透过瓶身看到的被颠倒压缩的背景，以及光穿过玻璃后在地面上聚成的焦散。镜头慢、动作少、声音稀，每一次“叮”都对应一次光的事件。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **轮廓先出现** | 灯还没亮时只有一圈冷色轮廓光从黑里浮出来，建立悬念。 |
| **扫光** | 一根条形灯绕着产品走，高光带从一侧扫到另一侧——这是产品片最经典的镜头。 |
| **逆光彩虹** | 灯转到产品后面时，光在玻璃里色散：瓶身里一道竖向彩虹，地面上一块带彩边的焦散。放在高潮。 |
| **字卡** | 产品让到右边，左边留白写名字和品类。 |

**结构**：黑场 + 轮廓光（1.7 秒）→ 条形灯在左后方亮起（叮）→ 灯经过正面，高光带横扫瓶身（叮）→ 灯转到右后方，逆光：瓶内彩虹 + 地面焦散 + 瓶肩星芒（两声叮 + shimmer）→ 镜头右移，字卡“折光 / EAU DE PARFUM · 50 ML” → 淡出。

## 3. 视觉语言

- **背景**：竖向渐变 `#07080C → #161A24（42%）→ #141821（50%）→ #0C0E14 → #030305`，没有硬地平线；瓶子身后一团 `rgba(58,68,92)` 的径向柔光，灯亮后加强。
- **条形灯**：灯在瓶子后半圈时直接可见——三层横向高斯（宽 1× / 2.4× / 5×，亮度 .75 / .22 / .08），顶端 60px 渐隐；地板上的倒影分 14 条横向柔边的色带逐渐变淡。
- **瓶型**：截面是圆角矩形（半宽 0.7、半深 0.36、圆角 0.2），沿周长取 72 点；瓶身高 1.5，肩部斜面收到 45%，瓶颈半径 0.16，瓶盖是 16 棱金属柱（半径 0.3、高 0.5）。厚底 0.18，内腔按 86% 缩放，液面在 1.1。
- **玻璃的六层画法**（从下往上）：
  1. 折射：瓶身范围内把背景**左右颠倒并缩小到 0.5**（液体里 0.34）再画一次——瓶后很宽的一片被“收”进瓶身，灯条在瓶里朝反方向走。
  2. 透过玻璃看见的后壁：后半圈底边、肩线、四条转角竖线，`rgba(170,190,220,.16–.22)`。
  3. 液体：玫瑰金竖向渐变 `rgba(255,196,168,.5) → rgba(190,92,96,.7)`，左右两侧各 18% 压暗成圆柱感；液面前缘一条 1.6px 亮线，跟着灯走一条竖向亮带。
  4. 外壁每一段：法线·视线 ≈ 0.32 处一条暗带（厚玻璃的全反射，最深 .5）；边缘菲涅尔亮 `(1 − n·v)^5`；条形灯高光 = 反射方向与灯方位角之差的高斯，锐 0.06 弧度 + 柔 0.22 弧度（×0.22）两层，总亮度封顶 0.78；锐高光 > 0.3 时左右各加一条红 / 蓝细边（色散）。
  5. 内腔轮廓一圈淡线（玻璃壁厚度）、厚底一层偏亮的实色、肩线前半圈亮线。
  6. 外轮廓两层描边：6px 淡光晕 + 1.3px 亮线，逆光时加亮。
- **瓶盖**：每个棱面单独平涂，颜色 = 基色 × (0.28 + 0.42·n·v) + 条形灯反射 + 固定的左侧补光，棱面内上亮下暗。
- **逆光彩虹**：用 `screen` 叠在瓶身里，一条 92px 宽、微斜的红橙黄绿蓝紫渐变带，亮度 .62 ± .1 轻轻闪。
- **焦散**：落在灯的对面地板上；同一个图案（椭圆亮斑 + 4 条慢慢游动的弧线）按红、绿、蓝各画一遍并横向错开 4–16px，用 `lighter` 叠加——重叠处是白的，边缘自然出彩虹。
- **地板倒影**：瓶子整体上下翻转、透明度 .2，再用 230px 的黑色渐变盖住。
- **字体**：思源宋体 Light（Noto Serif SC 300）96px `#EDEFF5`；品类用 Cormorant Garamond 500 24px，字距 6px `#B9BFCC`；中间一条 1.5px 金线 `rgba(214,184,120,.9)`。

## 4. 动作语言

- 瓶子匀速自转 0.2 弧度/秒（15 秒约 170°），不加速、不停顿。
- 条形灯方位角（0 = 相机方向）：−150°（左后）→ 1.7 秒亮起 → 3.4 秒 −115° → 7.7 秒 +115°（扫过正面）→ 8.6 秒 +148°（右后，逆光）→ 15 秒 +160°，每段 `ease`。
- 逆光程度 = 灯越过 ±100° 后 40° 内从 0 到 1；高潮之前只给 40%，把完整的彩虹留给 8.6 秒。
- 高潮瞬间瓶肩一颗三芒星（高斯包络 0.4 秒）。
- 字卡：文字从左 30px 处 `easeOut` 滑入并淡入 1 秒，金线随后展开。

## 5. 镜头语言

几乎不动的产品机位（透视，相机距离 6.2、高度 1.02）。前 8.6 秒极慢推近 7%；字卡前后 1.5 秒内镜头右移 190px、退后 7%，把左边让给文字。

## 6. 声音

- 70 BPM。柔和锯齿 pad Dmaj9 – Bm9 – Gmaj7 – A6（1000Hz 低通），次低音垫底；扫光时五个很轻的上行琴音。
- **玻璃叮**：自建四个不协和正弦分音（×1 / 2.32 / 4.25 / 6.1，衰减 1.6 / .9 / .5 / .3 秒）——灯亮、高光扫过正面、高潮（两声 2350 + 3520Hz）、字卡各一次。
- 灯亮前 `click`；扫光开始和结束各一阵轻 `whoosh`；高潮前 1.2 秒 `riser`，高潮时两次 `shimmer` + 次低音 + 四个高音铃。

## 7. 文字与标题

只有结尾字卡：产品名两个字 + 一行品类 / 容量。不写真实品牌、不写广告语。

## 8. 踩过的坑

- **像扁平插画**：第一版瓶子小、截面只有 48 点、只有一层半透明填色，看起来像矢量图标。重写成六层（折射、后壁线、液体、暗带 + 菲涅尔 + 高光、内腔线、双层轮廓），截面加到 72 点，瓶子放大。
- **背景里有一条地平线**：渐变色标在 49% / 50% 之间跳色，像桌子边。改成连续的无缝棚渐变。
- **灯的倒影像一个台子**：地板倒影用纵向渐变的矩形，左右是硬边。改成 14 条横向柔边的色带。
- **焦散像光盘**：整圈七彩的大椭圆太假。改成同一图案按 RGB 三色错开叠加，只在边缘出彩。
- **瓶里的彩虹看不见**：渐变是在平移之前的坐标里建的，填充时落在画布外。渐变坐标要在 `translate` 之后的空间里定义。
- **折射看不出来**：背景放大 1.4 倍后，灯条被推到瓶身外面。改成缩小到 0.5，灯条就出现在瓶里、而且反着走。
- **高潮不“高”**：开场灯本来就在左后方，彩虹一开始就满强度。开场逆光压到 40%。
- **整面糊白**：平面正对灯时整面变纯白，高光亮度封顶 0.78。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部改时间常量（`T_ON`、`T_SWEEP`、`T_BACK`、`T_CARD`，都是拍号 × `BEAT`）和灯的路径 `lightAz`；`score()` 用同一组常量排玻璃叮。
2. 抽帧检查：`node _engine/render.cjs glass-product stills 0.9,2.4,4.2,5.4,6.6,7.8,8.9,10.4,12.8`
3. 出片：`node _engine/render.cjs glass-product` → `demo.mp4` + `poster.jpg`（封面 9.3 秒：逆光彩虹 + 焦散）。

## 10. 引擎用法

- `P(x, y, z)`：产品机位的透视投影；`ring(y, 缩放)`：旋转后的截面环（位置 + 法线）。
- `specOf(法线, 位置, 宽度)`：条形灯镜面高光（视线绕法线反射后与灯方位角比较，高斯衰减）。
- `refract(轮廓, 缩放, 透明度)`：在凸包里把背景画布左右颠倒、缩放后再画一次。
- `backArc(环, 颜色, 线宽)`：只描背对相机的那半圈（后壁线）；同样的循环反过来描前半圈亮线。
- 两张离屏画布：`BG`（背景 + 灯条，也是折射的来源）、`BOT`（瓶子本体，也用来画地板倒影）；合成顺序：背景 → 倒影 → 渐隐 → 焦散 → 瓶子 → 星芒 → 字卡 → 颗粒 / 暗角。
