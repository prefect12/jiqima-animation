# 1930s 橡皮管卡通 — 风格提示词（v1）

> 棕褐色的老胶片，划痕、灰尘、闪烁；一片吐司长着面条一样的手脚、戴着白手套，从烤面包机里“叮”地弹出来，跟着拉格泰姆钢琴跳舞，顺手给自己抹上黄油。画面里所有东西——钟、窗帘、茶壶、花盆——都在跟着拍子一上一下地弹。
> 样片：《黄油吐司舞》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **1930s 橡皮管卡通** 风格拍一段欢乐的小默剧。用户给你一个物件（食物、日用品、产品），你把它变成一个原创的橡皮管角色，让它“出场 → 跳舞 → 用一个道具做一件和自己有关的事 → 亮相”，全片踩在一个摇摆的拍子上。

---

## 1. 这个风格是什么

早期有声卡通的样子：角色的手脚是没有关节的软管，手上戴四指白手套，眼睛是“饼切眼”（黑色瞳孔缺一角），整个世界随着音乐一起弹跳。它的质感一半来自画（粗黑线、平涂、白手套），一半来自“片子本身”：棕褐色调、每帧轻微晃动的片门、竖向划痕、灰尘毛发、明暗闪烁、光圈开合。角色是原创的吐司，没有圆耳朵、没有短裤、不借任何已有角色的造型。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **字幕卡开场** | 双线边框 + 四角星的奶油色卡片，一行大标题、一行小字，然后光圈打开进场景。 |
| **物件活过来** | 吐司在烤面包机里闭着眼“睡觉”，机器抖三下、冒气，“叮！”弹出，空中翻一圈落地才睁眼。 |
| **全场踩拍** | 所有背景物件在拍点上压扁、两拍之间上弹，相邻物件相位错开半拍，画面像在呼吸。 |
| **道具飞进手里** | 黄油盒盖掀开，黄油刀带着一块黄油转着圈飞过来，被白手套接住。 |
| **一拍一个动作** | 抹黄油五拍抹五下，每下黄油多一片；跳起翻身落地，摆“当当！”造型，眨一只眼。 |
| **光圈收尾** | 光圈收到角色脸上，黑场出“完”。 |

**结构（120 BPM，一拍 0.5 秒）**：字幕卡（0–1.0）→ 光圈打开（1.0–1.6）→ 面包机抖三拍（1.5 / 2.0 / 2.5）→ 叮！弹出（3.0）→ 落地睁眼（4.0）→ 挥手（4.5）→ 查尔斯顿踢腿舞（5.0–8.0），盒盖掀开（6.75），刀飞来（7.0），接住（7.5）→ 抹黄油 8.0 / 8.5 / 9.0 / 9.5 / 10.0 → 跳起翻身（10.5–11.5）→ 亮相 + 星星（11.5）→ 眨眼（13.0）→ 光圈收拢（13.4–14.1）→ “完”（14.1）→ 淡出（14.5）。

## 3. 视觉语言

- **调色**：只用六个棕褐色：纸 `#EFE4C9`、浅 `#D9CBA8`、中 `#A8977A`、深 `#5E5140`、墨 `#16120D`、白 `#FBF7EC`；吐司皮 `#8C6F48`、瓤 `#E4D2A8`、黄油 `#FFF6D6`。最后整屏用 `color` 混合叠一层 `rgba(150,118,72,.55)`，把所有颜色统一成棕褐。
- **线条**：黑色描边 3–5px，圆角圆头；角色外轮廓 7px（先描 14px 再填色，盖掉内部重叠的线）。
- **场景**：竖条纹壁纸（每 48px 一条 20px 宽的 `#CDBD98`）、挂镜线、带窗帘的窗、带钟摆的挂钟、搁架上的茶壶和糖罐、台面木纹（6 条正弦线）、花盆、黄油盒。
- **角色**（放大 1.3 倍）：面包形身体 = 圆角矩形 + 三个圆；瓤上 16 个气孔（初始化时随机）；白色大眼眶里是饼切眼；大笑嘴里有舌头；橡皮管手脚 9px 黑线，用一条二次曲线，**没有肘和膝**；手套 = 4 根香肠手指 + 拇指 + 手掌 + 三道手背线 + 喇叭口袖口；大椭圆黑鞋带高光。
- **字体**：标题和“叮！”用站酷庆科黄油体（ZCOOL QingKe HuangYou），英文小标用 Limelight，“完”和副标题用 Noto Serif SC 900。
- **胶片**：颗粒 0.1、暗角 0.7（`20,14,8`）；片门每 1/24 秒随机偏移 ±1.5 / ±2px；明暗闪烁 ±6%；最多 3 条竖划痕（有的持续 2–4 帧，亮 / 暗两种）；每帧最多 6 个灰尘点，偶尔一根毛发曲线。

## 4. 动作语言

- **一拍二**：角色和物件的动作按 12 帧/秒取整（`t = floor(t·12)/12`），胶片效果按 24 帧/秒，顿挫感就是这个时代的味道。
- **全场弹跳**：`hop(相位) = |sin(π·(拍 + 相位))|` 控制上弹（10px × 幅度），`squash(相位) = |cos(...)|⁶` 控制拍点压扁（6% × 幅度）。窗户 0、钟 0.5、花盆 0.25、茶壶 0、糖罐 0.5、黄油盒 0.5，互相错开。
- **角色**：跳舞时每拍身体上弹 22px、拍点压扁 10%；落地和亮相瞬间压扁 22% 再 0.25 秒回弹。
- **查尔斯顿**：左右脚轮流向外上方踢（踢出 40px、抬高 50px），两只手反向上下甩 50px。
- **抹黄油**：右手举过头顶来回刮，一拍一个来回；手臂向外弯（不要横穿脸），黄油从头顶往下一层层盖，下沿是波浪形滴落边，右上一道白高光。
- **弹出 / 跳起**：抛物线 + 空中整圈旋转；空中手脚张开。

## 5. 镜头语言

固定机位，舞台式构图：台面在 y = 540，角色站在正中偏右，烤面包机在左，背景物件左右对称分布。只用光圈（iris）开场和收尾：开场从画面中心打开 0.6 秒，收尾收到角色脸上 0.7 秒。

## 6. 声音

- 拉格泰姆，120 BPM：C – A7 – D7 – G7。左手“嘭-恰”跨步（1、3 拍低音，2、4 拍和弦），右手切分旋律，从第 3 小节起叠一支低八度的铜管（圆号感）。第 2 小节起刷子军鼓（2、4 拍）+ 摇摆 hi-hat（落在每拍的 2/3 处）。
- 5.0 / 7.0 / 9.0 秒钢琴八度大跳。
- 片头：钢琴上行琶音 + 两声铜管。
- 面包机：每拍 `rim` 两下 + `tom`；叮：`ding` + `bell`。
- 滑哨：自己用 `B.sfx.context` 搭一个正弦振荡器（7Hz 颤音）做指数滑音——弹出时上滑 400→1600Hz，下落时下滑；跳起翻身同样一上一下；光圈收拢时一声长下滑。
- 落地 / 接刀：`boing`；跳舞每拍一个木鱼（`rim`）；抹黄油每下 `squash` + `paper`；亮相 `chime` + 铜管和弦；“完”钢琴收尾和弦。

## 7. 文字与标题

- 只有三处文字：片头字幕卡（“黄油吐司舞” + “一出原创小卡通”）、“叮！”爆炸框、片尾“完”。
- 字幕卡要有这个年代的装饰：双线圆角框、四角四芒星、标题上方一行英文小标。
- 拟声字放进锯齿爆炸框里，稍微倾斜。

## 8. 踩过的坑

- 第一版吐司太小，伸出的手和背景茶壶叠在一起分不清；角色放大 1.3 倍，搁架整体右移。
- “叮！”一开始放在四芒星里，字比星大、又正好在吐司飞行路线上；换成 24 角锯齿爆炸框，挪到面包机左边。
- 角色放大后，还在面包机里的吐司从机器底座下面露出来；在面包机里时按台面高度裁切，并把它往上提，让面包顶从槽口露出一截。
- 抹黄油时右臂从右肩斜穿过整张脸去够左边，脸被一条黑线切开；改成手只在头顶右半边来回，手臂向外弯。
- 黄油体里的“完”字形太花，乍看不像“完”；“完”和副标题换成 Noto Serif SC 900。

## 9. 制作流程（本仓库）

1. 在顶部定时间表（`RATTLE`、`POP`、`LAND`、`DANCE`、`KNIFE`、`SPREAD`、`JUMP`、`TADA`、`IRIS_OUT`）；关键动作都落在 0.5 秒的整数倍上。
2. 抽帧：`node _engine/render.cjs rubber-hose stills 1.3,2.4,3.3,3.7,4.6,6.2,7.4,9.25,12.2`
3. 出片：`node _engine/render.cjs rubber-hose`

## 10. 引擎用法

- `bouncy(x, y, 相位, 幅度, fn)`：把任何物件包进“随拍弹跳”里。
- `hose(x0, y0, x1, y1, 弯度)`：橡皮管手脚；`glove(x, y, 角度)`：白手套；`shoe(x, y, 朝向)`：大鞋。
- `toastState()` / `drawToast(S)`：吐司的位置、旋转、压扁和姿势（腿 → 身体 → 黄油 → 脸 → 手臂 → 刀）。
- `knife(x, y, 角度, 黄油量)`、`burst(...)`（锯齿爆炸框）、`star(...)`（四芒星）。
- `film()`：棕褐统一 + 闪烁 + 划痕 + 灰尘 + 颗粒 + 暗角；`titleCard()`：片头字幕卡。
- 滑哨 `slide(w, B, 起始频率, 结束频率, 时长)` 写在 `score()` 里，用 `B.sfx.context` 自建振荡器。
