# 瑞士国际主义排版 — 风格提示词（v1）

> 12 栏 × 6 行的可见网格，红、黑、米白三色，Inter / 思源黑体无衬线大字，所有元素沿网格滑入、在拍点上落位；一块红色面板里反白的巨大数字被面板边缘裁切。适合讲座 / 展览 / 发布会海报、品牌规范演示、信息清晰的片头。
> 样片：《网格之后 · 设计讲座 07》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **瑞士国际主义排版** 风格做一张“自己排出来”的海报。用户给你一个活动的信息（名称、日期、地点），你先在 12 × 6 的网格上定好最终版式，然后让网格先出现、元素一个拍子一个拍子落进格子；中段让版式按网格换三种排法，最后回到定稿、网格退场。

---

## 1. 这个风格是什么

1950–60 年代瑞士平面设计的核心是**网格和秩序**：所有东西都对齐到看得见（或看不见）的栏和行，字体是中性的无衬线体，颜色克制到只有红、黑、白，靠字号对比和大面积留白制造张力。动起来时，它不“飞”也不“弹”，而是像机械一样沿水平、竖直方向滑动、咔嗒落位。观众的快感来自“一切都刚好对齐”。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **网格先行** | 开场 1.5 秒只画网格线和栏号、行号，告诉观众“规则在这里”。 |
| **一个模块走格子** | 一个红色单元格出现在右下角，按拍子先竖着走到顶、再横着走到第 8 栏，然后长成整块红色面板。 |
| **遮罩升起** | 每段文字都在自己的格子里从下往上升起（或标题从左往右滑入），格子外看不到。 |
| **裁切大字** | 巨大的“07”反白印在红面板里，被面板边缘裁掉一截，面板变形时裁切也跟着变。 |
| **版式变奏** | 同一组信息在一小节里换三种网格排法（红块在左 / 红块横在顶部 / 红块缩成窄栏），最后回到定稿。 |
| **网格退场** | 定稿后网格线按顺序缩回，只剩干净的海报。 |

**结构（120 BPM，一拍 0.5 秒）**：网格（3 拍）→ 红模块走格子并长成面板（4 拍）→ “07”（1 拍）→ 标题四个字（每字半拍）→ 规线、英文副标、日期、星期时间、地点、系列名（每项 1 拍）→ 变奏 B / C / D / 回到 A（每种 2 拍）→ 定稿 + 网格退场 + 红色小方块点题 → 淡出。
适合信息量“少而硬”的内容：一个标题、一个日期、一个地点。长段文字、情绪故事不适合。

## 3. 视觉语言

- **颜色**：纸 `#F2F0EB`、黑 `#111111`、红 `#E30613`；网格线 `rgba(17,17,17,.24)`、1px。只允许这三色 + 网格灰。
- **网格**：外边距 40，栏距 / 行距 16；12 栏每栏 85.33px，6 行每行 93.33px。栏号 01–12、行号 A–F 用 Inter 400 11px、40% 黑，写在边距里。
- **字体**：拉丁用 Inter（900 / 700 / 400），中文用思源黑体 Noto Sans SC（900 / 500）。
  - 标题“网格之后”900、150px、字距 −4%（变奏 B 140px、D 196px）。
  - “07”Inter 900、360px、字距 −18px，纸色，裁切在红面板里。
  - 日期“10.17”Inter 900、104px、字距 −5px；英文副标 700、36px；星期 28px（中文 500 + 时间 Inter 700）；地点 28 / 28 / 22px（第三行“免费入场”红色）；系列名 20px。
- **定稿版式 A**：红面板占第 8–12 栏 × 全部 6 行；标题在第 1 栏基线 336；规线 6px 从第 1 栏到第 7 栏、y=430；日期块在第 1 栏，地点在第 5 栏。所有左边缘都落在栏线上。
- **节拍器**：右下角 4 个 10px 小方块，当前拍亮红色，其余 25% 黑。

## 4. 动作语言

- **只走直线**：红面板变形时先动 x、再动 y（各占 0.4 秒的一半，`ease`），像在格子里挪。
- **遮罩升起**：文字在自己的格子里从下方 1.2 倍字高处升起，0.32 秒 `easeOut`；遮罩高度 = 字高 × 1.04，不能更高，否则会漏进下一行。
- **标题逐字滑入**：每个字 0.25 秒一个，从左边滑进自己的字框。
- **变奏换位**：文字先在 0.18 秒内向上缩出遮罩（`easeIn`），红面板同时走格子，0.2–0.45 秒文字再从新位置升起；规线同步缩短再伸长。
- **落位点缀**：红色小模块出现时 `back` 弹一下（0.2 秒）；结尾 16px 红方块同样弹出。
- **网格**：竖线自上而下画出、横线自左而右画出，每根 0.5 秒、依次错开 0.045 秒；退场时反向缩回，错开 0.03 秒。

## 5. 镜头语言

完全固定，画面就是海报本身，四周是 40px 的边距。不推不摇，不做景深；所有“运动”都来自元素在网格里的位移。

## 6. 声音

- 配乐：极简电子，120 BPM。节拍器贯穿全片（每拍一下 1500Hz 正弦短音，每小节第一拍 2200Hz 重音，外加一个极短方波“咔”）；第 2 小节起次低音（`subbass`）在 1、3 拍，底鼓轻打；4–12 秒十六分踩镲；8–12 秒三角波琶音（A–C–E–G–E–C，后半段升两个半音）；4–12 秒 Am / G 两个 pad 和弦。
- 每个元素落位配一个正弦 `blip`，音高随搭建顺序往上走（72 → 91）；标题四个字是 79 / 81 / 83 / 86；红面板变大是 `thud` + `whoosh`；规线是 `whip`。
- 变奏：每次换版 `whip` 两下（x 段、y 段）+ 落定 `thud` + 一个音。
- 定稿：`impact` + A 小调和弦长音，网格缩回时 12 下 `tick`；红方块 `blip`；14 秒再补一个高位和弦收尾。

## 7. 文字与标题

中文标题 2–4 个字，英文副标照直译；日期用“月.日”数字，星期和时间分开两种字体；地点最多两行 + 一行红色补充。所有文字左对齐、落在栏线上，不居中、不倾斜。讲座内容、学院名都是虚构的。

## 8. 踩过的坑

- 最初变奏时让所有文字也“先 x 后 y”地走格子，结果英文副标横穿标题那一行、“07”盖住地点，每次换版都有 0.2 秒文字撞车。改成：只有红面板走格子，文字先缩出遮罩、再在新位置升起。
- 遮罩一开始是字高的 1.3 倍，升起中的标题下半截漏进了英文副标那一行，看起来像两行字叠在一起；收到 1.04 倍。
- 网格线透明度 0.16 在 1080p 压缩后几乎看不见，“可见网格”失效；提到 0.24。
- 红面板在变奏 B→C 时从全高直接拉满全宽，一瞬间把整张画面刷红；配合文字先退场后，这一帧只剩红块和“07”，反而成了好看的过渡。

## 9. 制作流程（本仓库）

1. 先在 `A / B / C / D` 四个对象里用 `X(i) / XR(i) / Y(j) / YB(j)` 写版式（全部是栏、行的整数），再在 `T` 里写每个元素的落位时间（都是 0.5 的倍数）。
2. 抽帧检查（包括变奏中间帧）：`node _engine/render.cjs swiss-type stills 0.4,2.2,3.2,4.6,7.9,8.3,9.6,10.6,13.5`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "swiss-type/stills/*.jpg" -vf "scale=640:360,tile=3x3:padding=6:color=white" -frames:v 1 /tmp/swiss.jpg`
4. 出片：`node _engine/render.cjs swiss-type` → `demo.mp4` + `poster.jpg`（封面 7.9 秒：定稿版式 + 网格都在）。

## 10. 引擎用法

- `X(i)`、`XR(i)`、`Y(j)`、`YB(j)`：第 i 栏左 / 右边、第 j 行上 / 下边的像素坐标。
- `A / B / C / D`：版式表（红面板矩形、07 靠左还是靠右、每段文字的 x 和基线）；`SEQ` 是变奏时间表，`MOVE = .45`。
- `rise(开始时间, x, 底边, 字高, 宽, 画字函数, 方向)`：遮罩升起 / 滑入；变奏时再叠加全局的退出 / 进入偏移 `m`。
- `gin(k)`、`gout(k)`：网格第 k 根线的画出、缩回进度。
- `T`：全部落位时间，`score()` 里的 blip、whip、thud 都直接用它。
