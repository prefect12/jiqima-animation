# 红色剪纸 — 风格提示词（v1）

> 一张大红纸落在桌上，对折，剪刀沿轮廓走一圈、再一刀一刀掏出月牙纹、团花、锯齿纹，展开成一幅左右对称的窗花；纸有厚度、有投影，镂空处透出桌面。适合春节、节日祝福、民俗主题。
> 样片：《双虎抱福》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **红色剪纸** 风格把一个吉祥图案“当场剪出来”。用户给你一个主题（生肖、福字、喜鹊登梅……），你设计半边图样，让观众看完整个过程：落纸 → 对折 → 剪轮廓 → 掏镂空 → 展开 → 点睛的一刀 → 喜庆收尾。

---

## 1. 这个风格是什么

剪纸的魅力在“过程”和“对称”：观众知道纸是对折的，看着剪刀只剪半边，展开那一刻才看到完整的一对——这是全片的高潮。画面只有一种颜色（大红），所有细节都是**挖掉的洞**，靠洞透出的背景色显形。纸必须有厚度感：一层暗红的纸边 + 投影，洞里也看得到投影。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **对折** | 右半张绕中线翻到左边，翻过去露出颜色更深的背面，翻起时投影变大。 |
| **剪轮廓** | 剪刀尖沿着外轮廓匀速走，身后留下一道深色刀口线；剪完，外圈废纸从纸后面滑落。 |
| **掏镂空** | 每“一刀”是一组洞（脸 / 身上纹样 / 圆边和底座），剪刀一个一个描过去，描完那个洞就掉出一小片红纸。 |
| **展开** | 右半张从背面翻回正面，对称图样完整出现，配一声大锣。 |
| **点睛一刀** | 不对称的东西（“福”字）不能靠对折剪，所以展开以后在圆心再补剪一刀，剪刀走之字，字从上往下露出来。 |
| **喜庆收尾** | 背景从桌面变成金色放射光，窗花轻轻摇，彩纸屑落下，鞭炮声。 |

**结构**：落纸（0–1 秒）→ 对折（1–2）→ 挪到中间放大 1.12 倍（2–2.4）→ 剪轮廓（2.4–5.0）→ 脸（5–6）→ 身体纹样（6–7）→ 圆边、底座、尾巴（7–8）→ 剪刀离场、挪回（8–9）→ 展开（9–10）→ 金光（10–11）→ 剪福（11–11.5）→ 庆祝（11.6–14.4）→ 淡出到深红。

## 3. 视觉语言

- **纸**：大红 `#C8161D`，背面 `#A80F16`；256px 纸纹（深红斑点 + 浅红纤维，初始化时随机生成）。纸的厚度：先画一层 `brightness(.62)` 的暗纸、偏移 (1.6, 2.2)，再画正面。投影 `rgba(70,15,5,.32)`、模糊 6、偏移 (3, 5)，纸抬起来时模糊到 22、偏移到 (13, 21)。
- **半张纸**：300 × 520（整张 600 × 520），折线在 x=0；图样都写在半张坐标里。
- **图样**：布老虎式的正脸老虎（圆脸半径 62，两只圆耳半径 21）+ 侧身，前爪抱住半径 112 的圆（圆边带 6px 波浪），脚下一条带云纹的底座。
- **刀口纹样**：月牙纹（外弧 ±1.25 弧度、内弧偏 0.38r）、柳叶缝（`lens`）、三角锯齿、6 瓣团花、圆孔。脸上：月牙眼、三角鼻、ω 嘴、额头“王”（三横一竖）、胡须缝、耳心。
- **刀口线**：正在剪的那一段是 1.8px `rgba(50,0,0,.85)`。
- **折痕**：展开后在中线画 1.6px 暗线 + 1.4px 亮线（只画在纸上，`source-atop`）。
- **剪刀**：钢色渐变刀身 `#EEF1F4 → #9BA3AD`，黑色把手环，金色铆钉；有独立投影（偏移 12, 16）。剪的时候刀口按每秒 4 次开合。
- **背景**：桌面 `#F3E6D0` 加纤维纹 + 暗角；展开后 1 秒内换成金色径向光 `#FFE7A8 → #F2B955 → #C9762A`，16 道慢转的放射光（16% 不透明）。
- **福**：马善政毛笔楷 Ma Shan Zheng，124px，打成洞（透出金光）。

## 4. 动作语言

- 落纸：从 y=-420 `easeOut` 落下，带 -0.12 弧度的倾斜回正。
- 对折 / 展开：翻页角 θ 用 `ease`，横向缩放 `cos θ`；翻起时在翻页上叠一层由暗到亮的渐变。
- 剪刀：沿路径**按弧长匀速**走（`along()`），洞与洞之间走一段带 30px 上抬的弧线跳过去。
- 废纸：外圈大块 0.7 秒内往左下滑出、转 -0.3 弧度；小洞碎片每片各自错开 0–0.15 秒、左右散开 ±30px、边转边落。
- 展开后：整幅放大到 1.08，庆祝段开始后以 1.8 rad/s 摇 ±0.02 弧度。

## 5. 镜头语言

俯拍桌面，固定机位。用“挪纸 + 放大 1.12 倍”代替推镜头：剪的时候半张纸挪到画面中间，展开前挪回去。

## 6. 声音

- 120 BPM。剪刀声是主角：每个八分音符一声“咔嚓”（高频噪声 + 3400Hz 短金属音 + 回刃声），只在剪刀真的在剪的时候出现。
- 剪纸段伴奏很轻：梆子打拍、小锣点缀、`pizz` 低音，加一段 D 宫五声的拨弦小循环和沙锤。
- 对折落定：大鼓 + 轻钹；废纸掉落 `whoosh` + `paper`。
- 展开：板鼓 8 下越来越响 + `riser` → 10 秒大锣 + 钹 + 大鼓。
- 剪福：四下快剪 → `chime` + 钹。
- 庆祝：自制唢呐（锯齿 + 方波，6.5Hz 揉音，1900Hz 带通）吹一段五声旋律，大鼓 / 钹 / 小锣，三串鞭炮，14 秒一声收尾锣。

## 7. 文字与标题

全片唯一的字是剪出来的“福”。不要加标题字幕——剪纸本身就是标题。

## 8. 踩过的坑

- **老虎像狼**：第一版是侧脸、尖耳尖嘴，展开后像一对狗；改成民间布老虎的正脸（圆脸、圆耳、月牙眼、额头“王”），侧身不变，一下就像老虎了。
- **“福”不对称**：对折剪不出不对称的字。解决办法是展开后在整张纸（`PF`）上再剪一刀，剪刀走之字、字从上往下露出来。
- **废纸盖住图样**：外圈废纸原来半透明地从纸前面掉下去，和刚剪好的图叠在一起很脏；改成不透明、从纸后面滑出去。
- **小碎片排队掉**：底座 8 个云纹的碎片同一时刻、同一速度往下掉，像一排粉点；改成每片错开、散开、旋转。
- **彩纸屑太早掉完**：44 片、1.2 秒内全部发完，14 秒时画面已经空了；改成 72 片、2.2 秒内陆续发。
- **剪纸段太安静**：剪纸段响度 -25 LUFS 左右，庆祝段 -15，整体归一化以后前半段几乎听不见；加了拨弦循环和沙锤，前半段提到 -22 左右。
- 手臂和圆之间要挖一道缝（`GAP`），否则老虎的胸口和圆糊成一块，看不出“抱着”。

## 9. 制作流程（本仓库）

1. 改图样：`OUT_A / OUT_B`（外轮廓，折线上的两段不算刀口）和 `STAGES`（三刀镂空）；时间在 `T` 里。
2. 抽帧检查：`node _engine/render.cjs red-papercut stills 0.3,1.3,1.7,2.2,8.2,9.6,11.2,11.8,14.2`，拼 3×3 联系表看。
3. 出片：`node _engine/render.cjs red-papercut` → `demo.mp4` + `poster.jpg`（封面 12.6 秒：完整的双虎抱福）。
4. 检查：时长 15.0 秒，响度约 -16.2 LUFS。

## 10. 引擎用法

- `Path().M().L().Q().ARC()`：把轮廓采样成点列（`ARC` 可带波浪边）。
- `lens / cres / tri / circ / petals`：五种刀口形状，都返回点列；`one(形状)`、`group(形状们, 剪刀路径)` 组成一刀。
- `CUTS`：由 `STAGES` 自动排出的时间表 `{t0, t1, trace, shapes}`；`along(cut, u)` 按弧长取剪刀位置和方向。
- `renderHalf(t)`：每帧清空 `PC`，铺红纸纹 → 挖掉已剪完的洞 / 外圈 → 画正在剪的刀口线。
- 展开时用 `TF` 给翻页叠阴影（`source-atop`，只影响纸）；展开后把 `PC` 和它的镜像拼进 `PF`，再在 `PF` 上打“福”。
- `drawScissors(c, x, y, 角度, 开口)`：会开合的剪刀。
- 剪刀声、锣、钹、鼓、梆子、唢呐、鞭炮都在 `X.*` 里，用 `B.sfx.context` 自己建节点。
