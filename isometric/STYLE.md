# 等距信息图 — 风格提示词（v1）

> 45° 俯视的小方块世界：几座漂浮的小岛，每座岛上放一个“节点”，一个信封沿着弧线从一座岛跳到下一座。顶、左、右三个面三档明暗，配色柔和，适合把一个流程或系统讲成一段旅程。
> 样片：《一封邮件的旅程》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **等距信息图** 风格讲一个流程。用户给你一个系统或过程，你把它拆成 3–5 个节点，每个节点做成一座小岛上的一个物件，再让一个“主角道具”（信封、包裹、数据块）沿路径依次经过它们，最后在终点给出一句结论。

---

## 1. 这个风格是什么

像科技公司官网和年报里那种等距插画，但会动。整个世界只有一种投影（2:1 等距），所有东西都是方块拼的，每个方块三个可见面用三档明暗，所以不需要任何光影计算也显得立体。画面信息靠“空间位置”排列：从左到右就是流程的先后，从下到上可以表示“离开地面、上天”。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **节点 = 小岛** | 每个环节一座漂浮小岛，岛上一个物件（电脑、路由器、机柜、手机）。岛和岛之间留空，天然分段。 |
| **主角沿路径走** | 一个道具沿弧线跳过去，走过的路径从虚线变成实线——进度一目了然。 |
| **节点有反应** | 到达时节点“做事”：路由器闪灯 + Wi-Fi 波纹、机柜扫描光带、卫星发光再打下一束光。 |
| **离地 = 升级** | 卫星浮在天上，路径突然拉高，观众立刻懂“这一段走得远”。 |
| **终点庆祝** | 屏幕亮起通知、弹出彩色小方块，给一句结论字幕。 |

**结构（15 秒）**：四座岛按拍子依次升起（0–1.5）→ 卫星滑进来（2.0）→ 电脑点“发送”，信封从屏幕里长出来（2.5）→ 飞到路由器（4.0）→ 飞进服务器（6.0，在机柜里停半拍）→ 飞上卫星（8.5）→ 顺着光束落到手机（11.0）→ 手机通知 + 彩色方块 → 结论字幕（12.0）→ 淡出（14.45）。
**节点标签**：信封到哪一站，哪一站的标签才弹出，避免一开场就一屏字。

## 3. 视觉语言

- **投影**：严格 2:1 等距。1 个单位 `S = 30`：x 方向 `(+30, +15)`，y 方向 `(−30, +15)`，z 方向 `(0, −30)`。
- **三档明暗**：顶面在底色上提亮 28%，左面（朝 +y）用底色，右面（朝 +x）压暗 20%（`box(..., k = [.28, 0, −.2])`）；岛的泥土层用 `[.2, 0, −.18]`；云用 `[0, −.04, −.1]`，几乎不分面。
- **背景**：`#DCEAF6 → #F7EFE6` 竖向渐变，上面一层等距网格线（两组 ±26.6° 斜线，间距 52px，`rgba(120,140,170,.10)`）。
- **小岛**：4×4 单位，草皮 `#8FD3AE`（0.35 厚），泥土 `#E3B98B`（1.15 厚）；顶面画 3×3 白色格线（35% 白）；岛下一个 `#5A6F8C` 18% 透明的椭圆影子，岛本身悬空。
- **物件配色**：桌子 `#E8C597`、笔记本 `#D5DCE8`、屏幕 `#2E3A55`（亮起 `#3C5A8A`）、路由器 `#F3F5FA`、机柜 `#56678A`、卫星 `#F2C14E` + 太阳能板 `#4A7BD0`、手机 `#2E3A55` 屏幕 `#BFE3FF`、树 `#5DAE7E` / 树干 `#A0764E`。
- **强调色**：珊瑚 `#F27B6B`（信封描边、走过的路径、标签圆点）；正文色 `#34405A`。
- **字体**：Noto Sans SC（Google Fonts，只取用到的字）。标题 900 38px，标签 500 18px，结论 900 32px。
- **标签**：白色胶囊 34px 高、圆角 17，左边一个珊瑚色圆点；终点标签反色（深底白字、绿点）。

## 4. 动作语言

- **小岛出场**：从下方 240px 处 `back` 缓动 0.45 秒弹上来，每拍一座。之后每座岛以 4 秒周期上下漂 ±4px，相位错开。
- **信封飞行**：每段用 `ease` 走一条抛物线，弧高依次 110 / 120 / 70 / 50px；飞行中横向拉伸 `1 + .18·sin(πu)`、纵向反向压缩；身后拖 5 个渐小的珊瑚色圆点；朝飞行方向倾斜 35%。
- **停站**：到站后原地轻轻“呼吸”（14Hz 小幅压扁），下一拍再出发；进服务器那一站直接藏进机柜，机柜灯全变黄、一道光带从上往下扫。
- **到终点**：信封 0.25 秒缩成 0，手机跳一下（0.5 秒，抬高 0.5 单位），屏幕弹出通知卡，18 个彩色小方块炸开再落下。
- **路径**：卫星出场后虚线（点长 2、间隔 10）淡入；信封走过的部分叠一条 4px 珊瑚色实线。

## 5. 镜头语言

基本固定机位，只做两件事：开场 0–3 秒从 1.12 倍拉到 1.0（看清全景），11–14.5 秒再慢慢推近 3.5%；全程镜头中心跟着信封横向移动 10%，让画面有“在跟”的感觉但不晃。不切镜头，流程本身就是镜头。

## 6. 声音

- 120 BPM，F – Dm – B♭ – C，拨弦（`pluck`）按 `[0, 1, 1.5, 2.5, 3]` 拍型扫和弦，轻鼓（底鼓 + 沙锤）+ 拨弦贝斯（`pizz`）。整体轻快、音量低。
- 岛升起：马林巴 72 / 76 / 79 / 84 上行 + `pop2`。卫星进场 `swish` + 高音马林巴。
- 发送：`click` + `pop`；每段出发 `whip`，每次到站两个 `blip`（音高随站数升高）。
- 节点反应：路由器 3 个 `tick`，服务器 8 个快速 `tick`，卫星 `shimmer`，下行前 `riser`，送达 `chime` + `pop`，结论 `boop`，最后一个拨弦和弦 + 长和弦收尾。

## 7. 文字与标题

- 左上角一个标题（“一封邮件的旅程”）+ 一条珊瑚色短下划线，结尾时标题淡出，同一位置弹出结论胶囊（“已送达 · 全程只要几秒”）。
- 画面里只有标题、节点名、结论三种文字。节点名 2–4 个字。
- 物件上的“界面”（笔记本屏幕、手机通知）用色块和线条表示，不写字。

## 8. 踩过的坑

- `const ARC` 写在 `draw()` 里、却在它之前定义的函数被调用时用到，页面直接报 `Cannot access 'ARC' before initialization`，渲染超时。时间和路径常量一律放在文件顶部。
- `back()` 缓动在起点会略小于 0，拿它乘出来的 `globalAlpha` 是负数时浏览器会忽略这次赋值、沿用 1，于是岛下影子变成一块不透明的深蓝椭圆。透明度要 `clamp` 到 0–1。
- 右上角加过一个“MAIL 00:50”的计时器，观众会读成 50 分钟，删掉了。
- 第一版 `S = 26`，笔记本和手机小到看不出是什么；改成 `S = 30`，并把笔记本、手机单独放大。
- 结论胶囊宽度写死 400px，字比框长；改成 `measureText` 算宽度。
- 结论一开始放在画面正上方，和卫星、飞行弧线撞在一起；改到左上角接替标题的位置。
- 路由器岛是最低的一座，标签和影子被画面底边裁掉，四座岛整体上移 10–15px。
- 手机岛前面的树挡住了手机下半截，挪到手机后方。

## 9. 制作流程（本仓库）

1. 先在顶部定时间表（`POP`、`SEND`、`SEG`、`ARR`、`CAP`）和四座岛的屏幕锚点 `ISL`、卫星位置 `SAT`、弧高 `ARC`。
2. 抽帧：`node _engine/render.cjs isometric stills 1,2.7,4.2,6.3,7.5,9.9,11.4,12.6,14.2`
3. 出片：`node _engine/render.cjs isometric`

## 10. 引擎用法

- `P(x, y, z)`：等距投影，原点是当前的 `O`（每座岛画之前把 `O` 设成岛的锚点）。
- `box(x, y, z, w, d, h, 颜色, [顶, 左, 右])`：画一个方块的三个可见面，按从后往前的顺序调用。
- `quad(点列, 颜色)`：画任意一个等距平面（屏幕、光带）。
- `onLeft(x, y, z, fn)`：把 `transform(1, .5, 0, 1)` 套到朝 +y 的面上，在面里画 2D 内容（屏幕界面、机柜灯、手机通知）。
- `anchor(i)` / `satPos()`：带漂浮和出场动画的岛、卫星位置；`nodes()` 算出五个停靠点，`segPoint(i, u)` 给出第 i 段上的点，`envelope()` 返回信封当前状态。
