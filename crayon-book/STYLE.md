# 蜡笔绘本 — 风格提示词（v1）

> 粗糙纸面上的蜡笔笔触：来回涂的之字形排线、纸齿里露出来的白点、每秒抖 8 次的歪线条，顶上一条蓝天、角上一个太阳，像小朋友画在绘本里的一页。
> 样片：《想抱一抱的小刺猬》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **蜡笔绘本** 风格讲一个睡前故事大小的小事。用户给你一个主角和一个愿望，你把它拆成“想要 → 遇到麻烦 → 难过 → 想到办法 → 做到了”五拍，主角只有一个，道具只有一个，全部用蜡笔一笔笔涂出来。

---

## 1. 这个风格是什么

看起来像 5–8 岁的孩子用一盒蜡笔画的绘本页：线是歪的，颜色涂不满、会出格，纸的颗粒从蜡里透出来，天空是顶上一条蓝，太阳在角上发光。它的质感来自三件事：**纸齿**（蜡只留在纸的凸处）、**排线涂色**（看得见来回的笔道）、**抖线**（线条每 1/8 秒换一次抖动，画面一直“活着”）。适合绘本、睡前故事、儿童科普、温柔的品牌小故事。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一个愿望** | 主角想要一样东西（抱气球），观众一眼就懂。 |
| **天生的麻烦** | 麻烦来自主角自己（刺会扎破气球），不需要反派。 |
| **变形解决** | 用“把 A 变成 B”解决问题（刺一根根变成花），变形正好是蜡笔最好画的东西。 |
| **小符号说情绪** | 爱心、感叹号、汗滴、星星、眼泪，全都用蜡笔涂，代替对白。 |

**结构（按 100 BPM，一拍 0.6 秒）**：画纸（0–1.8 秒：天空、太阳、草地和标题一笔笔涂出来）→ 主角蹦进来（6 跳）、道具飘进来 → 看见（爱心）→ 伸手 → 失败（感叹号 + 吱一声弹开）→ 难过（眼泪、小调）→ 灵机一动（星星）→ 变形（每半拍一朵花）→ 做到（抱住、飞起来、爱心往上飘）→ 结尾一句字 → 淡出。

## 3. 视觉语言

- **纸**：底色 `#F7F0E0`，叠一张 240px 的纸纹平铺（颜色 `rgb(110,85,50)`，透明度 0–10%）。最后压一层很淡的暖色暗角（`vignette .16`）。
- **纸齿（最重要）**：所有蜡笔先画到一张离屏图层，最后用一张 240px 的“纸齿”纹理 `destination-out` 抠一遍。纹理 = 0.5×双线性噪声（x/5, y/2.5，横向拉长）+ 0.5×白噪声，`alpha = clamp((v − 0.53) × 3.2)`。纸不动，所以纸齿纹理也不动。
- **蜡笔线 `cline`**：同一条线画 3 遍，线宽 ×1 / ×0.75 / ×0.55，透明度 .92 / .6 / .45，每遍偏移 ±线宽/4。每个点有 ±2px 的固定歪斜 + ±1.2px 的抖动。
- **蜡笔涂色 `cfill`**：在形状里走之字形，行距 7px、笔宽 7.5px；**每一行单独一笔**，力度（透明度）在 .6–.98 之间随机、笔宽 ×0.8–1.2；再换 0.9 弧度补一遍（透明度 .35–.6，笔宽 ×0.6）。行与行之间自然留白。
- **颜色（一盒 12 色蜡笔）**：描边 `#2B2420`、刺猬 `#8A5A2E / #5B3A1F`、脸 `#EBC48E`、红 `#E03C2E`、粉 `#F08AAE`、黄 `#F6C21C`、橙 `#F28A22`、草绿 `#62A93A / #3F8A34`、蓝 `#3C7DD0`、天蓝 `#86BFEC`、紫 `#8C5BC4`。
- **留白**：气球左上留一块不涂的椭圆当高光；天空只画顶上一条，中间大片纸色。
- **字体**：站酷快乐体 ZCOOL KuaiLe。标题 78px 蓝色，结尾 92px 红色；字也画在蜡笔层里，一样被纸齿抠出颗粒，并描一遍 2.5px 同色边、错开 1.5px。
- **角色比例**：角色组整体以地面中点 (640, 600) 为轴放大 1.4 倍（`STAGE`），背景不放大。

## 4. 动作语言

- **抖线（boil）**：`bf = floor(t × 8)`，所有抖动都用 `hash(种子 + bf)`，线条每秒换 8 次形状——手绘动画的“呼吸”。
- **蹦跳走路**：1.8 秒走 6 跳，每跳高 18px，两条腿交替前后摆 8px。
- **弹开**：碰到刺的一瞬间气球压扁 18%（0.2 秒），然后 0.3 秒弹到右上方，带 0.5 秒衰减抖动。
- **难过**：眼睛变成向下的弧线，身子沉 5px，刺往下耷拉，眼泪每 1.2 秒滴一颗。
- **变形**：每半拍（0.3 秒）一根刺缩没（0.15 秒），同时花用 `back` 弹出来（0.33 秒），茎从身体长到花心。
- **抱住**：气球 0.6 秒飘到脸前，手臂从肩膀弯过去搭在气球左下，落定时气球压扁 6%；之后整组升高 72px 并轻轻上下浮。

## 5. 镜头语言

固定机位，像翻开的一页绘本。角色从画外走进来，道具从画外飘进来。页面构图：顶上天空条 + 右上太阳 + 下方草地，中间大块留白给角色。标题和结尾字都放在左上（不和气球抢位置）。

## 6. 声音

- 配乐：音乐盒（`mbox`）八分音符琶音 + 拨弦贝斯（`pizz`）+ 沙锤，100 BPM；C–G–Am–F 循环，难过那两小节换成 Am、琶音减半、去掉沙锤。
- 木琴（`marimba`）两句旋律：一句跟着蹦跳，一句跟着开花（每朵花一个音）。
- 音效与画面同一张时间表 `T`：画纸时 `scribble` 沙沙声；每一跳一个 `boop`；看见 `pop2`；伸手一声上滑哨；扎到时自造的“吱吱”（三角波 900→1500Hz 两下）+ `pop` + `boing`；难过一声下滑哨（820→260Hz，带 7Hz 颤音）；灵机一动 `ding`；每朵花 `pop` + `blip` 音阶上行；抱住 `squash` + `chime`；飞起来上滑哨 + `shimmer`；结尾音乐盒五音琶音。
- 自造音色：在 `S.at` 回调里用 `B.sfx.context` 建振荡器，连到 `B.sfx`。

## 7. 文字与标题

全片只有两句：开头“小刺猬想抱一抱”（主角 + 愿望），结尾“抱到啦！”（结果）。字要像孩子写的：圆胖、歪一点、有蜡笔颗粒。中间的情绪全靠符号。

## 8. 踩过的坑

- 第一版角色太小，画面中间大片空白：给角色组整体加了 1.4 倍的 `STAGE` 放大，关键帧坐标按放大后的构图重算。
- 涂色一开始是一整条之字形路径，力度一样，画面上出现贯穿整块的笔直白缝，像机器排线：改成每行单独一笔、力度和笔宽随机。
- 碰刺时的“！”画在了气球上被挡住：挪到刺猬头顶左侧。
- 抱住时手臂是一根细长的棍子横穿气球：手臂加粗、缩短、手搭在气球左下角，气球挪到 `bx + 196`，让鼻尖刚好顶进气球边。
- 气球高光椭圆太大，缩略图上像个“0”：缩到 8×14。
- 标题淡出无效：`textIn` 内部重设了 `globalAlpha`，外面的淡出被覆盖，改成把透明度作为参数传进去相乘。
- 所有逐帧随机都走 `hash()`，`Math.random` 只在初始化生成纸纹和纸齿。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部的时间表 `T`（秒）和 `HOPS / SPIKES / BLOOM_STEP`；`score()` 直接读同一张表，不用另外对时间。
2. 抽帧检查：`node _engine/render.cjs crayon-book stills 1,2.6,4.8,5.5,7,9.2,11,11.9,13.8`，再用 `ffmpeg … tile=3x3` 拼联系表看。
3. 出片：`node _engine/render.cjs crayon-book` → `demo.mp4` + `poster.jpg`（封面在 12.1 秒：满背小花、抱着气球、爱心往上飘）。
4. 验证：`ffprobe` 时长 15.0；`ebur128` 响度约 −15 LUFS。

## 10. 引擎用法

- `layer(c)`：拿一张和主画布同像素尺寸的离屏图层，已清空、已设好 1280×720 逻辑坐标。
- `cline(点列, 颜色, 线宽, 种子, 进度, 闭合)`：三遍叠画的蜡笔线，进度 `u` 控制画到哪。
- `cfill(路径函数, 包围盒, 颜色, 种子, 进度, 角度, 行距, 笔宽)`：在形状里之字形涂色，进度控制涂到哪一行。
- `ell / ellPath / polyPath`：椭圆点列、椭圆路径、多边形路径。
- `heart / flower / textIn`：蜡笔爱心、五瓣花、逐字露出的蜡笔字（带透明度参数）。
- 最后一步固定是：`L.globalCompositeOperation = 'destination-out'` + 纸齿纹理平铺，再 `c.drawImage(L.canvas…)` 贴回纸上。
