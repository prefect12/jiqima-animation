# 阈限空间录像 — 风格提示词（v1）

> 一盘翻出来的旧录像带：VHS 蓝屏、PLAY 字样、时间码、RGB 错位和横向跟踪噪声带，画面里是一条凌晨空无一人的商场走廊，荧光灯发着绿白的光。不吓人，只是“有点不对劲”。
> 样片：《凌晨三点的商场》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **阈限空间录像** 风格拍一段“本该有人、但一个人都没有”的地方。用户给你一个场所（商场、泳池、学校走廊、停车场），你把它变成一段监控 / 家用摄像机拍下的录像：一个固定或缓慢推进的镜头、一个空间、一件小小的怪事（灯灭了、门自己开了、音乐慢慢走调），然后录像带自己停掉。

---

## 1. 这个风格是什么

“阈限空间”（liminal space）指那些过渡性的、平时人来人往的地方在空无一人时的样子；“录像”指 90 年代 VHS 的质感。两者叠在一起，观众会自动脑补“这盘带子是谁录的、为什么录这个”。不安感来自**安静和不对劲**，不是来自吓人的东西：不要人影、不要脸、不要跳吓、不要血。画面越干净、越普通，越有效。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **灯一组一组灭** | 最好用的“事件”：灭的方向（近 → 远）就是观众视线被推着走的方向。 |
| **东西自己动** | 自动门、电梯门、旋转门、扶梯突然开始转——一个动作就够，不要解释。 |
| **音乐走调** | 商场背景音乐一开始就低半拍、带颤音；出事之后像磁带变慢一样越来越低。 |
| **录像带自己坏掉** | 跟踪丢失 → 雪花 → 蓝屏 STOP，是最干净的结尾，不需要交代结局。 |

**结构**：蓝屏 PLAY（0.8 秒）→ 画面从上往下卷入 → 灯全亮的走廊（建立空间，镜头极慢推进）→ 灯一拍一组依次熄灭 → 全黑只剩 EXIT 绿灯（停一拍）→ 尽头自动门自己滑开，冷光铺到地上 → 摄像机变焦推向门口 → 跟踪丢失、雪花 → 蓝屏 STOP → 淡出。

## 3. 视觉语言

- **分辨率**：场景先画在 480×270 的离屏画布上，再平滑放大到 1280×720，天然带 VHS 的软。
- **走廊**：一点透视，宽 7 米、高 3.2 米、长 30 米。地砖 1 米棋盘格，米色 `rgb(196,188,168)` / 灰 `rgb(150,150,142)`；天花吸音板 `rgb(178,176,164)`，每块描 0.6px 暗线；柱子 `rgb(208,206,196)`，招牌带不亮 `rgb(120,118,110)`，店里黑玻璃 `rgb(34,40,42)`，卷帘 `rgb(128,130,126)` 加横向暗纹。
- **光**：6 组灯管在 z = 2 / 7 / 12 / 17 / 22 / 27 米。每个面片按中心点算光照：`on × (0.3 + 0.7·(n·l)) × 0.78 / (1 + 0.028·d²)`，RGB 三个通道乘不同系数（R .92 / G 1 / B .84）得到荧光灯的绿白色；环境光 .09。灯管本体是发光矩形 + 径向光晕（lighter 叠加），抛光地砖上有一份镜像倒影（透明度 .22）。
- **门外的光**：冷蓝（B 通道 × .95），只朝走廊里照（乘 `(dz/d)²`），离端墙 2.5 米内衰减掉，避免把端墙照得比门外还亮。
- **VHS 处理**（全在低分辨率上做）：
  - RGB 分离：画面复制三份，各自 `multiply` 纯红 / 纯绿 / 纯蓝，再用 `lighter` 叠回，红 +2.2px、蓝 −1.8px；出故障时最多加到约 8.7px。
  - 色度拖尾：合成结果向右偏 3px、透明度 .18 再叠一次。
  - 行抖动：每 2 行一条，随机横移 ±0.4px（`hash(帧, 行)`）。
  - 跟踪噪声带：高 16px（故障时 +60px）从上往下滚，带内每行横移 7–27px，并撒 26 条以上白色短线。
  - 底部 9 行磁头切换噪声：固定右偏 6–14px。
  - 雪花：256px 噪声纹理，平时透明度 .07，丢跟踪时加到 .57。
  - 放大时 `saturate(.72) contrast(1.06)`，每 3px 一条 13% 黑扫描线，暗角 .5。
- **蓝屏**：`rgb(22,52,196)`。
- **OSD 字体**：VT323（Google Fonts），白 `#F2F2EA` + 3px 黑投影。

## 4. 动作语言

- 人不出现，只有“东西”动：灯、门、镜头。
- 荧光灯熄灭前 0.42 秒开始闪（`hash` 决定每帧亮 / 半亮 / 灭），灭后余辉 0.35 秒线性退掉。
- 自动门两扇各 1.6 米宽，1.5 秒 `ease` 向两侧滑进墙里，画面上用门洞矩形裁切。
- 故障只在“事件点”发生：画面卷入、最后一组灯灭（0.25 秒）、门开始动（0.2 秒）、结尾丢跟踪。平时只有极轻的行抖动。

## 5. 镜头语言

家用摄像机 / 监控视角，眼高 1.55 米。前 9.4 秒以 0.5 米 / 秒以下的速度几乎察觉不到地推进，加 ±0.9° 的慢速偏航和 1.5 厘米上下晃；门开后镜头一边前推一边**变焦**（焦距 250 → 470），像拍摄者本能地把镜头推向门口。不要切镜头，一镜到底。

## 6. 声音

- 72 BPM。商场背景音乐：电钢琴（正弦 + 八度三角波）Fmaj7 – Em7 – Dm7 – Cmaj7，整体降 38 音分，5.2Hz 颤音 ±14 音分，过 220Hz 高通 + 2200Hz 低通，像从天花板喇叭里漏出来；门开完之后每秒再降 160 音分（磁带变慢），丢跟踪时停。
- 常驻层：荧光灯嗡声（100Hz + 120Hz 锯齿 + 240Hz 正弦，520Hz 低通），每灭一组灯嗡声就小一截，全灭后消失；磁带嘶声（循环噪声，4200Hz 带通，增益 .022）。
- 同步音效：灯闪时 4 下 `crackle`，灭的瞬间 `thud + tom(33) + click`（继电器“咔咚”）；门：自建锯齿电机（95 → 140 → 90Hz）+ 低 `whoosh`，到位一个轻 `thud`；丢跟踪 `riser`，STOP 时 `click + thud`。

## 7. 文字与标题

画面内只有设备字幕和一个 EXIT 灯箱：左上 `PLAY ▶`（只在开头 3.3 秒）、右上 `SP`、左下日期 `OCT.17 1997` 和时钟 `AM 3:12:07`（每秒走一格）、右下磁带计数 `00:14:02:15`（时:分:秒:帧）；结尾 `STOP ■`。不加片名，不加解说——这个风格一旦出现“讲述者”就破功。

## 8. 踩过的坑

- **过曝**：最初光强 5.2、衰减 .09，灯下一片死白，地砖和店面全看不出。改成 .78 / .028 后整条走廊亮度均匀，才有商场的感觉。
- **花坛像一个人**：放在门边的花坛绿植，在全黑背景和门外亮光的衬托下成了一个站着的黑色剪影——正是这个风格最不能出现的东西。删掉远处的花坛，只留近处一个。
- **门太小**：走廊原本 36 米，门在画面里只有几个像素，门开了看不出来。缩短到 30 米、门加宽到 3.2 米，并在门开后加变焦推近。
- **门外比端墙还暗**：门外的点光源把端墙照亮，反而显得门洞是黑的。改成只朝走廊方向照 + 靠近端墙衰减，同时把门外雾光调亮。
- **灯灭后全黑**：环境光太低时中段 1 秒什么都看不见，提到 .09，保留墙和柱子的轮廓。
- **PLAY 一直闪**太吵，改成只在开头出现 3.3 秒。
- 磁带嘶声一开始太大（响度归一化后会盖住音乐），从 .045 降到 .022。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部改时间常量：`OFF`（每组灯灭的时刻）、`DOOR / DOOR_D`、`LOSE / STOP`；`score()` 用同一组常量排音效。
2. 抽帧检查：`node _engine/render.cjs liminal-vhs stills 0.5,1,3.5,6.2,7,8,10.6,12.4,13.2`
3. 出片：`node _engine/render.cjs liminal-vhs` → `demo.mp4` + `poster.jpg`（封面 6.9 秒：近处灯已灭、远处还亮）。

## 10. 引擎用法

- `P(x, y, z)`：透视投影（相机位置 `camZ`、焦距 `FOC` 由 `F.keyframes` 给出，带微小偏航），返回低分辨率画布坐标和深度。
- `light(x, y, z, nx, ny, nz)`：返回该点的 RGB 光照系数（6 组灯 + 门外冷光）；`col(基色, 光照)` 把它变成颜色。
- `wall(侧, z0, z1, y0, y1, 基色)`：侧墙按 1 米切片逐片打光，用来画柱子、店面、卷帘。
- `flick(t, 熄灭时刻, 帧号, F)`：荧光灯的亮度曲线（正常 → 闪烁 → 余辉 → 灭）。
- VHS 管线：`scn`（场景）→ `chR/chG/chB`（通道拆分）→ `mix`（错位叠回 + 拖尾）→ `out`（行抖动、噪声带、雪花）→ 放大到主画布 → 扫描线、蓝屏、OSD。
- 声音：`bus(B)` 在 `B.sfx.context` 上建一次滤波链和噪声缓冲；`ep()` 是带颤音、可整体降调的电钢琴；嗡声和嘶声用一个 `S.at(0, …)` 事件建常驻振荡器，再用 `setValueAtTime` 按灯灭时刻逐级降音量。
