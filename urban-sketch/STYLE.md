# 钢笔淡彩 — 风格提示词（v1）

> 速写本上的一点透视街景：钢笔线先一根根画出来，线头出头、角上交叉、阴影用排线；淡彩不贴线、比线松，而且只刷在视线停留的地方——热气飘到哪里，哪里才上色，四周留着线稿和纸白。
> 样片：《巷口早点》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **钢笔淡彩** 风格画一个真实的地方。用户给你一个街角、一家店或一段旅程，你先用钢笔把场景“搭”出来（透视骨架 → 主体 → 细节 → 阴影排线），再找一个会动的东西（热气、光线、一只猫、一个人走过）当“视线”，它走过的地方才着色，最后在角上手写一行地点和时间。

---

## 1. 这个风格是什么

城市速写（urban sketching）的样子：线是主角，快、准、不修，允许出头和重复；颜色是配角，透明、松散、常常不贴着线，而且画面边缘往往只有线没有色——颜色集中在画家最在意的地方。本片把“画家的注意力”做成了一个会移动的遮罩：热气从蒸笼升起，一路飘过招牌、灯笼、墙、自行车、地面，颜色跟着它一块块晕出来。适合城市旅行、建筑、生活方式、店铺故事。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一点透视** | 巷子、街道、走廊最适合：所有纵深线汇到一个灭点，线稿本身就有冲击力。 |
| **一个主体** | 早餐摊放在灭点前，雨棚、招牌、蒸笼、锅，所有细节往它身上堆。 |
| **会动的“视线”** | 热气是天然的引导线：从主体出发，绕场景一圈，再回到主体。 |
| **手写注记** | 最后在角上写“巷口 · 七点十分”，像速写本上的记录。 |

**结构（84 BPM，一拍 0.714 秒）**：透视骨架（0.3 秒起）→ 远处门洞 → 雨棚、柱子、台面 → 蒸笼、锅 → 招牌、电线、灯笼 → 窗、门、自行车、盆栽、小凳 → 地砖和阴影排线（全部在 5.0 秒前画完）→ 蒸笼冒气、先给蒸笼上色（第 7 拍 5.0 秒）→ 领头的一团热气沿路径绕场景一圈（5.71–11.07 秒）→ 颜色在主体周围整体晕开（10.71–12.14 秒）→ 手写注记（12.14–13.0 秒）→ 淡出。

## 3. 视觉语言

- **纸**：`#F7F3EA` + 256px 噪点纸纹（0–7%），暗角 `.14`。
- **钢笔**：`#2A2521`，线宽 1.7 ×（0.85–1.15），透明度 .88，圆头。每个点固定抖 ±0.55px；两点直线两头各出头 3–11px，中点再偏 ±0.75px，所以直线也有一点点手感。
- **透视**：灭点 (640, 300)。左墙屋檐 (0, 60)→(520, 250)、墙脚 (0, 700)→(520, 380)；右墙 (1280, 40)→(760, 250)、(1280, 700)→(760, 380)。墙上的窗、门按纵深 `pz(z) = (1 − 1/(1 + 2.5z)) / (1 − 1/3.5)` 取位置，越远越挤。
- **排线**：在多边形里排平行线，只保留落在多边形里的一截；间距 7–9px、线宽 0.8–1，用在雨棚下的台面、右墙墙脚、摊子底下、左墙深处。
- **淡彩**：整张颜色预先画好缓存。每个色块：整体随机偏移 ±7 / ±5px（故意不贴线），画 3 层、每层 22.5% 透明、顶点再抖 ±5px，沿边描一道 2.4px 的积色；26 处径向“擦白”让颜色不死板。颜色：天 `#BFD8EA`、左墙 `#E8BD80`、右墙 `#AEB9CF`、墙脚阴影 `#9EA6C8`、雨棚 `#D65A42`、台面 `#B47A4C`、蒸笼 `#E3B862`、招牌 `#C9412E`、灯笼 `#E04A32`、自行车 `#3E8C8A`、植物 `#7FA75C`。
- **字**：志莽行书 Zhi Mang Xing。招牌“早点”56px 用钢笔色写在红底上；注记“巷口 · 七点十分”44px 写在左上角。

## 4. 动作语言

- **画线**：约 370 根线（含排线），每根有自己的开始时间和时长（直线 0.03–0.22 秒），相邻两根重叠 45%；全部按顺序排好后，再整体压缩进 0.3–5.0 秒。
- **热气**：7 团白色软雾（半径 30–70，白 75%）循环上升，每团带一笔钢笔卷线；领头的一团（半径 70，白 85%，三道螺旋卷线）沿 17 个控制点、97 个采样点的路径走。
- **上色遮罩**：路径上每个采样点在热气经过后 1.3 秒里长出一个半径 150 的不规则圆（36 点、3 个谐波）；蒸笼先得到一个半径 150 的圆；最后以 (560, 430) 为中心长出半径 470 的大圆，把摊子整个罩进颜色里，四角仍然只有线稿。
- **注记**：从左往右露出，0.86 秒写完。

## 5. 镜头语言

固定机位，人站在巷口往里看。灭点略高于画面中心，摊子压在灭点前面，雨棚的边正好在视平线附近；左右两面墙把视线往里收，电线和灯笼横跨在上面。

## 6. 声音

- 钢笔：自造 5.2kHz 带通噪声，按 0.25 秒一格检查“这一格有没有线在画”，有就响一格——笔声和线稿严格同步。
- 蒸汽：从 5.0 秒起一段高通噪声，一直持续到结尾。
- 配乐：清晨吉他感的拨弦（`pluck`）八分音符分解（Gmaj7 – Em7 – Cmaj7 – D7），冒气之后贝斯和沙锤进来，热气出发后加 pad。
- 热气经过 8 个“点位”（蒸笼、招牌、左灯笼、天上、右灯笼、右墙、台面前、盆栽）各一声木琴，音一路往上走；冒气 `chime`；最后整体晕开 `shimmer` + `whoosh`；写注记时再响一段笔声；收尾电钢琴和弦。

## 7. 文字与标题

只写画面里本来就有的字（招牌“早点”）和速写本上的一行注记（地点 + 时间）。都用手写体，不用印刷体标题。

## 8. 踩过的坑

- 画线时间是一根接一根累加的，第一版线稿到 11 秒才画完，灯笼比颜色还晚出现：所有线排好后，整体按比例压进 0.3–5.0 秒。
- 第一版墙面大片空白，不像速写：补了门洞、落水管、砖缝、挑出来的招牌、门帘、筐子、灯泡、包子、井盖和一根远处的电线。
- 地砖线从台面上穿过去：纵向地砖线在摊子前截断，横向线在摊子两侧断开。
- 想用小水渍增加变化，结果 3 个谐波的小圆缩小后变成星形斑点：换成径向渐变的“擦白”。
- 台面下的阴影是一块方方正正的矩形：改成不规则多边形并降低透明度。
- 雨棚的波浪边一开始朝上翻（点列被反转了两次）：直接用从 π 到 0 的下半椭圆。
- 注记最初放在右下，和墙脚排线撞在一起：挪到左上角。

## 9. 制作流程（本仓库）

1. 改线稿：`demo.html` 里按顺序调用 `ln / box / hatch`，顺序就是画的顺序；时间会被自动压进 `T.lines`。
2. 改颜色：`WASHES`（颜色、多边形、可选透明度）；改“视线”：`PATH_CP`（热气路径控制点）和 `T.travel`。
3. 抽帧：`node _engine/render.cjs urban-sketch stills 1,2.5,4,5.2,6.5,8,9.5,11,13`，看线稿是否在 5 秒前画完、颜色边缘是否自然。
4. 出片：`node _engine/render.cjs urban-sketch`（封面 13.0 秒：颜色已晕开、注记写完）。
5. 验证：时长 15.0，响度约 −15 LUFS。

## 10. 引擎用法

- `ln(点列, 时长, { over, w, gap, jit })`：一根钢笔线，两点直线自动出头。
- `box(a, b, c, d)`：四根线围一个框（四个角自然交叉出头）。
- `hatch(多边形, 角度, 间距, 时长, 线宽)`：多边形内排线。
- `LW(z, h) / RW(z, h)`：左墙 / 右墙上纵深 z、高度 h 处的屏幕坐标。
- `spot(x, y, 半径, 形状号)`：往遮罩上加一块不规则圆；色层 = 缓存彩色层 `destination-in` 遮罩，再 `multiply` 到纸上。
- `rng(种子)`：初始化用的确定性随机，线稿每次一模一样。
