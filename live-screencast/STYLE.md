# 活体录屏 — 风格提示词（v1）

> 一个干净的表格软件界面，没有鼠标——一个揉皱的纸团小人从天上掉进来，亲手把一行数据扛到最上面、跳上按钮踩“筛选”、再踩“图表”，最后顺着柱状图一级一级跳下来。界面是代码画的通用界面，小人就是你的鼠标。
> 样片：《纸团小人教你用表格》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **活体录屏** 风格演示一个软件功能。用户给你一个工具和 2–4 个要教的操作，你设计一个小角色，让它用身体去完成每个操作：点击 = 跳上去踩，拖动 = 扛起来搬，结果出现 = 它站在结果上庆祝。

---

## 1. 这个风格是什么

产品教程视频的“有人味”版本：界面照常，但操作者从鼠标变成了一个会跑会跳的小家伙。观众的视线天然跟着角色走，所以不需要高亮框和箭头；每一个“点击”都有起跳、落地、压扁、音效，比鼠标一闪更容易记住。界面是自己画的通用表格（标题栏写“表格（示例）”），不模仿任何真实品牌的界面和图标。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **从天而降** | 角色从画面上方掉进界面、落地压扁、眨眼挥手——一秒建立“它是主角”。 |
| **扛着拖动** | 排序用“把最大的一行扛到最上面”，其他行随后自动归位。比点表头更直观。 |
| **跳上按钮** | 工具栏按钮被踩下 3px + 一圈蓝色外扩框 = 一次点击。 |
| **在弹层里操作** | 下拉菜单弹出，角色跳到选项上，复选框打勾，被筛掉的行淡出。 |
| **结果当台阶** | 柱状图长出来后，角色从最高的柱子一级级跳到最低的，每落一次弹出一个数值。 |

**结构（120 BPM，一拍 0.5 秒）**：纸团掉进表格（0.5–1.0）→ 挥手 → 跳到“橙子”那一行（2.5），扛着跳到第一行（3.0，扛的途中苹果、香蕉下移一格让位），其他行经右侧通道归位（3.0–4.0） → 跳上“筛选”（4.5）→ 跳到“销量 > 30”选项旁，打勾（5.0），两行淡出 → 表格滑到左边，跳上“图表”（6.0）→ 四根柱子按八分音符长出（6.5–7.25）→ 在柱子上跳台阶（7.5 / 8.0 / 8.5 / 9.0）→ toast “图表已生成”（9.5）→ 原地欢跳 → 跳回最高的柱子，片尾字幕（12.0）→ 淡出（14.45）。

## 3. 视觉语言

- **桌面**：`#E9EEF4 → #DDE4EC` 斜向渐变。
- **窗口**：1100×612，白色圆角 14，投影 blur 40 / y 16 / 20%；标题栏 `#F6F7F9`，三个灰色圆点 `#CDD2DA`（不用红黄绿），居中标题“表格（示例）”。
- **工具栏**：`#FBFBFC`，按钮 92×36、圆角 8、描边 `#D9DEE5`，图标是 2px 线画的排序 / 漏斗 / 柱状图；激活态 `#E8F0FE` 底 + 蓝色 `#2F7DF6`。右边一个公式栏（`A1 fx 水果` → `B2 fx 65` → `筛选 fx 销量 > 30` → `图表 fx 销量（4 项）`），跟着操作变。
- **表格**：行高 48、列头行 28，网格线 `#E3E6EB`，列头 / 行号底色 `#F1F3F6`；第三列是条形数据条 `#35B28A`（圆角 4，长度 = 170 × 值 / 65）。表头上排序后出现蓝色 `↓`，筛选后出现蓝色漏斗。
- **图表面板**：白卡 460×450，柱子 60 宽、间距 95、最高 300px，`#6FA0FF → #2F7DF6` 竖向渐变，顶部圆角 8。
- **字体**：Noto Sans SC 400 / 700 / 900（Google Fonts，只取用到的字）。界面字 13–18px，片尾字幕 900 30px 放在 `#FFD84D` 黄色胶囊里、倾斜 −0.03。
- **纸团小人**（半径 26）：
  - 轮廓：18 个点的不规则圆，半径在 0.94–1.04 倍之间（初始化时随机一次），底色 `#F4F0E6`，描边 `#8C8373` 1.6px，外加一层暖灰投影。
  - 揉皱纹理：128×128 离屏画布，初始化时用 70 个随机三角形（亮 / 暗半透明）+ 22 条折痕（深线 + 旁边一条白色高光线）生成，之后每帧只贴图；贴图随横向位置旋转（`x·0.02`），跳起来像在滚。
  - 脸：两只 3.2×4.4 的小黑眼睛（带白点高光，偶尔眨眼），粉色腮红 `rgba(242,123,107,.45)`，小嘴（开心时变成半圆）。眼睛朝跳跃方向偏 4px。
  - 手脚：`#3B3A36` 3.2px 圆头线，手是小纸球。刻意避开“橙色方块机器人”那类造型。

## 4. 动作语言

- **跳**：每次移动都是一段抛物线 `[开始, 落地, x, y, 弧高]`，0.5 秒，落地卡在拍点上。空中身体拉长（0.92 × 1.1），手向两侧张开，嘴张开。
- **落地**：0.16 秒内压扁到 1.25 × 0.78 再回弹，落地瞬间闭眼。
- **扛**：抓住的那一行浮起 6px、蓝色描边 + 投影，行的位置 = 小人脚底 − 行高，跟着小人一起跳；小人双手画在行的前面。
- **归位**：两条道——表格本列和右侧“通道”（整行右移 310px，只盖住 C 列数据条，A/B 列的字永远露着）。要跨越别的行的（西瓜、草莓、香蕉）先在自己那一行横着被拎出去（右移 + 放大 3% + 投影），在通道里竖着走，再横着落回空位；只差一格的（苹果、葡萄）在本列里挪进空位，带白底和竖线。同一条道里的行永远不交叉，关键帧全在 0.125 秒网格上（`SORTK`：`[时刻, 行位, 右移比例]`），每次有行到位响一声 `tick`。
- **欢呼**：双手举过头；挥手用约 3Hz 的摆动（`sin(t·18)`）；原地欢跳 0.35 秒、高 46px。
- **弹出**：下拉菜单纵向 `back` 展开 0.3 秒；图表面板从中心 `back` 放大 0.45 秒；柱子 `back` 长出 0.4 秒；数值标签 `back` 0.3 秒。

## 5. 镜头语言

固定机位，窗口占画面约 85%。不推镜头，用界面自身的变化引导视线：开场表格居中，出图表前（5.6–6.1 秒）表格整体左移 200px，给图表让位。角色可以跳出窗口上沿一点点，但头不能出画。

## 6. 声音

- 120 BPM，C – Am – F – G，电钢琴和弦 + 反拍拨弦 + 轻 groove 鼓 + 贝斯，音量低。
- 角色：每次起跳 `jump`，每次落地 `boop`（音高轮换）+ `paper`（纸团沙沙声）；掉进来时 `whoosh` + `boing`。
- 界面：点按钮 `click`，下拉 `swish`，打勾 `pop`，扛起 `pop2`，放下 `thud`，归位时每次有行到位一声 `tick`（3.375 / 3.5 / 3.625 / 3.875 / 4.0），柱子长出马林巴 72 / 76 / 79 / 84，跳台阶 `blip` 逐级降调，toast `ding`，片尾 `chime`。

## 7. 文字与标题

- 界面文字就是字幕：按钮名、表头、公式栏、下拉选项、toast，全部用观众一眼能懂的中文。
- 数据用简单的例子（水果销量），数字不超过两位。
- 片尾一句话总结教了什么：“排序 · 筛选 · 一键出图表”。

## 8. 踩过的坑

- 开场到出图表前的 6 秒，窗口右半边一大片空白：改成表格先居中，出图表前再滑到左边。
- 几次长距离跳跃弧线太高（150 / 130 / 110px），小人头顶出画；降到 90 / 60 / 60px。
- 小人落在复选框上会把复选框整个挡住，观众看不到“打勾”；改成落在选项文字右侧，复选框露在外面。
- 排序归位时行和行互相穿过，文字叠成一团；移动中的行加白底和投影。
- 加了白底投影后，5 行在同一列里同时交叉穿行，半行字被别的行挡住，看起来还是乱；而且橙子放下时正落在苹果上。改成：扛的途中苹果、香蕉先下移让位；其余行走“两条道”——需要跨行的先横着拎到右侧通道（右移 310px 只盖数据条），竖着走完再横着落回空位，相邻的只在本列挪一格；按 0.125 秒一步排好先后，保证同一条道里任何时刻不重叠、字永远不被挡。这是 5 行的环形置换（最长下降子序列 = 3），两条道也必须靠先后顺序错开，不能一拍同时走完。
- 纸团纹理如果每帧重新随机会闪：`Math.random` 只在初始化时生成纹理和轮廓，之后只贴图。

## 9. 制作流程（本仓库）

1. 在顶部定时间表（`DROP`、`GRAB`、`PUT`、`FBTN`、`CHECK`、`CBTN`、`BARS`、`STEP`）和移动表 `MOVES`，所有落地时间卡在拍点上；`LANDS` 自动汇总所有落地时刻，用来做压扁。
2. 抽帧：`node _engine/render.cjs live-screencast stills 0.95,1.6,2.75,4.25,5.1,5.9,7.2,8.25,12.8`
3. 出片：`node _engine/render.cjs live-screencast`

## 10. 引擎用法

- `hero()`：根据 `MOVES`、`JOY` 算出小人当前脚底位置、是否在空中、是否在扛东西。
- `drawHero(m)`：画小人（影子 → 腿 → 手 → 身体纹理 → 脸）。
- `btn(x, 文字, 图标, 点击时刻, 激活)`：工具栏按钮，自带按下和外扩框。
- `rowPos(i)` / `drawRow(i, 被扛)`：每一行随排序（`SORTK` 关键帧）、被扛、被筛选的位置、通道右移和透明度；绘制顺序为静止行 → 本列移动行 → 通道行。
- `FINAL`：每项排序后的位置；`CHART`：筛选后进图表的四项。
