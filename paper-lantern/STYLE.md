# 纸雕灯影 — 风格提示词（v1）

> 一盏走马灯，灯面是五六层叠在一起的纸雕，背后一盏暖灯：后面的纸最亮最虚，前面的纸最暗也最虚，中间那层最清楚；镜头推进灯里，纸雕世界转起来，最后再拉回一盏灯。适合中秋、礼品品牌、温情故事。
> 样片：《走马灯》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **纸雕灯影** 风格讲一个“绕一圈回到原点”的温情故事。用户给你一段人生或一段旅程，你把它放进一盏灯里：开场点灯、推进去，主角在层层纸雕里一路走，世界像走马灯一样转，最后回到出发的那扇门，再拉出来看回那盏灯。

---

## 1. 这个风格是什么

纸雕灯（lightbox）的质感来自三件事：**背光**（光从最后面透过来，纸越靠后越亮）、**层间投影**（每层纸在后一层上投一道暗影，有厚度）、**景深**（远层和近层都虚，中间那层实）。所有东西都是剪影，没有描边、没有内部细节，靠轮廓和层次讲故事；唯一的“亮”是挖掉的洞：窗、门、太阳。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **点灯 + 推进灯里** | 开场是一盏暗着的灯，0.3 秒点亮；2.4–3.4 秒推进，灯面正好放大到铺满画面，灯框被推出画外。 |
| **走马灯 = 横移** | 主角固定在 x=560 往右走，世界往左转；远山 0.1、丘陵 0.3、树丘 0.6、房子和主层 1、前景草 1.5、前景大树 2.6 倍视差。 |
| **躲在树后长大** | 最前面一层的大树在拍点上正好挡住主角，树移开时人已经长大一截（小孩 → 少年 → 大人）。 |
| **绕一圈回原点** | 世界长 1500px，终点是同一座房子；门开，门里的光把两个剪影照出来，拥抱。 |
| **拉回灯外** | 12.6–13.8 秒拉回，灯面上还是那座亮着窗的房子。 |

**结构**：暗灯 → 点灯 + 片名“走马灯”（0–2.4 秒）→ 推进（2.4–3.4）→ 小孩出门放风筝（3.6）→ 松手风筝飞走（5.2）→ 树后长成少年（5.83）→ 过桥 → 树后长成大人、拎箱子（8.33）→ 路灯、远处城市 → 天色变暗、窗子亮 → 回到门前放下箱子（11.0）→ 门开（11.25）→ 拥抱（12.0）→ 拉出（12.6–13.8）→ 片尾“回家” → 淡出。

## 3. 视觉语言

- **背光板**：径向渐变，白天 `#FFF1CF → #FBC77E → #D98A45`，一路插值到夜里 `#FFD39A → #E48A48 → #7A2C12`（6–11 秒）。太阳是一个挖空的亮洞，从 (360,150) 慢慢移到 (960,210)。
- **六层纸**（每层是一张径向渐变的纸，中心亮边缘暗）：
  - 远山 `#FAD9A2 → #E6A864`，模糊 2.2px
  - 丘陵 + 远城 `#F0B670 → #CF8444`，模糊 1.3px
  - 树丘 `#DA8F4A → #A4552A`，模糊 0.6px
  - 房子 `#B8662F → #7A3A18`，模糊 0.3px（窗、门挖空）
  - 主层（地面、树、桥、路灯、人）`#8E4520 → #4E200D`，不模糊
  - 前景（草、大树）`#3A170A → #1C0905`，模糊 3.5px
- **层间投影**：`rgba(50,15,2,.55)`，模糊 22、向下 9（1080p 像素）。每层叠一张纸纤维纹（`source-atop`，只落在纸上）。
- **光**：门开时门口一团 `lighter` 暖光（半径 160）；9.5 秒后每扇窗一团光（半径 70）；光里飘 26 粒尘。
- **灯**：深红木架 `#4A140C` + 金线 `#C99A4A`，翘角顶盖，三条红流苏；灯面 400×225（正好 16:9），两侧斜面上有随转动移动的竹骨。
- **人物剪影**：小孩 112px（大头 + 小辫）、少年 152px（书包）、大人 184px（长外套 + 箱子）、老人 160px（前倾 + 发髻）。
- **字体**：Noto Serif SC 600，34px，暖米色，只在灯外出现。

## 4. 动作语言

- **匀速走**：主角的世界坐标是“头尾各 8% 加减速、中间匀速”的曲线，3.6 秒出门、11.0 秒停在门前；步子的相位由走过的距离算，不会滑步。
- **镜头跟人**：相机位置 = 人的位置 − 560，人出门那一小段相机不动。
- **推拉**：`ease` 缩放，以灯面中心 (640, 362.5) 为原点，1 → 3.32 → 1。
- **挡住再长大**：最前层大树的世界坐标由“长大时刻的相机位置 × 2.6 + 560”反算出来，保证那一帧树正好在人身上。
- 风筝 5.2 秒松手，用 `easeIn` 往右上飞出画面；门扇 0.45 秒推开；拥抱时两人各往中间挪、手臂抬起。

## 5. 镜头语言

一个“推进—横移—拉出”的长镜头：灯外全景 → 推进灯里 → 跟着人横移（走马灯转）→ 停在门前 → 拉回灯外。推进和拉出各 1 秒，不切镜头。

## 6. 声音

- 72 BPM。八音盒（`mbox`）旋律 + 低八度点缀，弦乐（`strings`）每小节一个和弦（C – Am – F – G – C），`bass` 轻轻托底。
- 点灯：`whip`（划火柴）+ 轻 `whoosh` + `shimmer`。推进：`whoosh` + `shimmer`。
- 长大那一拍：`swish`（树掠过）+ `chime`，旋律同一拍跳到高音 C。
- 开门：自制门轴吱呀声（锯齿波 90→140→70Hz、900Hz 带通）+ `bell`；拥抱：八音盒琶音；拉出 `whoosh`；结尾低音 `bell` + 弦乐和弦。

## 7. 文字与标题

只有两处字，都在灯外：开场“走马灯”（0.9–2.6 秒），片尾“回家”（13.6 秒起）。灯里一个字都不放，全靠剪影。

## 8. 踩过的坑

- **小孩被门洞挖掉了**：人和门都在主层，窗 / 门的洞在人之后挖，站在门口的小孩被一起挖空；改成先挖洞再画人。
- **人贴在房子上看不见**：人和房子同一层同一个颜色，门口的两个人和墙糊成一片；把房子单独拆成更浅的一层放在人后面，门里的光再从人身后透出来。
- **挡人的大树一开场就挡在画面中间**：第一版最前层视差 1.5、走路用正弦缓动（起步很慢），算出来的树位置开场就在房子右边；改成视差 2.6 + 匀速走，开场时树还在画面外。
- **推满以后还看得到灯柱**：灯柱和灯面重叠了 12px，放大 3.2 倍后两边各多出 38px 的木条；灯柱挪到灯面外，放大倍数改成 3.32。
- **风筝凭空消失**：小孩变少年的那一帧风筝跟着没了；改成 5.2 秒松手，风筝自己飞出画面。
- **旋律比片子长**：第一版写了 23 拍（19 秒），后半段都被截掉，响度也一段有一段没；重写成 17 拍，长大、开门、拥抱都落在拍上。
- 人物原来只有 92–150px，缩在灯面里几乎看不见；放大到 112–184px。

## 9. 制作流程（本仓库）

1. 改顶部时间表 `T`（点灯、推进、走路、长大、开门、拥抱、拉出）和 `LOOP / FIGX / DOOR`。
2. 抽帧检查：`node _engine/render.cjs paper-lantern stills 1.8,3.45,5.5,5.83,8.33,9.6,11.5,12.2,14`，拼 3×3 联系表看。
3. 出片：`node _engine/render.cjs paper-lantern` → `demo.mp4` + `poster.jpg`（封面 13.3 秒：镜头拉回一半，灯框里是亮着窗的家和拥抱的两个人）。
4. 检查：时长 15.0 秒，响度约 -15.5 LUFS。

## 10. 引擎用法

- `layer(颜色[中心, 边缘], 模糊, 画形状, 挖洞, 挖完再画)`：纸雕的核心——在 `LY` 上画黑色形状 → `source-in` 换成本层渐变 → 叠纤维纹 → 挖洞 → 带投影和模糊贴进 `DIO`。
- `DIO` 是整个纸雕场景（1920×1080，每帧清空）；灯外时缩小画进灯面，推满时 1:1 铺满。
- `figW(t) / camS(t)`：人的世界坐标和相机位置；`X(世界x, 视差)` 换算到屏幕。
- `person(g, x, 地面y, 身高, 步态相位, 类型, {stand, hug})`：四种人物剪影；`tree / ridge / smoothPath`：树、山脊线。
- `lerpCol(a, b, u)`：两个十六进制颜色插值（背光从白天到夜里）。
- 门轴声 `creak(w, B)` 用 `B.sfx.context` 自己建振荡器接到 `B.sfx`。
