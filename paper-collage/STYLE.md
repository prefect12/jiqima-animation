# 剪纸拼贴定格 — 风格提示词（v1）

> 牛皮纸背景、彩纸剪出来的形状、每片纸都有投影和白色毛边，画面按 12 帧/秒量化并逐帧微抖，像手工一帧一帧摆拍出来的定格动画。
> 样片：《从想法到上线》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **剪纸拼贴定格** 风格讲一个“从无到有”的故事。用户给你一个主题，你用 3–4 个能用纸剪出来的物件串起来（灯泡 → 手机 → 火箭 → 横幅），每个物件都是由几片纸“拼”出来的。

---

## 1. 这个风格是什么

温暖、手工、慢一点。它的质感来自三件事：纸片投影（有厚度）、12fps 的顿挫（定格感）、每帧每个顶点都轻轻抖一下（手摆的不精确）。适合品牌故事、个人经历、产品从 0 到 1。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **一片一片拼出来** | 手机屏幕上的 UI 块一片片贴上去 = “在做产品”。 |
| **物件变形** | 灯泡（想法）→ 手机（产品）→ 装上尾翼变火箭（上线）。 |
| **层叠山丘** | 三层纸山做地面，天然有纵深。 |
| **撒纸星星 + 横幅** | 结尾庆祝，横幅上写一句话。 |

**结构**：物件掉下来（落地弹一下）→ 点亮 / 变化 → 下一个物件升上来 → 一片片贴细节 → 点火升空 → 纸星星 + 横幅，结尾小火箭绕一圈回来。

## 3. 视觉语言

- **纸面**：牛皮纸 `#E3CFAA` + 256px 纸纹噪点平铺（10% 不透明）。
- **山**：三层 `#9CB58A / #6E9A6A / #4E7A55`，折线轮廓，越近越深。
- **物件色**：暖黄 `#F6C945 / #FFE27A`、橙红 `#F2683C / #E36A4C`、奶白 `#F7F4EC`、天蓝 `#9FC7E8`、金属灰 `#9AA3AC`。
- **纸片**：每片 `shadowBlur 10`、`shadowOffsetY 3–7`（越靠前越大）、投影色 `rgba(40,25,10,.35)`；边缘 2px 半透明白线（剪口）。
- **圆**：用 26–30 个点的多边形，半径 ±2.5% 固定扰动，像手剪的圆。
- **字体**：站酷快乐体 ZCOOL KuaiLe，写在奶白横幅上，墨色 `#3B2E22`。

## 4. 动作语言

- **12fps 量化**：`f = floor(t*12)`，所有动画用量化后的时间，所以动作是一格一格的。
- **逐帧抖动**：每个顶点每格 ±0.8px（`hash(f, 顶点, 种子)`），不同纸片种子不同。
- **整体放慢**：故事时间 = 影片时间 / 1.45，给每个动作留足停顿。
- 掉落用平方缓动，落地向下顿 10px；弹出用 `back`；升空用 1.6 次方加速。

## 5. 镜头语言

固定机位，像摆在桌上俯拍的纸景。物件从画面外进出（掉下来、升上去、横幅从左边滑进来），不移动镜头。

## 6. 声音

- 拨弦八分琶音（`pluck`）+ 轻鼓 + 贝斯，92 BPM，温暖。
- 每贴一片纸一个 `paper` 摩擦声；落地 `thud + boing`；点亮 `chime`；升空 `riser → impact`；星星一颗一个 `pop2`；横幅落定时八音盒（`mbox`）琶音。

## 7. 文字与标题

全片只有一句话，写在最后的横幅上（6–8 个字）。其余全部靠物件讲。

## 8. 踩过的坑

- 火箭飞走后画面只剩星星和横幅，最后 4 秒太空：加了一只小纸火箭从左到右绕一圈飞过。
- 抖动一定要按 12fps 的格号取，不能按真实时间，否则会变成 30fps 的细碎抖动，失去定格感。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 里各物件的故事时间（按 `K` 缩放前的时间写）。
2. 抽帧：`node _engine/render.cjs paper-collage stills 2,5,8.8,12.5`
3. 出片：`node _engine/render.cjs paper-collage`

## 10. 引擎用法

- `shape(点列, 颜色, 种子, 投影高度)`：画一片带投影、毛边、逐格抖动的纸。
- `circ(x, y, r, 点数, 种子)`：手剪圆；`rect(x, y, w, h)`：略歪的四边形。
- 配乐里用 `at(故事时间, …)` 自动乘以 `K` 对齐画面。
