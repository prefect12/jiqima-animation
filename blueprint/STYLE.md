# 工程蓝图 — 风格提示词（v1）

> 普鲁士蓝底、白色细线、网格和图框：零件一根根被“画”出来，标上尺寸和序号，拆成爆炸图再一件件装回去。适合硬件发布、工程科普、“这东西是怎么做出来的”。
> 样片：《一把雨伞》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **工程蓝图** 风格做一支产品 / 结构讲解短片。用户给你一件东西，你先把它拆成 4–8 个零件，定好“画线 → 动作 → 标注 → 爆炸 → 装配 → 用起来”的顺序，每个关键动作卡在拍点上，最后让这件东西真的被用一次。

---

## 1. 这个风格是什么

观众看到的是一张正在被绘图仪画出来的工程图：先有图框和网格，再有中心线，然后零件按顺序出现。它的说服力来自“规矩”——尺寸箭头、序号气泡、零件表、标题栏、隐藏线虚线，这些工程制图的惯例让一件普通的东西显得精确、可信。最后一个“使用场景”（下雨）是唯一不属于图纸的东西，所以格外有效。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **逐线画出** | 零件沿轮廓“画”出来，笔尖处带一个绘图仪十字准星。 |
| **机构动作** | 会动的部分（伞骨展开）分成 4 格棘轮式动作，一拍一格。 |
| **尺寸标注** | 尺寸线从延伸线里“拉”出来，数字最后出现；一拍一个尺寸。 |
| **爆炸图 → 装配** | 零件先停在分离位置并带装配方向箭头，然后一拍装上一个。 |
| **零件表 / 标题栏** | 每出现一个零件，右上角零件表就填一行；标题栏交代图名、图号、比例。 |
| **盖章** | 装配完成时盖一个“装配完成”印章，是全片唯一的暖色。 |
| **真实使用** | 最后让物体被用一次（下雨打在伞面上），从图纸跳到现实。 |

**结构（15 秒版，120 BPM）**：图框 + 网格（0–1 秒）→ 中棒（1.0）→ 伞骨 + 滑块（2.0）→ 伞骨四拍展开（2.5/3.0/3.5/4.0）→ 三个尺寸（4.5/5.0/5.5）→ 爆炸图：伞面 / 伞尖 / 手柄（6.5/7.0/7.5）→ 装配三拍（8.5/9.0/9.5）→ 盖章（10.0）→ 下雨（10.5 起）→ 14.45 淡出。

## 3. 视觉语言

- **底色**：径向渐变 `#1A4E8A`（中心）→ `#0E3261`（边缘）；一张 64×36 随机噪声图拉伸到全屏，`soft-light` 10% 做晒图纸的斑驳；再叠 `grain 0.045` 和深蓝暗角 `vignette(.35, '4,14,32')`。
- **网格**：细格 20px、`rgba(234,243,255,.055)`；粗格 100px、`.13`；只画在内框里。
- **图框**：外框 14px 边距 2px 线，内框 34px 边距 1.2px 线；上下边写 1–6、左右边写 A–D 的分区号（Plex Mono 11px）。
- **线色**：全部用 `#EAF3FF`，靠透明度和线宽分层——零件轮廓 2–2.2px、伞骨 2px、支骨 1.2px、尺寸线 1–1.2px、中心线 1px 点划线 `[26,6,4,6]`、隐藏线 1.2–1.4px 虚线 `[7,5]`、剖面线 1px 17% 透明、45° 间隔 11px。
- **晒图洇墨**：零件图层整体 `shadowBlur 4`、`shadowColor rgba(170,215,255,.55)`，线条带一点点辉光，像蓝晒纸上的白线。
- **零件实体**：管件画成“白描边 + 内部 `#1A4B86` 填色”的双线管（手柄：15px 白线上叠 10.5px 蓝线），伞面填 `rgba(28,80,142,.96)` 并加剖面线。
- **字体**：数字和英文 IBM Plex Mono（500/600），中文 Noto Sans SC（500/700）。尺寸数字 18px，零件表 15–16px，标题栏图名 24px。
- **印章**：`#FFD7A8` 双圆角框，旋转 -0.12 rad，上面用底色打 70 个随机小洞（`hash` 固定）模拟印泥不匀。
- **比例**：1px = 2mm，所以画面上的 Ø1100、820 和 66° 都和几何参数一致（伞骨长 300px、张角 66°、俯视倾斜 0.2）。

## 4. 动作语言

- **画线**：`pl(点列, 进度)` 按长度匀速画，0.4–0.5 秒一个零件，`easeOut`。
- **棘轮展开**：每拍张开 25%，0.2 秒内带一点过冲（自定义回弹曲线），像伞骨卡进一格。
- **尺寸**：延伸线先伸出，尺寸线从中点向两端展开，箭头跟着走，进度过 60% 才出数字。
- **爆炸 / 装配**：爆炸位移——伞面 -130、伞尖 -150、手柄 +55；装配在拍点前 0.3 秒开始 `easeIn` 加速，正好在拍点“咔”地落位，再有 0.15 秒 4px 的反弹。
- **尺寸让位**：爆炸阶段尺寸标注淡到 28%，装配完再恢复——一张图上同一时刻只强调一件事。
- **序号气泡**：引线从气泡伸向零件，端点小实心圆；零件移动时引线跟着拉伸。
- **雨**：190 根雨线，速度 820–1060 px/s，斜率 0.16；落在伞面范围内的雨在伞面上停住，溅起两道短斜线（0.16 秒）；伞骨尖每 0.5 秒滴一滴水。

## 5. 镜头语言

固定机位，一张图纸从头到尾不动。所有“镜头感”来自图纸本身：先全局（图框、网格）后局部（零件），焦点靠“正在画的那一笔”和绘图仪准星来引导。

## 6. 声音

- **配乐**：极简电子，A 小调，120 BPM——pad 长和弦、每拍一个 sub bass、第 2 小节起四拍底鼓 + 反拍踩镲；从标注段开始叠十六分音符拨弦琶音，像仪器在计算。
- **机械音效（自己合成）**：`ratchet`（4 个高频咔嗒 + 一下低频“咚”）对应伞骨每一格；`clack`（带通噪声 + 三角波）对应每次装配落位，三个零件音高不同；`plotter`（方波 95→140Hz 过带通）对应每次画线；`zip`（扫频噪声）对应尺寸线拉出，数字出现时 `tick`。
- **盖章**：`thud + impact`。**下雨**：循环噪声（高通 900Hz、低通 6kHz）1 秒渐强，再叠 60 个随机音高的短噪声点当雨滴。
- 结尾一个 A 小调和弦收住。

## 7. 文字与标题

画面上的字全部是“图纸上本来就会有的字”：零件名、材料、数量、尺寸、标题栏、印章。不要旁白字幕、不要口号。零件名 2 个字，材料 2–3 个字；尺寸只写数字和单位符号（Ø、°），单位统一写在标题栏。

## 8. 踩过的坑

- 伞面剖面线最初只画了 260px 长，覆盖不到伞面下半部分，看起来像只填了一半；改成 420px 长的斜线再用伞面轮廓裁切。
- 第一版雨太淡（150 根、1.2px、55% 透明度），1080p 下几乎看不见“开始下雨”；加到 190 根、1.5px、78%、每根 26px 长。
- 雨滴溅起最初画成两个小圆圈，缩小后像伞面上的脏点；改成向两侧抬起的两道短斜线。
- 伞骨中间的支骨长度要固定：滑块位置用“支骨长 132px”反推，否则展开时支骨会伸缩穿帮。
- 装配后伞面盖住了后排伞骨和滑块，按工程制图惯例把它们改画成虚线（隐藏线），而不是直接消失。
- 所有随机量（雨滴位置、印章洞、噪声纹理）要么用 `hash()`，要么只在初始化时生成一次，否则逐帧闪烁。

## 9. 制作流程（本仓库）

1. 改 `demo.html` 顶部的时间表（`T_SHAFT / OPEN / DIMS / EXP / ASM / STAMP / RAIN`）和几何常数（`CX / TOP / L / TH_OPEN / TILT`），`score()` 里的音效直接用同一组常量。
2. 抽帧检查：`node _engine/render.cjs blueprint stills 1,3,4.2,6,7.8,9.2,10.3,12.3,14.3`
3. 拼联系表：`ffmpeg -y -v error -pattern_type glob -i "blueprint/stills/*.jpg" -vf "scale=640:360,tile=3x3:padding=6:color=white" -frames:v 1 /tmp/blueprint.jpg`
4. 出片：`node _engine/render.cjs blueprint` → `demo.mp4` + `poster.jpg`（封面 12.3 秒：装配完成 + 下雨 + 全部标注）。

## 10. 引擎用法

- `pl(点列, 进度, 闭合)`：按长度画出折线的一部分，未画完时记录笔尖，最后统一画绘图仪准星。
- `ribPt(方位角, 张开度, 沿骨位置)`：伞骨上一点的屏幕坐标（含俯视倾斜）；`ribPts()` 取整根伞骨的点列。
- `openAt(t)`：四个拍点叠加的棘轮式张开度 0–1。
- `dyOf(零件, 装配时刻)`：爆炸位移 → 0 的装配曲线，带落位反弹。
- `arrow(x, y, 角度)`：尺寸线箭头；`arcPts()`：角度标注的圆弧点列。
- `silY(dx) / hemY(dx)`：伞面顶轮廓和前缘的高度，用来让雨滴停在伞面上。
- 声音：`burst()`（滤波噪声）、`tone()`、`ratchet / clack / plotter / zip / rainBed`，都通过 `B.sfx.context` 自己建节点，连到 `B.sfx`。
