# 纸片立体书 — 风格提示词（v1）

> 一本放在木桌上的立体书：封面翻开，纸城堡沿折痕立起来；拉一下纸条，太阳升起、旗子升上旗杆；再翻一页，城堡倒下，一条纸龙从山洞前探出头，拉条一拉就喷出一层层纸火焰。
> 样片：《龙与城堡》（15 秒）· `demo.mp4` · 源码 `demo.html` · 封面 `poster.jpg`

你要用 **纸片立体书** 风格讲一个两三页就能讲完的童话。用户给你一个故事，你把它拆成 2–3 个跨页：每个跨页左边一句话、右边一组立体机关，再给每页配一个“拉条”让某样东西动起来。

---

## 1. 这个风格是什么

观众看到的是一本真实的书，被一个看不见的人翻开。它的魅力来自“纸”的物理：页绕书脊转、机关件沿折痕从平躺转到直立、每一片纸都在页面上投下影子、侧面有小小的三角支撑纸条、拉条从页边伸出来。一切都是平面——没有任何圆滚滚的 3D 物体，立体感全靠多层平面在不同深度上站起来。

## 2. 剧情：什么故事适合

| 本事 | 用法 |
|---|---|
| **翻页 = 转场** | 一页一个场景，翻页时旧场景倒下、新场景立起，天然的“换幕”。 |
| **层次 = 纵深** | 远山、主体、前景树 / 石头，各在一条折痕上立起，镜头一动就有视差。 |
| **拉条 = 小动作** | 太阳升起、旗子升起、嘴张开、火焰伸出——每页一个，给观众一个“哇”的瞬间。 |
| **左页一句话** | 故事的文字印在左页上，一页不超过 15 个字。 |

**结构**：合着的书（封面书名）→ 翻开封面，城堡随封面转过去而立起 → 拉条 1（太阳 + 旗子）→ 翻页，城堡倒平、龙在后半程立起 → 龙往前探头（低音 tom）→ 拉条 2（张嘴 + 纸火焰）→ 镜头慢慢退后 → 淡出。

## 3. 视觉语言

- **书**：单页 4.2 × 5.4（世界单位），书块高 0.2；封面是 0.2 厚的硬板，布面青 `#20576A`、板边 `#163844`，烫金 `#D9B45A` / `#E8C66A`（书名 + 描边框 + 小城堡徽章）。纸 `#F4EBD5`，左页内框 `#EFE3C6`，书页块前沿每 0.03 画一条纸层线。
- **桌面**：径向渐变 `#7A5A43 → #2C1E16`，左上一盏台灯的暖光（`rgba(255,220,160,.14)`），全画面 5% 颗粒 + 暗角 .45。书在桌上的投影 `shadowBlur 40`、偏移 (18, 10)。
- **机关件**：平面多边形 + 同平面上的印刷细节（砖缝、窗、门、鳞片、眼睛）。描边 1.1px `rgba(70,50,30,.55)`；沿上缘再描一条 0.8px 的亮纸边 `rgba(255,250,235,.35)`。侧面三角支撑用 `#D8CDB4`。
- **光照**：光的行进方向 L = (0.55, 0.35, −1) 归一化（左后上方）；每个平面按朝向相机的法线算 `0.64 + 0.36·max(0, −n·L)`。影子 = 把机关轮廓沿 L 投到所在页面上，`rgba(50,30,15,.2)`，并裁在页面范围内。
- **配色**：天空淡彩 `#CFE3EA`、草地 `#A9CF8A`、小路 `#E8D3A6`、城墙 `#DCCDAE`、屋顶 `#C8553D`、旗 `#F2C14E`、太阳 `#F6B93B`；龙身 `#3E8E5B`、肚皮 `#8CCB7E`、翅膀 `#2F6E47`、角 `#F2E3B3`；山 `#8C7BA3`、洞口 `#2F2438`；火焰三层 `#E4572E / #F28B30 / #FFD166`；拉条 `#E9C46A` + 红标签 `#C0392B`。
- **字体**：站酷小薇体（ZCOOL XiaoWei），墨色 `#4A3526`，字高 0.3–0.34 个单位；封面书名 0.6。

## 4. 动作语言

- **翻页**：页绕书脊（y 轴）转 0 → π，`ease`，1.9 秒（3 拍）。页是硬卡纸，不弯曲。
- **机关立起**：角度直接由页角算——城堡 `easeOut(θ封面 从 0.35π 到 0.93π)`；翻下一页时城堡在 θ = 0 → 0.42π 内倒平；龙在 θ = 0.55π → 0.98π 内立起。所以机关永远和翻页同步，不会“自己动”。
- **探头**：龙立到 90° 后再用 `back` 前倾 22°（0.4 秒），之后以 ±3° 慢慢起伏；每 2.6 秒眨一次眼。
- **拉条**：纸条从页边多拉出 0.55，同一时间内太阳沿纸杆从 0.35 升到 1.95、旗子升 0.44；第二个拉条让下巴转开 24°，三层火焰从嘴里伸出（长度 1.0 / 0.8 / 0.58），火焰锯齿每 1/8 秒交替一次形状。

## 5. 镜头语言

一台慢慢移动的“俯拍相机”（透视，焦距 1060–1380px）。开场对准合着的书（在画面右半），翻开封面时平移到书脊中心并退后；翻页时往右偏一点（让竖起来的那页不是正侧面）；龙探头后轻推近，最后缓缓退后。机位高度始终在书上方 6–7.4 个单位，俯角约 40°。

## 6. 声音

- 96 BPM。童话拨奏：Dm – B♭ – F – C，低音四分拨弦（`pizz`）+ 高八度八分琶音（`pluck`），第 3 小节起加弦乐铺底，结尾 D 小调和弦 + 钟声。
- 翻封面：`whoosh + paper`，城堡立起时一串上行拨弦（D5 → D6），落定 `thud`。
- 拉条：两下 `paper` + `chime`。
- 翻页：`paper → whoosh → paper → thud`。
- 龙探头：两下低音 `tom`（E2 → A1）+ 次低音。
- 喷火：`riser → whoosh → tom`，一段 70 → 55Hz 锯齿低吼（300Hz 低通）+ 10 下纸火苗噼啪。

## 7. 文字与标题

只有三处：封面“龙与城堡”；第 1 页“从前，／山上有一座城堡。”；第 3 页“城堡后面的山洞里，／住着一条龙。”；外加拉条上的“拉”。文字印在纸上，随页一起转动、一起透视。

## 8. 踩过的坑

- **翻页像半透明**：抬起的页在下面一页上的影子是在画完抬起的页之后才画的，裁切区域又和它重叠，结果把抬起的页也压暗了一块，看起来像透明纸。改成先画影子、再画抬起的页。
- **顶部被裁**：城堡旗子、龙的远山在画面顶上被切掉。焦距从 1250 降到 1090 左右，投影中心下移 24px。
- **火焰出画**：火焰原长 1.3，喷到画面右边外面，缩到 1.0。
- **龙的翅膀和背刺“飘着”**：翅膀原来是一块不接触页面的纸，还带了一根悬空的三角支撑；背刺按手填坐标放，离脖子有缝。翅膀改到脖子后面并去掉支撑，背刺改成沿脖子后缘的每一段自动生成。
- **封面徽章像“上传”图标**：三角 + 方块的组合一眼像 UI 图标，改成城垛小城堡。
- **翻页看不到**：相机正对书脊时，竖起来的那页只剩一条线。翻页中段把相机往右偏 1 个单位。
- 分组画法：先画左边（从下往上），再画右边（从下往上）；同一页内机关按到相机的距离从远到近排序。

## 9. 制作流程（本仓库）

1. 在 `demo.html` 顶部改时间常量（`T_OPEN`、`T_PULL1`、`T_TURN`、`T_PEEK`、`T_PULL2`，都是拍号 × `BEAT`）；每页内容在 `page1 / page2 / page3 / page4 / cover` 里。
2. 抽帧检查：`node _engine/render.cjs popup-book stills 0.3,1.3,2.4,5.4,7.4,7.8,8.3,9.4,12.4,13.9`
3. 出片：`node _engine/render.cjs popup-book` → `demo.mp4` + `poster.jpg`（封面 12.4 秒：龙喷火）。

## 10. 引擎用法

- `P([x,y,z])`：透视 lookAt 投影；相机位置和焦距用 `F.keyframes` 排。
- `leafXf(θ, 书脊高度)`：页坐标 (u, v, w) → 世界坐标；`leafN(θ)` 是页正面法线，和“到相机的向量”点乘决定看到正面还是背面。
- `pieceXf(页变换, 折痕 v0, 立起角 φ)`：机关平面坐标 (a, b) → 世界坐标；`piece(…, 形状, 颜色, 印刷细节, {struts})` 返回带 `depth / shadow / draw` 的对象。
- `shadowOn(点列, θ, 高)`：沿光线把点投到页面平面上。
- `drawPieces(列表, 页面轮廓)`：先裁在页面内画所有影子，再按深度从远到近画机关。
- `textOn(页变换, u, v, 文字, 字高, 颜色, 方向)`：三个投影点求仿射矩阵，把字“印”在页上（左页方向取 −1）。
- `tab(页变换, u0, 拉出量)`：拉条 + 页面上的槽。
